# 02 · Linux 发展简史与发行版生态

> 上一篇：[[01-从Windows到Linux的思维转换]] · 下一篇：[[03-文件系统与目录结构]]
> 搞清"Linux"这个词到底指什么，NixOS 在版图里的位置。

## 1. 时间线：三个关键年份

### 1970 · Unix 诞生
贝尔实验室的 Ken Thompson 和 Dennis Ritchie 写出 Unix。
确立了影响至今的设计哲学：
- **一切皆文件**（硬件、进程、网络套接字都抽象成文件）
- **小工具组合**（每个程序做好一件事，用管道串起来）
- **纯文本配置**

Unix 是商业软件，后来衍生出 BSD、Solaris 等。macOS 的血统就来自 BSD。

### 1983/1985 · GNU 与自由软件运动
Richard Stallman 发起 GNU 项目（"GNU's Not Unix"）：
要做一个**自由**的 Unix 替代品——用户有权运行、学习、修改、分发。
到 90 年代初，GNU 做出了编译器（gcc）、shell（bash）、核心工具（coreutils）……
**唯独缺一个能用的内核**。

### 1991 · Linux 内核
芬兰大学生 Linus Torvalds 写出 Linux 内核并开源。
GNU 的工具 + Linux 内核 = **GNU/Linux**，即今天我们说的"Linux"。

> 严格说："Linux"只是内核；你用的系统是 GNU/Linux + 一堆其他软件。
> 日常说"Linux"指整个操作系统，都知道什么意思就行。

## 2. 发行版：同一内核，千种组合

内核 + GNU 工具 + 包管理器 + 桌面 + 默认配置 = **发行版（distro）**。
不同发行版 = 不同的"组装哲学"。300+ 发行版，主要家族：

### Debian 系（最庞大）
- **Debian**（1993）：稳定代名词，社区驱动，服务器常客
- **Ubuntu**（2004）：Debian 之上做易用性，曾是桌面首选，推动 Linux 普及
- Linux Mint、Pop!_OS、deepin（深度，国产）：Ubuntu 的再加工

### Red Hat 系（企业）
- **Fedora**：技术前沿试验田（Wayland、PipeWire 都是它先推）
- **RHEL**：企业付费版 → CentOS（已转型）/ Rocky / Alma

### Arch 系（折腾向）
- **Arch**（2002）：滚动更新、极简、wiki 天下第一
- **Manjaro**：Arch 的易用版

### 独立思想派
- **Gentoo**：一切从源码编译，极致定制
- **NixOS**（2003 起）：**你的系统**。不改良旧方案，直接换范式——
  用函数式编程思想做包管理和系统配置。详见 [[02-Nix核心思想-纯函数式部署]]

### 国产
deepin、UOS（统信）、openKylin：政企市场为主。

## 3. 桌面环境：发行版之上的又一层

发行版管系统，**桌面环境（DE）**管你看到的界面：
- **GNOME**：现代化、触屏友好、扩展生态大（≈ macOS 风）
- **KDE Plasma**：功能最全、可定制性最强（≈ Windows 风）
- Xfce/LXQt：轻量，老机器用

还有一类**平铺窗口管理器/合成器**（窗口自动排列，键盘流）：
i3、Sway、Hyprland，以及你用的 **niri**（滚动平铺新物种）。
你没有装完整 DE，是"niri + 自己拼组件"的极客方案——见 [[02-niri与平铺合成器]]。

## 4. NixOS 在版图里的位置

| 维度 | 传统发行版 | NixOS |
|---|---|---|
| 装软件 | `apt install`（命令式，改系统状态） | 配置文件声明（声明式） |
| 配置 | 散落 /etc 各处，手动改 | 一个 git 仓库管全部 |
| 升级失败 | 可能变砖 | 开机选旧代际秒回滚 |
| 同一台机多版本共存 | 难（依赖地狱） | 天然支持（/nix/store 哈希隔离） |
| 复制系统到新机 | 重装+凭记忆 | git clone + 一条 rebuild |

代价：学习曲线陡、社区小、外来二进制（Unity 这种）要特殊处理
——你已经在 [[Unity开发踩坑]] 体验过了。

## 5. 2026 年的 Linux 桌面现状

- **Wayland 已成主流**（取代 X11），见 [[01-显示服务器-从X11到Wayland]]
- **PipeWire 统一音频**（取代 PulseAudio/JACK 之争）
- **Flatpak** 补应用生态（沙箱化桌面应用）
- 游戏：Steam Proton 让 Windows 游戏大量可玩
- 你的配置（niri + Noctalia + DMS）是非常现代的前沿组合

## 6. 一句话总结

> Unix 给了哲学（1970），GNU 给了工具和自由（1983），Linus 给了内核（1991），
> 发行版给了千种组装方式，NixOS 给了"系统即代码"的范式革命。
> 你选的是最前沿但也最需要学习的那条路——这套笔记就是为此写的。
