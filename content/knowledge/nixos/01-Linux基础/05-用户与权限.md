# 05 · 用户与权限

> 上一篇：[[04-Shell与终端基本功]] · 下一篇：[[06-进程与systemd服务]]

## 1. 用户模型：三层的简单世界

```
root（uid 0）      ← 超级管理员，无所不能（≈ SYSTEM）
loysan（uid 1000） ← 你，普通用户（≈ 标准用户）
系统用户           ← 给服务用的傀儡账户（systemd-*、nixbld* 等）
```

看你的信息：
```bash
id                # uid/gid/所属组
whoami            # 当前用户
```

每个文件都记在`/etc/passwd`（用户列表，无密码！）和
`/etc/shadow`（密码哈希，只有 root 能读）里。
你的 NixOS 配置里用户是**声明出来**的（configuration.nix 的 users.users.loysan）。

## 2. 用户组：权限的"团购"

组 = 给一批用户集体授权。你在的组（configuration.nix 里声明的）：

| 组 | 给你什么能力 |
|---|---|
| `wheel` | 能用 **sudo**（最重要） |
| `networkmanager` | 改网络设置不用 sudo |
| `video` | 调亮度/访问显示设备 |
| `input` | 读输入设备（某些工具需要） |
| `audio` | 音频设备访问 |

改组后要**重新登录**才生效（组关系在登录时建立）。

## 3. 文件权限：rwx 九宫格

```bash
$ lsd -l ~/.local/bin/screenshot-ocr
.rwxr-xr--  loysan  users  1.2k  screenshot-ocr
└┬┘└┬┘└┬┘
 │  │  └─ 其他人（others）：r-- 只读
 │  └──── 属组（group users）：r-x 读+执行
 └─────── 属主（owner loysan）：rwx 读写执行
```

- **r**ead（4）：读文件内容/列目录
- **w**rite（2）：改文件/在目录里增删文件
- **x**ecute（1）：执行文件/**进入**目录（目录的 x = 能 cd 进去）

第一位字符：`-` 普通文件、`d` 目录、`l` 符号链接。

## 4. chmod / chown：改权限

```bash
chmod +x 脚本.sh        # 加执行权限（下完脚本第一步）
chmod 755 文件          # rwxr-xr-x（数字法：r=4 w=2 x=1 相加）
chmod 600 ~/.ssh/key    # 只有自己能读写（密钥必须这样）
chown loysan:users 文件  # 改属主（要 sudo 改别人的）
sudo chown -R loysan:users 目录/  # 递归改（修复"root 建的文件"常用）
```

**最常见新手问题**：脚本"Permission denied" → 九成是没 `chmod +x`。

## 5. sudo：临时当管理员

```bash
sudo 命令          # 以 root 执行（输你自己的密码）
sudo -i           # 切到 root shell（尽量别长待）
sudo !!           # sudo 重跑上一条命令（忘了加 sudo 时）
sudo -u 用户名 命令  # 以其他用户身份跑
```

- sudo 密码默认**缓存几分钟**，期间不重复问
- 输密码时屏幕**什么都不显示**（连星号都没有）——不是卡了，照常输完回车
- NixOS 的 sudo 配置也能声明：`security.sudo.*`

## 6. 什么时候真的需要 sudo（判断准则）

| 操作 | 需要 sudo？ |
|---|---|
| 改 ~/nixos-config 里的文件 | ❌（家目录是你的） |
| `nixos-rebuild switch` | ✅（要激活系统配置、切 /run/current-system） |
| `nixos-rebuild build` | ❌（只构建不激活） |
| 装/删软件（改 packages.nix） | 编辑❌ / switch✅ |
| 改 /etc、/var | ✅ |
| `systemctl restart xxx` | ✅（系统服务） |
| `systemctl --user restart xxx` | ❌（用户服务） |
| 杀掉别人的进程 | ✅（杀自己的不用） |

## 7. polkit：图形界的 sudo

GUI 程序需要提权时（比如改系统设置）不弹终端密码框，而是 **polkit** 认证弹窗。
niri 这类合成器不自带认证 agent，你的配置里专门起了
`lxqt-policykit-agent`（modules/security.nix）——所以设置类 GUI 弹密码框正常。

## 8. SSH 密钥（比密码好用的身份认证）

你的系统开着 SSH 服务（modules/security.nix）。
- 服务端：`services.openssh.enable = true`（已开）
- 客户端：系统自带 `ssh` 命令（替代 Windows 的 PuTTY）
- 密钥对：`ssh-keygen -t ed25519` 生成（存 ~/.ssh/），
  公钥拷到服务器后免密登录。比 PuTTYgen/Pageant 简单。
- 密钥管理 GUI：seahorse（已装，配合 gnome-keyring）

## 9. 一句话总结

> root 是"房东"，你是"租户"，wheel 组给了你"物业电话"（sudo）。
> 文件权限九宫格决定谁能碰什么；组是批量授权。
> 日常原则：能用用户身份干的，绝不动用 sudo。
