# 模糊查找与目录跳转:fzf / yazi / zoxide

> [!info] 本页内容
> fzf 为什么是"万能粘合剂"?yazi 和 ranger 是什么?
> `cd` 有什么可改进的?zoxide 怎么做到"按记忆跳目录"。

## 一、fzf(2014):把"选择"变成通用能力

### 问题
传统管道只能"输出",不能"选择":

```
ls                       ← 输出列表,你看,然后手动敲名字
```

### fzf 的答案:管道中间的交互选择器

```
fd -e md | fzf           ← 列出 .md 文件,模糊输入过滤,回车选中
```

- **模糊匹配**:输入 `lsp` 能匹配 `LSP与Treesitter.md`(子串/跳字匹配)
- **交互预览**:选中项旁边实时显示内容(`--preview 'bat {}'`)
- **通用性**:不挑输入——文件列表、历史命令、git 分支,什么都能喂给它

**为什么叫"万能粘合剂"**:它填补了 Unix 管道哲学缺失的一环——**交互**。传统管道是"自动流水线",fzf 是"流水线上的人工选择站"。

### 经典组合(你配置里已装)

```bash
# 目录跳转:搜索目录并进入
cd $(fd -t d | fzf)

# 打开文件:搜索文件并 nvim
nvim $(fd -e nix | fzf)

# 历史命令搜索(Ctrl+r 增强版)
history | fzf

# 终端内已配:你的 Ctrl+r 就是 fzf 版历史搜索
```

> [!tip] fzf 的"插件化"用法
> fzf 还能嵌进别的工具:zoxide 用它选目录、tmux 用它切会话、
> nvim 的 telescope 核心交互也是模糊匹配。学会 fzf = 学会所有模糊交互。

## 二、目录跳转:cd → zoxide(2020)

### cd 的痛点
只能"当前位置相对移动":想去常用目录要 `cd ~/nixos-config/notes/knowledge/nixos/05-操作进化历程/04-文件与搜索` 这种长路径,或记一堆别名。

### zoxide:按使用频率"智能跳转"

```
z 教程          ← 直接跳到常用路径里含"教程"的那个
z nixos         ← 跳到 nixos-config
zi              ← 交互模式(fzf 列表选)
```

原理:zoxide 记录你 `cd` 过的目录,按**频率 + 最近**排序,"z 关键词"匹配排名靠前的目录。

| | cd | zoxide |
|---|---|---|
| 状态 | 无记忆 | 记忆 + 学习 |
| 跳转 | 相对路径 | `z 关键词` 智能匹配 |
| 交互 | 无 | `zi` 走 fzf |
| 兼容 | — | 注册为 `cd` 的 shell 函数,无缝替换 |

## 三、文件管理:ranger(2009)→ yazi(2023)

终端文件管理器——把"上下左右选文件"做成 TUI 界面:

| | ranger | yazi |
|---|---|---|
| 语言 | Python | Rust |
| 界面 | 三栏(目录/文件/预览) | 单栏 + 浮层预览 |
| 速度 | 一般 | 快(异步预览) |
| 特色 | 老牌成熟 | 现代:预览图片/视频、插件、vim 键位 |
| 现状 | 维护放缓 | **现役新贵**(2024 后社区快速增长) |

**yazi 你已装**,基本用法:

```
yazi                ← 打开(在 kitty 里)
h/l                 左/右进目录
↑/↓ 或 j/k         选择
Enter               进入/打开
空格                多选
Ctrl+a              全选
:rename             重命名
```

> [!tip] yazi 与 nvim 的配合
> yazi 里按 `o` 用 nvim 打开当前文件;`ya` 支持在 nvim 里 `:Yazi` 直接调出文件选择。

## 四、一页生态图

```
找文件名    fd →(列表)→ fzf →(选择)→ nvim/bat
搜内容      rg →(列表)→ fzf →(选择)→ 跳转
跳目录      zoxide(z 关键词 / zi 交互)
管文件      yazi(TUI 文件管理器)
```

**现代文件操作心智**:不再"记得路径",而是"模糊描述 + 交互选择"。

> [!tip] 记忆法
> - `fd`/`rg` 负责**找**(输出候选)
> - `fzf` 负责**选**(交互确认)
> - `zoxide` 负责**跳**(记住去哪)
> - `yazi` 负责**管**(浏览/重命名/批量)
> 四件套 = 现代版的 find/grep/cd/ls。
