# 00 补充练习 · 实操教学

> [!info] 本节说明
> 本章是前面章节的"综合练兵场":10 组练习,把移动、块操作、正则、宏、外部命令组合起来用。
> 练习文件编号是 1000+ 的补充分组号,文档按主题重新编号为 1-10。每组是一道综合题,含 2-5 步。
> 每道题的流程:
> 1. 在 kitty 终端 `cd` 进目录,用 `nvim` 打开对应的练习文件
> 2. 看题目要求,在文件上动手操作,达成目标状态
> 3. 对照"目标状态"验收,卡住时点题末链接查看解法(解答.md)
> 4. 打勾检验清单。练完可随时重开文件(初始状态不变)
>
> 所有解法只用 nvim 内置命令,不依赖插件(题 1 的 `<leader>` 键位需要你已装的 telescope)。

## 题 1:移动键位速查(4 关指法练习)

> [!info] 这组不是改文本
> 4 个练习文件是"速查卡":每个文件写着一组要练的键位。打开后对着文件里的文字逐个操练,练熟一关再进下一关。文件本身不需要改动。

### 关卡 1:横向移动

**打开文件**:

```bash
cd ~/nixos-config/notes/knowledge/nvim/00-补充练习
nvim 练习/1008-补充练习 9.txt
```

文件内容:`hl, ftFT, webWEB, 0^$`

| 键 | 作用 |
|---|---|
| `h` `l` | 左 / 右移动一个字符 |
| `f` + 字符 | 跳到本行下一个该字符(如 `ft` 找下一个 t) |
| `F` + 字符 | 向前(左)找字符 |
| `t` + 字符 | 跳到该字符前一个位置(till,不落在字符上) |
| `T` + 字符 | 向前 till |
| `w` `e` `b` | 按词前进 / 跳到词尾 / 回词首 |
| `W` `E` `B` | 按 WORD(只看空格)前进 / 词尾 / 词首 |
| `0` `^` `$` | 行首 / 行首第一个非空字符 / 行尾 |

练习:光标从行首走到行尾再走回来,每行练几遍,直到不需要思考。

### 关卡 3:查找跳跃

**打开文件**:

```bash
cd ~/nixos-config/notes/knowledge/nvim/00-补充练习
nvim 练习/1010-补充练习 11.txt
```

文件内容:`ftFT, /?nN, *, #, %` 和 `<leader><leader>, <leader>sw, <leader>sg`

| 键 | 作用 |
|---|---|
| `f` / `F` / `t` / `T` | 行内找字符(关卡 1 复习);`;` 重复上一次 f/t |
| `/` `?` | 向后 / 向前搜索,输入内容回车 |
| `n` `N` | 下一个 / 上一个匹配 |
| `*` `#` | 搜索光标下的单词,向后 / 向前 |
| `%` | 跳到配对的括号(`(` `)` `{` `}` `[` `]`) |

| 键 | 作用(以你的配置为准,`:map <leader>` 可查) |
|---|---|
| `<leader><leader>` | 快速找文件(常见配置绑定 telescope find_files) |
| `<leader>sw` | 搜索光标下的单词 |
| `<leader>sg` | 全局搜索字符串 |

> [!tip] 关于 `<leader>`
> 多数配置里 `<leader>` 是空格。这行键位依赖你已装的 telescope,如果你的映射不同,用 `:map <leader>` 查一下实际绑定。

### 关卡 4:标记跳跃


| 键 | 作用 |
|---|---|
