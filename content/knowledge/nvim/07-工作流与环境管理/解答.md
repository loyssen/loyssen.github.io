## 题 102:在多个 Buffer 之间快速切换

**操作解法(按键)**:

```
Ctrl-^      在最近两个 buffer 之间来回切(切到 # 标记的那个)
```

**命令解法**:

```vim
" 打开/新建文件,形成 4 个 buffer
:e README.md
:e main.js
:e test.js
:e temp.txt

" 查看 buffer 列表(编号 + 文件名 + 标记)
:ls

" 按编号跳 / 按名字跳
:b 3
:b main.js

" 下一个 / 上一个
:bnext
:bprev
```

| 命令 | 作用 |
|---|---|
| `:e 文件` | 打开文件,新增一个 buffer |
| `:ls` | 列出所有 buffer(编号、文件名、状态标记) |
| `:b 3` / `:b main.js` | 按编号或名字直接跳转 |
| `:bnext` / `:bprev` | 切到下一个 / 上一个 buffer |
| `Ctrl-^` | 切到轮换 buffer(`#` 标记,最近访问的那个) |

## 题 103:关闭和删除 Buffer

> [!note] 本质命令题
> Buffer 管理是 Ex 命令的领域,`:bd` 全家没有按键对应物。

**命令解法**:按场景逐步操作:

```vim
:ls            " 观察 4 个 buffer 和标记(% 当前、+ 已修改)

:b 2           " 切到 main.js
:w             " 保存修改

:b 4           " 切到 temp.txt
:bd            " 直接关闭(没修改过,无需确认)

:b 3           " 切到 test.js
:bd!           " 强制关闭,丢弃未保存更改

:ls            " 确认只剩 README.md
```

| 命令 | 作用 |
|---|---|
| `:bd` | 删除(关闭)当前 buffer;有未保存修改时会拒绝 |
| `:bd 编号` | 按编号删除指定 buffer |
| `:bd!` | 强制关闭,丢弃未保存的修改 |
| `:w` | 保存当前 buffer |
| `:ls` 的 `%`/`+` | `%` = 当前窗口的 buffer,`+` = 已修改未保存 |

> [!warning] 别误伤修改
> `:bd` 遇到未保存修改会报错停下(E89:No write since last change),这是保护机制。确认要放弃修改才用 `:bd!`。

## 题 105:Buffer 重命名和保存

> [!note] 本质命令题
> 改名走 `:saveas`,按键没有对应物。

**命令解法**:

```vim
" 另存为新名字(当前 buffer 自动挂到新文件上)
:saveas draft-final.md

" 关闭旧文件的 buffer(# 指上一个访问的 buffer)
:bd #

" 确认 buffer 列表
:ls
```

| 命令 | 作用 |
|---|---|
| `:saveas 新名` | 另存为:内容写入新文件,当前 buffer 改挂新文件,旧文件内容不变 |
| `:bd #` | 删除轮换 buffer(刚被替换掉的旧文件 buffer) |
| `#` | 特殊 buffer 标记:上一个访问的 buffer |

> [!tip] `:saveas` 和 `:w 新名` 的区别
> `:saveas` 之后当前 buffer 就关联新文件了(继续编辑写新文件);`:w 新名` 只是"导出"一份,当前 buffer 还是旧文件。

## 题 106:分割窗口中的 Buffer 操作

**操作解法(按键)**:

```
Ctrl+w w      循环跳到下一个窗口
Ctrl+w h / l  跳到左 / 右窗口
Ctrl+w c      关闭当前窗口(只关窗口,不删 buffer)
```

**命令解法**:

```vim
" 打开第一个文件,再垂直分屏打开第二个
:e README.md
:vsplit main.js

" 再水平分屏打开空 buffer
:split

" 在当前窗口显示编号 3 的 buffer
:b 3
```

| 命令 | 作用 |
|---|---|
| `:split 文件` / `:vsplit 文件` | 水平 / 垂直分屏并打开文件 |
| `:new` | 水平分屏 + 新建空 buffer |
| `Ctrl+w w` | 在窗口间循环跳转 |
| `Ctrl+w h/j/k/l` | 按方向跳到指定窗口 |
| `Ctrl+w c` | 关闭当前窗口,里面的 buffer 只是隐藏,不删除 |

## 题 107:Buffer 列表过滤和查找

> [!note] 本质命令题
> 过滤列表只能走命令,按键没有对应物。

**命令解法**:

```vim
" 一次打开一批文件,模拟 20+ 场景
:args 练习/*.txt

" 只看 .js 文件
:filter /\.js/ ls

" 只看名字带 test 的
:filter /test/ ls

" 只显示已修改未保存的 buffer(逐个打印文件名)
:bufdo if &modified | echo expand('%') | endif

" 或者用 telescope 在 buffer 里模糊搜索
:Telescope buffers
```

| 部分 | 作用 |
|---|---|
| `:args 通配符` | 用通配符一次打开多个文件(每个都是 buffer) |
| `:filter /正则/ ls` | 只显示匹配正则的 buffer(原生过滤,不用管道) |
| `/\.js/` | 转义点号,匹配扩展名 `.js` |
| `:bufdo if &modified | echo ...` | 逐个 buffer 检查修改标记,打印已修改的文件名 |
| `:Telescope buffers` | telescope 的 buffer 列表模糊搜索 |

> [!warning] 本机实测修正
> 原题的 `:filter /\+/ ls` 在本机(nvim 0.11.7)会报 `E866: (NFA regexp) Misplaced +`;而且 `:filter` 只匹配 buffer 的文件名部分,`+` 这种标记列匹配不到。找"已修改"的 buffer 用上面的 `:bufdo` 一行,或直接看 `:ls` 输出的 `+` 列。

> [!warning] 为什么不用 `:ls | grep`
> Vim 命令行的 `|` 是命令分隔符,不是 shell 管道。过滤 `:ls` 输出要用 `:filter`。

## 题 108:隐藏和未列出的 Buffer

> [!note] 本质命令题
> 标记和行为都靠命令观察。

**命令解法**:

```vim
" 打开两个文件,当前窗口一个,另一个分屏或切走
:e a.txt
:vsplit b.txt
:ls              " 当前窗口 buffer 标 %,另一个标 a

" 隐藏当前 buffer:窗口让给别的 buffer,它保留加载
:hide
:ls              " 被隐藏的 buffer 标记变 h

" 打开帮助(未列出的 buffer)
:help
:ls              " 列表里没有 help
:ls!             " 出现带 u 标记的 help buffer
```

**`:ls` 标记对照表**:

| 标记 | 含义 |
|---|---|
| `%` | 当前窗口中的 buffer |
| `#` | 轮换 buffer(`Ctrl-^` 切换到的那个) |
| `a` | 激活:已加载且显示在窗口里 |
| `h` | 隐藏:已加载但不在任何窗口显示 |
| `u` | 未列出:不出现在普通列表(help、quickfix 等) |
| `+` | 已修改未保存 |
| `=` | 只读 |

| 命令 | 作用 |
|---|---|
| `:ls` | 只显示普通 buffer 列表 |
| `:ls!` | 连同未列出 buffer 一起显示 |
| `:hide` | 把当前 buffer 藏起来(不卸载,窗口切换到别的 buffer) |

> 记忆口诀:当前 `%`、轮换 `#`、激活 `a`、隐藏 `h`、未列 `u`、修改 `+`、只读 `=`。

## 题 109:会话管理

> [!note] 本质命令题
> 会话的存与取都靠命令。

**命令解法**:

```vim
" 1. 打开文件,排好布局
:e README.md
:vsplit main.js

" 2. 保存会话(首次)
:mksession ~/.nvim-sessions/work.vim

" 3. 退出 nvim,下次启动时恢复
:q
```

```bash
# 4. 用会话文件启动 nvim
nvim -S ~/.nvim-sessions/work.vim
```

```vim
" 或者不退出,直接在 nvim 里恢复
:source ~/.nvim-sessions/work.vim

" 修改布局后覆盖保存
:mks!
```

| 命令 | 作用 |
|---|---|
| `:mksession 文件` | 把当前窗口布局、buffer、光标位置保存成会话脚本 |
| `:mks!` | 覆盖保存(不带 `!` 遇到已有文件会拒绝) |
| `nvim -S 文件` | 启动 nvim 时加载会话 |
| `:source 文件` | 在当前 nvim 里执行会话脚本,恢复环境 |

> [!tip] 会话文件就是 vim 脚本
> 用 nvim 打开会话文件看看,里面就是 `:edit`、`:vsplit` 之类的命令,可读可改。

## 题 110:Buffer 批量操作

> [!note] 本质命令题
> 批量 = `:bufdo`,纯按键逐 buffer 做不现实。

**命令解法**:

```vim
" 在所有 buffer 中替换
:bufdo %s/oldVarName/newVarName/ge

" 在每个 .js buffer 开头插入版权头
:bufdo if expand('%:e') == 'js' | call append(0, ['/*', ' * Copyright 2024', ' * Licensed under MIT', ' */', '']) | endif

" 删除所有 buffer 行尾空格并保存
:bufdo %s/\s\+$//e | update

" 保存所有已修改的 buffer
:bufdo if &modified | write | endif
```

| 部分 | 作用 |
|---|---|
| `:bufdo 命令` | 对 buffer 列表里的每一个依次执行命令 |
| `e` 标志 | 出错不中断(某 buffer 没有匹配也不报错停下) |
| `expand('%:e')` | 当前 buffer 的扩展名(`js` / `md` …) |
| `call append(0, [...])` | 在第 0 行(文件开头)之前插入多行 |
| `\|` | 命令分隔符,一行里串联多条命令 |
| `update` | 只在 buffer 被修改过时才写入 |
| `&modified` | 当前 buffer 是否被修改的标志 |

> [!warning] 先小范围试
> `:bufdo` 会扫过所有 buffer,不想要的 buffer 先 `:bd` 掉再批量,免得误伤。

## 题 111:在 Neovim 中创建新文件

**命令解法**:三种方式:

```bash
# 方式一:启动时直接打开不存在的文件
nvim 练习/新建笔记.md
```

```vim
" 方式二:在 nvim 里打开新路径
:e 练习/另一个文件.txt
i这是新文件的内容<Esc>
:w

" 方式三:无名空 buffer,命名保存
:enew
:w 练习/scratch.log
```

| 命令 | 作用 |
|---|---|
| `nvim 新路径` | 启动即进入已关联路径的 buffer,`:w` 即创建 |
| `:e 路径` | 打开新路径(不存在也能开,`:w` 时才落盘) |
| `:enew` | 新建一个没有名字的空 buffer |
| `:w` / `:w 路径` | 保存当前 buffer / 按指定路径保存 |

> 关键认知:新建 buffer 不等于磁盘上有文件,`:w` 之前不会落盘。

## 题 112:文件重命名

> [!note] 本质命令题
> 重命名 = 另存 + 关 buffer + 删旧文件,三步都是命令。

**命令解法**:

```vim
" 1. 另存为新名字(当前 buffer 切换成新文件)

" 2. 关闭旧文件的 buffer
:bd #

" 3. 删除磁盘上的旧文件
```

| 命令 | 作用 |
|---|---|
| `:saveas 新名` | 用新名字保存,当前 buffer 改挂新文件 |
| `:bd #` | 删除轮换 buffer(旧文件的那个) |
| `#` | 上一个访问的 buffer |
| `:!rm 文件` | 执行外部 shell 命令删除文件 |

## 题 114:文件移动

**命令解法**:两种思路:

```vim
" 方法一:另存 + 关旧 buffer + shell 移动
:saveas lib/utils.js
:bd #
:!mv src/utils.js lib/utils.js

" 方法二:shell 直接移动,再打开新路径
:!mv src/utils.js lib/utils.js
:e lib/utils.js
```

| 命令 | 作用 |
|---|---|
| `:saveas 新路径` | 把内容写到新路径,buffer 换挂 |
| `:bd #` | 关闭旧路径的 buffer |
| `:!mv 旧 新` | shell 移动文件(改路径不复制) |
| `:e 新路径` | 打开移动后的文件 |

> [!warning] 和重命名的区别
> 重命名是"名字变了、位置没变",移动是"路径变了"。手法完全一样:saveas + bd + mv,只是 `mv` 的目标不同。

## 题 115:目录操作

```vim
" 查看当前工作目录
:pwd
```

| `:lcd 目录` | 只切换当前窗口的工作目录 |
| `:e .` | 以目录模式打开当前目录(装了 oil 就用 oil) |

## 题 117:批量文件操作

**命令解法**:

```vim
" 批量把 .txt 改成 .md
:!for f in *.txt; do mv "$f" "${f%.txt}.md"; done

" 创建目录和文件结构
:!mkdir -p components
:!touch components/Header.js components/Footer.js components/Sidebar.js
```

| 部分 | 作用 |
|---|---|
| `:!` | 把后面的内容交给 shell 执行 |
| `for f in *.txt; do …; done` | shell 循环,遍历所有 txt 文件 |
| `"${f%.txt}.md"` | 参数展开:去掉 `.txt` 后缀再拼 `.md` |
| `mkdir -p` | 建目录(已存在不报错) |
| `touch 文件` | 创建空文件 |

## 题 119:文件复制

**命令解法**:

```vim
" 打开要备份的文件
:e config.js

" 方式一:shell 复制一份备份
:!cp config.js config.backup.js

" 方式二:另存为副本,继续在副本上编辑
:saveas config.copy.js
:bd #
```

| 命令 | 作用 |
|---|---|
| `:!cp 源 目标` | shell 复制文件(磁盘上多一份) |
| `:saveas 新名` | 另存一份,当前 buffer 挂到新文件上继续编辑 |
| `:bd #` | 关闭原文件 buffer |

> `cp` 只动磁盘,`:saveas` 把编辑目标切到副本——两种"备份"的差别就在这。

## 题 121:文件搜索和打开

**操作解法(按键)**(telescope,已装):

```
<leader>ff     弹出搜索框,输入关键词回车打开
```

**命令解法**:

```vim
" 原生 :find:按名字在 path 里找(支持 Tab 补全)
:find Header.js

" :e 时按 Tab 补全路径
:e src/co<Tab>
```

| 命令 | 作用 |
|---|---|
| `<leader>ff` | telescope find_files:项目内模糊搜索文件名 |

> `path` 里包含的目录越多,`:find` 能"省略"的路径前缀越多。项目根目录通常已在 path 里。

## 题 123:文件编码和格式

**命令解法**:

```vim
" 查看当前编码和行尾格式
:set fileencoding?
:set fileformat?

" 另存为 UTF-8
:set fileencoding=utf-8
:w

" 行尾转 LF(unix)或 CRLF(dos)
:set fileformat=unix
:w

" 打开时强制按某编码解码(乱码时的兜底)
:e ++enc=utf-8 %
```

| 选项 | 作用 |
|---|---|
| `fileencoding` | 当前 buffer 写入磁盘时用的编码(显示 `?` 查看) |
| `fileencodings` | 打开文件时按顺序尝试的编码列表(探测顺序) |
| `fileformat` | 行尾格式:`unix`(LF)/ `dos`(CRLF)/ `mac`(CR) |
| `++enc=utf-8` | 打开时强制按指定编码解码,忽略探测结果 |

> [!warning] 改编码要 `:w` 才落盘
> `:set fileencoding=utf-8` 只是改设置,执行 `:w` 后文件才按新编码写盘。
