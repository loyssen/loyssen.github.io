# Neovim 实操教程 · 索引

> [!info] 这是啥
> 基于 [neovim-practise-101](https://github.com/wsgggws/neovim-practise-101)(181 道实战练习题)落地的实操教程。
> 每章一个文件夹:**教学.md**(打开命令 + 要求 + 目标状态 + 检验清单,题末链接查看解法)+ **解答.md**(独立解法:操作解法优先 + 命令解法 + 解析)+ **练习/** 初始状态文件。
> 练习文件可以反复重开,随时重置。

## 怎么学

1. 从 **01 章**开始,一章一章往后
2. 每道题:先在 kitty 终端 `cd` 进章目录 → `nvim 练习/xxx.txt` → 按教学.md 的要求动手
3. 达成目标状态后,对照"参考解法"对比思路,打勾检验清单
4. 全部勾完进入下一章

> [!tip] 配套工具
> - nvim 里按 `<Space>ck` 打开快捷键速查窗
> - `<Space>?` 打开 legendry 图鉴(全量键位,可搜索)
