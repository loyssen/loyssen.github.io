## 题 166:范围操作符

> [!note] 本质命令题
> 范围是 Ex 命令专属的写法,键盘上没有对应操作。

**命令解法**:

```vim
:2,4d
:1,3s/line/LINE/g
:3m0
:1,5normal A!
```

| 部分 | 作用 |
|---|---|
| `:2,4d` | 数字范围:对第 2、3、4 行执行 `d`(**边界包含!**) |
| `:%` | 整个文件,等价 `:1,$`(最常用) |
| `:.` / `:$` | 当前行 / 最后一行 |
| `:.,+2d` | 相对范围:当前行到下两行 |
| `:3m0` | 把第 3 行 `m`(move)到第 0 行(文件开头之前) |
| `:1,5normal A!` | 对范围内每一行执行普通模式命令 `A!`(行尾插入 `!`) |

> 记忆:范围 = "第 A 行到第 B 行,两边都算"。`%` 是 `1,$` 的快捷键,
> 几乎所有替换题都会见到 `:%s`。

## 题 167:全局命令 (global)

> [!note] 本质命令题
> "按内容选行"是 `:g` 的专属能力,行号不可靠时只能靠它。

**命令解法**:

```vim
:g/console\.log/d
```

只匹配 Debug 更短也行:`:g/Debug/d`。

| 部分 | 作用 |
|---|---|
| `:g` | global 全局命令:对"匹配的每一行"执行后面的命令 |
| `console\.log` | 匹配模式,`\.` 转义点号(不转义则 `.` 匹配任意字符,效果一样但不够严谨) |
| `d` | 删除 |

> [!tip] 理解 `:g` 的执行模型
> `:g/{模式}/{命令}` = "找出所有匹配的行,依次对它们执行命令"。它和
> `:%s` 不同:`:s` 只做替换,`:g` 可以执行任意命令(`d` 删除、`m` 移动、
> `normal` 批量操作…)。题 180、题 3 还会用到。

## 题 168:反向全局命令 (vglobal)

> [!note] 本质命令题
> "删掉不匹配的行"用 `:v` 一行,反着写 `:g` 也可以但没必要。

**命令解法**:

```vim
:v/^\/\//d
```

也可以写成 `:g!/^\/\//d`(`v` 就是 `g!` 的别名)。

| 部分 | 作用 |
|---|---|
| `:v` | 反向全局:对"不匹配"的行执行命令(`v` = vglobal,等价 `:g!`) |
| `^` | 行首锚点 |
| `\/\/` | 转义的斜杠(模式里的 `/` 必须写成 `\/`) |
| `d` | 删除 |

> 记忆:`:v` = "v 掉不想要的"——匹配"不想要的行"再删,比想"想要的行的命令"快。

## 题 169:组合命令

> [!note] 本质命令题
> `|` 串联是命令行的核心语法,按键无法一次做完多个动作。

**命令解法**:

```vim
:put ='foo baz'
:%s/foo/bar/g | %s/baz/qux/g | w
```

| 部分 | 作用 |
|---|---|
| `\|` | 管道:一行里依次执行多个命令,前一个出错则中断 |
| `:put ='foo baz'` | `put =` 表达式:把表达式结果作为一行插入(本题用来造内容) |
| `:%s/foo/bar/g` | 第一个替换 |
| `w` | 保存(组合命令的收尾常用) |

> [!warning] 实测确认的坑
> 1. `:5,10d | normal gg` 在 1 行文件上执行:第 5-10 行不存在,报
>    `E16: 无效的范围`,后面的 `normal gg` **不会执行**——这正是 `|`
>    的特性:前面出错,后面中断。
> 2. 替换命令里如果要匹配 `|` 字符本身,必须写 `\|`
>    (如 `:%s/a\|b/x/g`),否则会被当成命令分隔符。
> 3. `:put` 会把光标移到插入的那一行(后面题 172、175 的循环依赖这个行为)。

## 题 170:命令行窗口

**操作解法(按键)**:

```
q:          打开命令行窗口(里面是按时间倒序的 : 历史)
j/k         在历史里上下找
改一改      窗口是普通缓冲区,随便编辑
Enter       执行光标所在行的命令
/date       窗口内搜索历史命令
:q          关闭窗口
q/          打开"搜索历史"窗口
<C-f>       在命令行输入中按,直接切换到命令行窗口
```

**命令解法(设置)**:`:set history=100` —— 控制保存多少条历史(默认 50,调大更耐用)。

> 先在普通文件里敲几条命令(`:set number`、`:s/用/Vim/`、`:!date`)
> 制造历史,再按 `q:` 就能看到它们。

## 题 171:子命令和管道

> [!note] 本质命令题
> 调外部命令只能走命令行,这是 Ex 命令的独有领域。

**命令解法**:

```vim
:%!uniq      " 全文件去重(只去相邻重复)
:1,4!sort    " 只排序前 4 行
:%d          " 清空(练习文件里有题头,不删 jq 会失败)
:put ='{\"name\": \"nvim\"}'   " 造 JSON 行(双引号转义)
:1d          " 空文件上 put 留空首行,删掉
:%!jq .      " 格式化 JSON
```

| 部分 | 作用 |
|---|---|
| `:!cmd` | 执行外部命令(不改变缓冲区,如 `:!ls`) |
| `:A,B!cmd` | 过滤器:把范围内的行送入 `cmd`,输出替换原内容 |
| `:%!uniq` | 全文件过滤。注意 `uniq` 只去**相邻**重复,`b a b` 不会变 |
| `:%!jq .` | 用 jq 格式化 JSON(`.` 表示"原样输出"逻辑) |

> [!tip] 过滤器是最快的"用系统工具改文本"方式
> 排序、去重、格式化、管道给 `grep`/`awk` 都走 `:!`。想要"去全部重复"
> 先 sort 再 uniq:`:%!sort | uniq`。
>
> 实测:`:%!jq .` 要求整个文件都是合法 JSON——文件里混着其他文本会直接
> 报错(题 171、177 都会因此先 `:%d` 清空文件再造 JSON 行)。

## 题 172:读取和写入命令

> [!note] 本质命令题
> `:r`/`:w` 读写是命令行的能力,键盘没有对应物。

**命令解法**:

```vim
:r !date
:for i in range(1, 12) | put =i | endfor
:12,14w partial.txt
:r partial.txt
```

| 部分 | 作用 |
|---|---|
| `:r !cmd` | 执行外部命令并读取输出到光标行之后(`!` 表示后面是命令) |
| `:r 文件` | 读取文件内容到光标行之后(没有 `!` 就是读文件) |
| `:A,Bw 文件` | 把范围内的行写入新文件(不写全文件) |
| `:w >> 文件` | 追加写入(不覆盖已有内容) |

> [!warning] 实测确认:为什么写 `:12,14w` 而不是 `:10,12w`
> 执行完 `:for i in range(1, 12) | put =i | endfor` 后,文件共 14 行:
>
> ```text
> 1  :r !date          ← 题头
> 2  (date 输出)       ← :r !date 插进来的
> 3  1                 ← 循环从第 3 行开始
> ...
> 13 11
> 14 12
> ```
>
> 因为 `:r` 和 `:put` 都会把**光标移到插入的内容上**,循环里的每次
> `put` 都追加在上一行之后,1..12 是**正序**堆叠——但前面多占了
> 2 行(题头 + 日期),所以值 `10`、`11`、`12` 落在第 12、13、14 行。
> 写范围前先数清行号,这是范围操作的基本功。
>
> 想插到文件头用 `:0r 文件`(0 行 = 开头之前)。

## 题 173:寄存器操作

**操作解法(按键)** — 关键在 `<C-r>` 插入:

```
:s/           敲 :s/ 后
<C-r>a        按 Ctrl+r 再按 a:寄存器 a 的内容粘贴进命令行
/             再敲 /
<C-r>b        按 Ctrl+r 再按 b:寄存器 b 的内容粘贴进来
/g            回车执行
```

注意 `<C-r>` 是 **Ctrl+r**,不是字面量 `<C-r>a`——在命令行里按
`Ctrl+r` 再按 `a`,`some text` 会真的出现在命令行里。

**命令解法**:

```vim
:let @a = 'some text'
:let @b = 'other text'
:reg a b
:put =@a
:s/<C-r>a/<C-r>b/g
```

| 部分 | 作用 |
|---|---|
| `:let @a = 'some text'` | 给寄存器 a 赋值(等号两侧空格可有可无) |
| `<C-r>a` | 在命令行里插入寄存器 a 的内容 |
| `:reg a b` | 查看寄存器内容 |
| `:put =@a` | 把寄存器内容作为文本写入当前行之后 |
| `:@a` | 把寄存器内容当 Ex 命令执行(寄存器里存命令时用) |

> 把命令存进寄存器再 `:@a` 执行,是题 178 的核心,一起练。

## 题 174:条件命令

> [!note] 本质命令题
> `:if` 是 Vim script 的控制结构,键盘没有对应物。

**命令解法**:

```vim
" 一行版(推荐,不易漏 endif)
:if !isdirectory('backup') | call mkdir('backup') | endif
" C# 场景:文件类型是 cs 时缩进改为 4
:if &filetype == 'cs' | set shiftwidth=4 | endif
" 交互式多行版:回车后提示符保持,输完 endif 才执行
:if !isdirectory('backup')
:  !mkdir backup
:endif
```

清理(外部命令不可撤销):`:!rmdir backup`。

| 部分 | 作用 |
|---|---|
| `:if 条件` | 条件为真(非 0)才执行到 `:endif` |
| `!isdirectory('backup')` | `!` 取反,`isdirectory()` 判断目录是否存在 |
| `call mkdir('backup')` | Vim 内置函数建目录(不经过 shell) |
| `&filetype` | 当前文件类型选项,`&` 前缀表示"选项的值" |
| `search('pattern')` | 找到返回行号(非 0 即真),找不到返回 0,可直接当条件 |
| `\|` | 一行版把 `:if`/`endif` 串起来,避免多行输入 |

> [!warning] 实测确认的坑
> 别写 `:if ... | !mkdir ... | endif`——`!` 命令会把 `|` 之后的
> **所有内容**交给 shell(包括 `endif`),bash 会报
> `endif: 未找到命令`,`:if` 也永远等不到 `:endif`。目录操作改用
> 内置函数 `call mkdir('backup')` 就干净了。
>
> 本机 nvim 没有 `rmdir()` 函数(E117),删目录用外部命令
> `:!rmdir backup`。

## 题 175:循环命令

> [!note] 本质命令题
> 批量生成内容就是 `:for` 循环的活,手工一行行敲没有意义。

**命令解法**:

```vim
:%d
:for i in range(1, 10) | put ='Item ' . i | endfor
:1d
```

遍历列表版:

```vim
:%d
:for item in ['apple', 'banana', 'cherry'] | put =item | endfor
:1d
```

| 部分 | 作用 |
|---|---|
| `:for 变量 in 集合` | 循环,依次把集合元素赋给变量,`endfor` 结束 |
| `range(1, 10)` | 生成 1 到 10 的序列(含边界;第三个参数是步长,`range(1, 10, 2)` = 1,3,5,7,9) |
| `put =表达式` | `=` 开头表示"写入表达式的值";`'Item ' . i` 是字符串连接 |
| `\|` | 一行版循环:`for ... \| put ... \| endfor` 直接回车执行 |
| `%d` | 清空整个文件(题 166 学的范围 `%` + `d`) |
| `:1d` | 删掉空首行(见下面的坑) |

> [!warning] 实测确认的坑:空文件上 `:put` 会留一个空行
> `:%d` 后文件是 0 行,光标停在"幻影第 1 行",`:put` 插在它**之后**,
> 所以第一条内容落在第 2 行,留下一个空首行。循环结束后 `:1d` 删掉它,
> 文件正好是 `Item 1` 到 `Item 10` 共 10 行。
>
> `:put` 会把光标移到插入的行(题 172 验证过),所以循环里连续
> `put` 是正序追加,不用担心倒序。

## 题 176:函数定义和调用

> [!note] 本质命令题
> 函数是 Vim script 的封装单元,只能通过命令行定义。

**命令解法**:

```vim
" 1. 执行文件里的函数定义(每行带 : 前缀,复制后执行)
:1,6y
:@"
" 2. 可视选中文本后调用
:'<,'>call WrapWithTag('div')
" 3. 自定义 CleanWhitespace
:function! CleanWhitespace()
:  let save_pos = getpos('.')
:  %s/\s\+$//e
:  %s/\n\{3,}/\r\r/e
:  call setpos('.', save_pos)
:endfunction
:call CleanWhitespace()
```

| 部分 | 作用 |
|---|---|
| `:function! 名字(参数)` | 定义函数,`!` 表示可覆盖同名旧函数;`endfunction` 结束 |
| `a:tag` | 形参引用(`a:` 前缀) |
| `:'<,'>call` | 对可视选择范围调用函数(`'<`/`'>` 是上次可视选择的起止标记) |
| `normal! \`<` | 执行普通命令,`` `< `` 跳到选择起点;`!` 表示不受用户映射影响 |
| `execute 'normal! ...'` | 用字符串拼接普通命令(引号里拼 `a:tag`) |
| `getpos('.')` / `setpos('.', ...)` | 保存 / 恢复光标位置 |
| `%s/\s\+$//e` | 去行尾空格,`e` 标志:没有匹配也不报错 |
| `%s/\n\{3,}/\r\r/e` | 3 个以上连续换行压成 2 个(替换文本里 `\r` 表示换行) |

> [!warning] 实测确认的坑
> 不选文本直接 `:'<,'>call` 会报 **E20: 没有设定标记**——必须先做
> 可视选择(如 `viw`),`'<` `'>` 标记才存在。
>
> CleanWhitespace 的光标恢复逻辑实测有效:先 `getpos('.')` 记下位置,
> 替换完 `setpos('.', save_pos)` 还原,光标纹丝不动。

## 题 177:命令缩写

> [!note] 本质命令题
> 自定义命令和缩写是纯命令行功能。

**命令解法**:

```vim
:command! JsonFormat %!jq .
:command! RemoveTrailing %s/\s\+$//e
:command! SortLines %!sort
" 清空题头(命令已生效,删掉没影响)
:%d
" 造 JSON 行并格式化
:put ='{\"name\": \"nvim\"}'
:1d
:JsonFormat
" 造带行尾空格的行
:put ='hello   '
:RemoveTrailing
" 造乱序行
:put ='banana' | put ='apple'
:SortLines
" 命令行缩写(修手误)
:cnoreabbrev Wq wq
```

| 部分 | 作用 |
|---|---|
| `:command! 名字 命令体` | 定义自定义命令;名字必须**大写字母开头**,否则报错 |
| `!` | 覆盖已存在的同名命令(不加!重复定义会报 E174) |
| `%!jq .` | 命令体里用 `%` 表示"当前文件整体",`!` 走外部命令 |
| `:cnoreabbrev 错 对` | **命令行**缩写:输入错写法,按空格/回车时展开成对的 |
| `:command` vs `:cnoreabbrev` | `command` 定义的是完整命令体;abbrev 只是输入展开,本质不同 |

> [!warning] 实测确认的坑
> 1. `:put ='{"name": "nvim"}'` 会报错(E723)——命令行里裸双引号是
>    注释起始,字符串在 `"` 处断裂。写成 `'{\"name\": \"nvim\"}'`
>    转义就没事,输出是干净的 `{"name": "nvim"}`。
> 2. `%!jq .` 要求**整个文件**是合法 JSON。练习文件里还有 3 行命令
>    定义,直接 `:JsonFormat` 会失败,所以先 `:%d` 清空再造 JSON 行
>    (空文件上 `put` 留空首行,记得 `:1d`,同题 175)。
> 3. 敲 `:Wq` 回车会展开成 `:wq` 直接保存退出——先别在有未保存修改
>    时试,真会退出。

## 题 178:执行缓冲区内容

> [!note] 本质命令题
> "把文本当命令执行"是 Ex 命令的独门用法。

**命令解法**:

```vim
" 寄存器版
:let @q = 'set number'
:@q
" 缓冲区版:先往文件里写 3 行命令文本,再复制执行
:1,3y
:@"
```

| 部分 | 作用 |
|---|---|
| `:@q` | 把寄存器 q 的内容当 Ex 命令执行(寄存器版) |
| `:@"` | 执行无名寄存器(默认复制目标)的内容 |
| `:1,3y` | 复制 1-3 行到无名寄存器 |
| `:call execute(getline(1, 3))` | 函数版:把 1-3 行字符串逐条当命令执行 |

> [!warning] 实测确认的坑
> `:1,3@:` **不能用**——`@:` 是"重复上一条命令行",没有上一条时
> 直接报 **E30: 没有前一个命令行**。正确姿势是复制后 `:@"`:
> `:1,3y` + `:@"`。

## 题 179:复杂的搜索替换

> [!note] 本质命令题
> `\=` 表达式替换是命令行的专属能力,按键没有对应物。

**命令解法**:

```vim
" 1. 编号替换:每行一个号(0 1 2)
:let i=0 | g/pattern/s//\=i/ | let i+=1
" 2. 所有单词大写(含下划线的 \w)
:%s/\<\w\+\>/\U&/g
" 3. 函数版:首字母大写
:function! ProcessMatch(match)
:  return toupper(a:match[0]) . a:match[1:]
:endfunction
:%s/\<\w\+\>/\=ProcessMatch(submatch(0))/g
```

| 部分 | 作用 |
|---|---|
| `\=` | 替换文本以 `\=` 开头 = 用表达式的结果替换;表达式逐次匹配求值 |
| `submatch(0)` | 当前匹配到的完整文本(可传给函数) |
| `&` | 替换文本里代表"整个匹配" |
| `\U` | 修饰符:后面的内容全部大写(`\U&` = 把匹配整体大写) |
| `\<` `\>` | 词首 / 词尾边界,`\w` = 单词字符(字母数字下划线) |
| `:let i=0 \| g/pattern/s//\=i/ \| let i+=1` | 每匹配一行执行替换 + 计数递增(`\|` 串三件事;在 `:g` 里 `\|` 是命令体的一部分) |

> [!warning] 实测确认的坑
> 1. 原题 hint 的 `:let counter=0 | %s/pattern/\=counter+=1/g` 直接执行
>    报 **E15: Invalid expression**——Vim 表达式里没有 `+=` 复合赋值。
>    正确写法是 `:let i=0 | g/pattern/s//\=i/ | let i+=1` 三件套:
>    先 `let i=0`,全局替换用 `\=i`,再 `let i+=1`(把 `+=` 拆成
>    `:g` 里的独立命令,每匹配一行自增一次)。
> 2. `\<w\+\>` 是错误的——它只匹配"全部由字母 w 组成的词",对
>    `hello world` 一个都匹配不上(实测报 E486: 找不到模式)。
>    正确是 `\<\w\+\>`:`\<` `\>` 是词边界,`\w\+` 才是单词字符。
> 3. 一行多个匹配怎么编号?`:g` 写法里 `let i+=1` 每**行**执行一次,
>    一行多个匹配会得到同一个号。想要每处一个号(1 2 3),用函数版:
>    `let g:c=0` + 函数里 `let g:c+=1 | return g:c`(题 176 的函数知识)。

## 题 180:宏与命令结合

**操作解法(按键)** — 录制宏:

```
qa      开始录制到寄存器 q
gUw     大写当前单词(宏的内容)
q       停止录制
```

**命令解法** — 批量执行:

```vim
" 造内容
:for i in range(1, 20) | put ='item ' . i | endfor
" 对第 5-20 行执行宏
:5,20normal @q
" 或对匹配行执行宏
:g/item/normal @q
```

| 部分 | 作用 |
|---|---|
| `qa` ... `q` | 录制宏到寄存器 q;`@q` 执行一次 |
| `:5,20normal @q` | 对范围内每一行执行普通命令 `@q`(范围 + `normal` + 宏) |
| `:g/item/normal @q` | 对匹配 `item` 的每一行执行宏(全局命令 + `normal` + 宏) |
| `gUw` | 大写当前单词(宏内容示例) |
| `normal!` | 加 `!` 可避开用户映射干扰(题 176 提过) |

> 实测确认:造行后文件是 `item 1`..`item 20`(正序,光标跟随 `put`),
> `:5,20normal @q` 只改第 5-20 行,第 1-4 行不动;
> `:g/item/normal @q` 对全部 20 行生效。
>
> `:5,20normal` 按行号选行,`:g/pattern/normal` 按内容选行——
> 文件一大,按内容选更可靠。

## 题 181:多文件操作

> [!note] 本质命令题
> 跨文件批量操作只有命令行能做,键盘没有对应物。

**命令解法**:

```vim
" 造 3 个临时 C# 文件
:!echo 'var a = 1;' > a.cs
:!echo 'var b = 2;' > b.cs
:!echo 'var c = 3;' > c.cs
" 1. 参数列表
:args *.cs
:args
:next | :prev | :first | :last
" 2. 对参数列表里所有文件替换并保存
:argdo %s/var /let /ge | update
" 3. 对已打开缓冲区执行
:bufdo %s/let /var /ge | update
" 4. 对所有窗口执行
:windo set number
" 5. quickfix 列表 + cdo
:vimgrep /var / *.cs
:cdo %s/var /let /ge | update
:copen
" 清理
:!rm -f a.cs b.cs c.cs
```

| 部分 | 作用 |
|---|---|
| `:args 文件...` | 设置参数列表(支持 `*.cs` 通配;不写参数 = 查看列表) |
| `:next`/`:prev`/`:first`/`:last` | 在参数列表里切换文件 |
| `:argdo 命令` | 对**参数列表**里每个文件执行命令(替换的 `%` 是"当前文件的全部") |
| `:bufdo 命令` | 对**每个已打开缓冲区**执行命令 |
| `:windo 命令` | 对**每个窗口**执行命令 |
| `:vimgrep /模式/ 文件` | 把匹配位置收集进 quickfix 列表 |
| `:cdo 命令` | 对 quickfix **列表中的每个位置**执行命令 |
| `ge` 标志 | `g` 一行全部替换 + `e` 无匹配不报错(否则空文件直接中断批量) |
| `update` | 只保存有改动的文件(比 `w` 更安全) |

> [!tip] 三个 do 怎么选?
> 看"对象是谁":文件在参数列表用 `:argdo`(批量改一堆文件);已经
> 打开着的用 `:bufdo`;搜索结果/报错列表用 `:cdo`;多个窗口并排用
> `:windo`。`update` 结尾是标准姿势,避免没改动也写盘。
>
> 实测确认:全部命令跑通,`ge` 标志保证某个文件没匹配也不中断批量;
> `:vimgrep /var / *.cs` 后 `:copen` 打开 quickfix 窗口,`:cdo` 逐条
> 应用替换。
