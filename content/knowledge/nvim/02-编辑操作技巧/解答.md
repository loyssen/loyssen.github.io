## 题 21:复制整行

**操作解法(按键)**:

```
yy      复制当前行(整行,含换行)
G       跳到文件最后一行
p       粘贴到当前行下方
```

**命令解法(进阶)**:`:1t$` —— 把第 1 行复制到文件末行之后(`t` = copy 的缩写,`1t$` 读作"第 1 行 → 末行之后";`m` 是移动,`t` 是复制)。

**关键命令解析**:

| 命令 | 作用 |
|---|---|
| `yy` | yank 整行:复制当前行(含换行) |
| `G` | 跳到文件最后一行 |
| `p` | paste:粘贴到当前行下方 |
| `:1t$` | 命令版:第 1 行复制到 `$`(末行)之后 |

> [!tip] 为什么不是 `yyp`
> 仓库答案是 `yyp`(复制到当前行下方,日常更常用),但这个文件的副本要求放在末尾,所以要先 `G` 跳到最后一行的位置再 `p`。记住一个原则:`p` 永远粘贴在当前行的**下方**,先移动光标再粘贴。

## 题 22:复制多行

**操作解法(按键)**:

```
V       进入行可视模式,选中当前行
j       把选择向下扩展一行(现在共选中 2 行)
y       yank:复制选中的 2 行
G       跳到文件末尾
p       粘贴到当前行下方
```

**命令解法(进阶)**:`:1,2t$` —— 第 1、2 行复制到末行之后,和按键版等价。

**关键命令解析**:

| 命令 | 作用 |
|---|---|
| `V` | 行可视模式,选中整行 |
| `j` | 向下扩展选择,多按一次 `j` 多选一行 |
| `y` | 复制选中的行 |
| `G` / `p` | 跳到末尾 / 粘贴到当前行下方 |
| `:1,2t$` | 命令版:第 1-2 行复制到末行之后 |

> [!tip] 想多选几行?
> 多按一次 `j` 就多选一行:`Vjjy` 选中 3 行、`Vjjjy` 选中 4 行。选中的行数要跟题目要求对上。

## 题 23:复制到指定位置

**操作解法(按键)**:

```
/hello   搜索定位到 def hello:
j        下移到函数体的 pass 行
yy       复制整行(    pass)
/world   搜索定位到 def world:
j        下移到它的函数体行
p        粘贴到当前行下方
```

**命令解法(进阶)**:`:2t5` —— 第 2 行复制到第 5 行之后。命令版要求先知道行号,搜索定位版不依赖行号,文件再长也能用。

**关键命令解析**:

| 命令 | 作用 |
|---|---|
| `/hello<Enter>` | 搜索 `hello`,光标落在第一个匹配处 |
| `j` | 向下移一行,从 `def` 行进到函数体 |
| `yy` | 复制当前行(`    pass`) |
| `/world<Enter>` | 搜索 `world`,跳到目标函数 |
| `p` | 粘贴到当前行下方 |

> [!warning] 为什么不用 `y2j`
> 仓库提示是 `/hello<Enter>` 后 `y2j`,但 `y2j` 会连 `def hello():` 和空行一起复制,粘贴后目标状态就对不上。这里只需要函数体那一行,所以先 `j` 移到 `pass` 行再 `yy`。解题时以"目标状态"为准,不必照抄提示。

## 题 24:删除单词

**操作解法(按键)**:光标放在 `beautiful` 上:

```
daw      delete a word:删一个词并顺带吃掉它后面的空格
```

**命令解法(进阶)**:`:s/ beautiful//` —— 行内替换,把"空格 + beautiful"删掉,结果同样是单空格。

**关键命令解析**:

| 命令 | 作用 |
|---|---|
| `d` | delete 删除 |
| `aw` | a word:一个词 **加上它后面(或前面)的空格** |
| `daw` | 删词并顺带吃掉一个空格,不会留下双空格 |

> [!warning] `daw` 和 `diw` 的区别
> 仓库提示是 `diw`(inner word,只删词本身),用它删完会得到 `hello  world`——中间两个空格,和目标状态不符。题目要求单空格,所以要 `daw`。两个都要掌握:`i` 系列不含空白,`a` 系列连空白一起处理。

## 题 25:删除到行尾

**操作解法(按键)**:

```
/and     搜索 and,光标落在 a 上
h        左移一格,停在 world 后面的空格上
D        删除到行尾
```

**命令解法(进阶)**:`:s/ and everyone//` —— 行内替换删掉多余部分(命令版不需要关心光标位置)。

**关键命令解析**:

| 命令 | 作用 |
|---|---|
| `D` | 从光标所在位置删到行尾(等价 `d$`) |
| `h` | 左移一格,让光标停在要保留内容的最后一个字符之后 |

> [!warning] 光标位置决定 D 的结果
> `D` 会删掉光标所在的字符。光标停在 world 后的空格上,空格连同 ` and everyone` 一起被删,正好是 `hello world`;如果光标停在 `and` 的 `a` 上直接按 `D`,会留下 `hello world `(行尾多一个空格)。删到行尾前,先想清楚光标该停在哪。

## 题 26:删除到行首

**操作解法(按键)**:

```
/and     搜索 and,光标落在 a 上
d0       从光标删到行首
```

**命令解法(进阶)**:`:s/^hello world //` —— `^` 锚定行首,把行首内容替换掉。

**关键命令解析**:

| 命令 | 作用 |
|---|---|
| `d0` | 从光标删到行首,行首第 1 个字符也会被删掉 |
| `d^` | 变体:只删到行首第一个**非空白**字符(行首有缩进时保留缩进) |

> [!tip] `0` 和 `^` 的差别
> 这一行没有缩进,`d0` 和 `d^` 结果一样。在缩进代码里要小心:行首有空格时,`d0` 连缩进一起删,`d^` 会保留缩进。这也是为什么代码里"删到行首"常用 `d^`。

## 题 27:删除括号内内容

**操作解法(按键)**:光标放在括号内任意位置(光标在 `(` 上按 `di(` 也可以):

```
di(      删光圆括号内内容,括号保留
```

**命令解法(进阶)**:`:s/([^)]*)/()/` —— 用正则把 `(内容)` 整体替换成 `()`(注意转义/字符类写法,`[^)]*` 匹配任意非 `)` 字符)。

**关键命令解析**:

| 命令 | 作用 |
|---|---|
| `d` | 删除 |
| `i(` | inside 圆括号:括号内部文本对象 |
| `di(` | 删光括号内内容,括号留着 |

> [!tip] 文本对象全家桶
> `di{` 花括号内、`di[` 方括号内、`di"` 双引号内、`dit` HTML 标签内——同一个套路,把 `(` 换成对应的符号就行。后面"改内容"时把 `d` 换成 `c`(`ci(`)就是删掉并进入插入模式。

## 题 28:删除引号内内容

**操作解法(按键)**:光标放在引号内任意位置:

```
di"      删光双引号内内容,引号保留
```

**命令解法(进阶)**:`:s/"[^"]*"/""/` —— 正则把任意引号内容替换成空引号。

**关键命令解析**:

| 命令 | 作用 |
|---|---|
| `di"` | 删除双引号内部文本,引号保留 |
| `ci"` | 删除并进入插入模式,直接改写引号内内容 |

> [!tip] 顺手试 `ci"`
> `ci"` 是同一件事的"改写"版:删掉引号内内容并进入插入模式,输入新内容直接替换。删和改是一对兄弟操作。

## 题 29:批量修改相同单词

**操作解法(按键)**:光标放在第一个 `name` 上:

```
*           搜索当前单词,光标停在第一个匹配
cgnuser<Esc> 改第一个匹配
.           重复:自动找下一个并改掉
.           再重复:改最后一个
```

**命令解法(进阶)**:`:%s/name/user/g` —— 全文件替换,一步到位。

**关键命令解析**:

| 命令 | 作用 |
|---|---|
| `*` | 搜索光标所在单词并跳到匹配处 |
| `cgn` | change 下一个匹配:删掉匹配文本并进入插入模式 |
| `.` | 重复上一次修改——`cgn` 的"跳到下一个"动作也会被重复 |

> [!warning] 本机没有多光标插件
> 仓库解法用 `Ctrl-n` 多光标插件逐词选中再改,本机未安装。原生等价做法就是 `cgn` + `.`:改一次,然后按 `.` 一路重复下去,每次自动跳到下一个匹配,比 `:%s/name/user/g` 更"所见即所得"(先看到改的结果,再决定要不要继续)。

## 题 30:列编辑模式

**操作解法(按键)**:

```
Ctrl-v     进入列可视(块)模式
jjj        把块向下扩展 3 行,共选中 4 行
I- <Esc>   块首插入 "- "(横杠+空格),按 Esc 统一生效
```

**命令解法(进阶)**:`:%s/^/- /` —— 每行行首加 `- `,一行命令搞定(列模式练的是"所见即所得的矩形块")。

**关键命令解析**:

| 命令 | 作用 |
|---|---|
| `Ctrl-v` | 列可视模式:按"列块"而不是按整行选择 |
| `jjj` | 块向下扩展 3 行 |
| `I` | 在块内**每行行首**进入插入模式(注意是大写 I) |
| `<Esc>` | 结束插入,修改一次性应用到块内所有行 |

> [!tip] 和行可视的区别
> 行可视 `V` 选中的是整行,列可视 `Ctrl-v` 选中的是矩形块,只影响块覆盖的字符。在行首/行尾批量加前缀后缀,是列模式最常用的场景。输入 `I` 后要连着输入要加的内容(包括空格),再按 `<Esc>` 才生效。

## 题 31:多行行尾添加

**操作解法(按键)**:分两步——先删掉文件自带的 3 个分号,再用列模式加回来。

```
gg$x      删第 1 行行尾分号($ 到行尾,x 删光标处字符)
j$x       删第 2 行
j$x       删第 3 行

gg        回到第 1 行
Ctrl-v    列可视模式
jj        选中 3 行
$         块右边界扩展到行尾(行长度不同也适用)
A;<Esc>   块尾追加分号,统一生效
```

> [!warning] 按键序列之间不要加空格
> `gg$x`、`j$x` 是三条独立的按键序列,写在同一行时不要用空格隔开——空格在 normal 模式等于 `l`(右移),在行尾会 wrap 绕到下一行(whichwrap 含 `l` 时),实测会把行删乱。本机 whichwrap 是 `b,s` 不会触发,但写成无空格的形式在任何环境都稳。

**命令解法(进阶)**:`:%s/;$//` 删掉分号,再 `:%s/$/;/` 加回来——两条命令就能完成任务,但那样就练不到列模式了。

**关键命令解析**:

| 命令 | 作用 |
|---|---|
| `gg$x` | `$` 跳到行尾,`x` 删除光标处字符 |
| `Ctrl-v` `jj` | 列块选中 3 行 |
| `$` | 把块右边界扩展到行尾,行长度不同也适用 |
| `A` | 在块内**每行行尾**进入插入模式(列模式里 A = 块尾追加) |
| `<Esc>` | 生效 |

> [!tip] 列模式里 `I` 和 `A` 的分工
> `I` = 块首插入(每行行首),`A` = 块尾追加(每行行尾)。一个管开头一个管结尾,配合 `$` 扩展块边界,长短不一的每行都能精确落到行尾(实测三行长度不同时 `A;` 依旧只加在行尾)。

## 题 32:提取变量

**操作解法(按键)**:

```
f0                跳到本行下一个 0(0.9 的 0)
ciWdiscount<Esc>  把 0.9 整体替换成 discount
Oconst discount = 0.9;<Esc>   在当前行上方开新行补声明
j                 回到 total 行
f0                跳到 0.1 的 0
ciWtax;<Esc>      0.1; 是一个 WORD,分号被一起吃掉了,输入 tax; 补回来
Oconst tax = 0.1;<Esc>   补第二个声明
```

**命令解法(进阶)**:

```vim
:%s/0\.9/discount/
:%s/0\.1/tax/
```

替换完再按两次 `O` 在行首补两行声明(`const discount = 0.9;` / `const tax = 0.1;`)。

**关键命令解析**:

| 命令 | 作用 |
|---|---|
| `f0` | 跳到本行下一个 `0` |
| `ciW` | 替换一个 WORD:`W` 以**空白**为分隔,`0.9` 整体是一个 WORD |
| `O` | 在当前行上方开新行并进入插入模式 |
| `j` | 从新行回到原行 |

> [!warning] 为什么是 `iW` 不是 `iw`
> `iw` 按标点分词,`0.9` 会被拆成 `0`、`.`、`9` 三段,`ciw` 只能改掉一段,结果变成 `discount.9`。`iW` 以空白为界,`0.9` 才是整体。另外第 3 步的 `0.1;` 是一个 WORD(分号不算分隔符),`ciW` 会把分号一起吃掉,所以输入 `tax;` 把它补回来。嫌麻烦也可以用替换:`:%s/0\.9/discount/`。

## 题 33:重命名变量

> [!note] 本质命令题
> "重命名"就是"全文件替换",没有按键对等物,`:s` 是唯一正解。

**命令解法**:

```vim
:%s/\<x\>/number/g
:%s/result/doubled/g
```

**关键命令解析**:

| 部分 | 作用 |
|---|---|
| `%` | 全文件范围 |
| `\<x\>` | 单词边界:只匹配独立的 `x`,不会误伤 `x` 开头的词 |
| `g` | 每行的所有匹配都替换 |
| `:s/result/doubled/g` | 把两处 `result` 都换成 `doubled` |

> [!tip] 真实项目里用 LSP
> 纯文本文件没有 LSP,只能用 `:s` 替换。在真实代码文件里(有 LSP 的语言),`<leader>rn` 触发 LSP 重命名,会自动跳过字符串和注释里的同名内容,更安全。两个都要会。

## 题 34:函数参数对齐

**操作解法(按键)**:

```
f(a<CR><Esc>    在 ( 后面断行
f,a<CR><Esc>    在逗号后面断行(重复 4 次)
f,a<CR><Esc>
f,a<CR><Esc>
f,a<CR><Esc>
$i<CR><Esc>     在 ) 前面断行
:2,6>           第 2-6 行(参数行)右缩进
```

**关键命令解析**:

| 命令 | 作用 |
|---|---|
| `f(` | 跳到本行下一个 `(` |
| `a` | 在光标**后**进入插入模式 |
| `<CR>` | 断行(插入模式里按回车) |
| `f,` | 跳到下一个逗号——每次断行后光标都在新行行首,所以能连着用 |
| `$i` | 行尾进入插入模式,在 `)` 前断行 |
| `:2,6>` | 第 2-6 行右缩进一级 |

> [!warning] 缩进宽度跟 shiftwidth 走
> `:2,6>` 每次缩进的宽度 = `shiftwidth`,本机全局设置是 **2 空格**,直接按会得到 2 空格缩进,和目标状态的 4 空格不符。先 `:set sw=4` 再 `:2,6>`,或者用 `:2,6>>` 连缩两级(实测两者都能得到 4 空格)。

> [!warning] 仓库提示在这个文件里不成立
> 提示里说的"光标移到括号内按 `=` 自动对齐"和"用 gf 格式化"都不行:`=` 自动缩进依赖文件类型提供的缩进规则,`.txt` 没有;`gf` 是"打开光标下的文件",跟格式化无关。真实代码文件里,一键格式化交给 conform 插件(`:ConformFormat`,本机已装),这里练的是手动断行的基本功。

## 题 35:JSON 压缩格式化

> [!note] 本质命令题
> 把多行 JSON 压成一行是批处理,`:%!` 外部命令是唯一正解。

**命令解法**:`:%!jq -c .`(本机已装 jq)。没有 jq 时用 python:

```vim
:%!jq -c .
:%!python3 -m json.tool --compact
```

**关键命令解析**:

| 部分 | 作用 |
|---|---|
| `%` | 全文件范围 |
| `!` | filter:把缓冲区内容交给外部命令处理,输出替换回缓冲区 |
| `jq -c .` | jq 解析 JSON,`-c` 紧凑输出(不换行、不留多余空格) |
| `python3 -m json.tool --compact` | python 等价写法 |

> [!tip] `:%!` 是调用外部命令的核心姿势
> 任何能读标准输入、写标准输出的命令都能这么用(`:%!sort`、`:%!grep x` 等)。注意:jq 压缩输出不带空格(`{"name":"John",...}`),和题目示例的空格布局略有差别,内容完全等价;想逐字符一致,用 `:%s/\n */ /g` 把换行换成空格(末尾可能多一个空格,再 `:%s/ $//` 清掉)。

## 题 36:JSON 美化格式化

**命令解法**:

```vim
:%!jq .
```

**关键命令解析**:

| 部分 | 作用 |
|---|---|
| `:%!` | 全文件交给外部命令(同题 35) |
| `jq .` | 解析 JSON 并美化输出,默认 2 空格缩进 |

> [!tip] 为什么不用 python
> `python3 -m json.tool` 也能美化,但默认是 4 空格缩进,和题目示例(2 空格)不一致。jq 默认正好 2 空格,所以优先用 jq。幂等:对已美化文件再跑一次 `:%!jq .`,结果不变。

## 题 37:修复 JSON 逗号

**命令解法**:

```vim
:2,3s/$/,/
```

改完验证:`:%!jq .` 不报错、缓冲区没被清空,就是合法 JSON。

**关键命令解析**:

| 部分 | 作用 |
|---|---|
| `2,3` | 行范围:第 2、3 行(第 1 行是 `{`,第 4 行是最后一个键值对,第 5 行是 `}`) |
| `s` | substitute 替换 |
| `$` | 行尾锚点:只匹配行尾 |
| `,` | 替换成逗号 |

> [!warning] 仓库提示只修了一半
> 仓库提示 `:%s/"$/",/` 只匹配以引号结尾的行:它给 `"John"` 行加了逗号,却漏掉数字行 `"age": 30`,还会给最后一行 `"New York"` 多加一个逗号(JSON 里最后一项不允许尾逗号,实测结果正是 `"age": 30` 缺逗号、`"New York",` 尾逗号报错)。这里用行范围 `2,3` 最直接。

> [!warning] 验证用 `:%!` 不是 `:!`
> `:!jq .` 只是把命令丢给 shell,并不会读取缓冲区内容,还会挂起等标准输入。验证 JSON 必须用 `:%!jq .`:缓冲区被 jq 读走,合法则输出替回缓冲区,不合法则缓冲区被清空、报错一目了然。
