##  38:修改 HTML 标签

> [!note] vim-surround 已装
> 标签题优先用 surround 的 `cst` / `dst` / `yss`,原生解法也附在下面。

**操作解法(按键)**(vim-surround):光标放标签内任意位置(标签名或内容上都行):

```
cst<span>      Change Surround Tag:输入框里打 span,回车确认(打 > 也能确认)
```

一步把 `<div>Hello World</div>` 变成 `<span>Hello World</span>`。

**原生备选**(不依赖插件,两步):

```
ci<span><Esc>    光标放开标签名上:删掉 div、输入 span(开标签完成)
f<l              跳到闭合标签的斜杠上(f< 后光标在 < 上,再 l 到斜杠)
di<              删掉斜杠和标签名(/div)
ispan<Esc>       输入新标签名(闭合标签完成)
```

**命令解法**:`:g/div>/s//span>/g` 或 `:%s/div>/span>/g` —— 把两处 `div>` 都改成 `span>`。

**关键命令解析**:

| 命令 | 作用 |
|---|---|
| `cst` | (surround)改包裹的标签,输入新标签名 |
| `ci<` | 改尖括号内的内容(= 标签名),光标放标签名上 |
| `di<` | 删尖括号内的内容(标签名),尖括号保留 |
| `f<l` | 先 `f<` 跳到下一个 `<`,再 `l` 落到斜杠上(`di<` 在斜杠上才干净) |

> [!warning] 别用 `cit` 改标签名
> `cit` 改的是标签**内容**——实测光标在 `<div>Hello World</div>` 上按 `cit<span>`,
> 结果是把 `Hello World` 换成了 `<span>`,标签名纹丝不动(`<div><span></div>`)。
> 记忆:`it` = 标签之间的内容,`at` = 整个标签块(含标签含内容);改**标签名**要用 `ci<`。

> [!tip] 高亮与重排
> 练习文件是 `.txt`,想看 HTML 高亮先 `:set ft=html`;需要重排缩进时也是
> `:set ft=html` 后再 `gg=G`(机器没装 tidy,别用外部命令格式化 HTML)。

## 题 39:删除 HTML 标签

**操作解法(按键)**(vim-surround):光标放标签内任意位置:

```
dst      Delete Surround Tag:删掉包裹的标签,内容保留
```

**原生备选**(两步):

```
da<         删掉光标所在/最近的 <div>(连尖括号)
f<l         跳到闭合标签的斜杠上
da<         删掉 </div>
```

**命令解法**:`:%s/<\/\?div>//g` —— `\/\?` 是"可选的斜杠",开闭标签一起删。

**关键命令解析**:

| 命令 | 作用 |
|---|---|
| `dst` | (surround)删掉包裹标签,只留内容 |
| `da<` | 删一个 `<...>` 块(连尖括号) |
| `<\/\?div>` | `\/\?` = 可选的 `/`,同时匹配 `<div>` 和 `</div>` |

> [!warning] `dat` 会连内容一起删
> 仓库原解写 `dat`,实测它是把整个标签块(标签 + 内容)一起删掉,
> 光标放 `<div>Hello World</div>` 上按 `dat` 只剩空行。想"只删标签留内容",
> 用 `dst`(surround)或 `da<` 拆两步。

## 题 40:包裹 HTML 标签

**操作解法(按键)**(vim-surround):光标放行内任意位置:

```
yss<div>      yss = 给整行加包裹;输入框里打 div(打 > 确认)
```

`Hello World` 整行被包成 `<div>Hello World</div>`。

> [!warning] 这题不能用 `ysiw`
> `ysiw` 只包光标下的**一个单词**:实测 `ysiw<div>` 得到 `<div>Hello</div> World`,
> 两个词被拆开各包各的。要包的是整行两个词,必须用 `yss`(surround 行操作符)。

**原生备选**:

```
I<div><Esc>      行首插入开标签
A</div><Esc>     行尾追加闭标签
```

**关键命令解析**:

| 命令 | 作用 |
|---|---|
| `yss` | (surround)给整行加包裹 |
| `ysiw` | (surround)给光标下的单词加包裹 |
| `I` / `A` | 行首插入 / 行尾追加 |

## 题 41:修改标签属性

**操作解法(按键)**:

```
ci"new<Esc>    光标放引号内任意位置(实测从行首按也行,nvim 会自动找引号对)
```

**第二种(用 `f` 系列)**:

```
0f"            跳到左引号上
cf"            删到并包含下一个引号(两个引号和 old 一起删掉)
"new"<Esc>     引号要重新打回来
```

**关键命令解析**:

| 命令 | 作用 |
|---|---|
| `ci"` | 改引号内内容,引号保留(光标在引号内任意位置即可) |
| `cf"` | 删到下一个 `"` **并包含它**,所以引号得重打 |
| `ct"` | 删到下一个 `"` **前一个字符**(不含引号)——光标放 `old` 上配合用 |

> [!warning] 写漏引号的坑
> 仓库原解写 `cf"new<Esc>`,实测会得到 `<div class=new>Content</div>`——
> `cf"` 把 `"old"` 连两个引号一起删了,输入 `new` 没有引号。用 `cf"` 就必须把
> 引号一起打回来:`cf"` 后输入 `"new"`;不想打引号就用 `ci"` 或 `ct"`。

## 题 42:创建 Markdown 链接

**操作解法(按键)**:光标放 URL 上任意位置:

```
ciW[GitHub](https://github.com)<Esc>
```

`ciW` = Change inside WORD:URL 里没有空格,是一个 WORD(按空格分的大词),
`ciW` 把它整体删掉并进入插入模式,直接输入链接。

**不想重打 URL 的写法**:

```
ciW           删掉 URL(删掉的内容进了寄存器 ",插入模式下能粘回来)
[GitHub](     输入前缀
<C-r>"        粘贴寄存器 " 里的 URL(就是刚删掉的那个)
)<Esc>        收尾
```

**关键命令解析**:

| 命令 | 作用 |
|---|---|
| `ciW` | 改整个 WORD:按空格分词,`https://github.com` 整体算一个 |
| `ciw` | 改小词:按标点分词,`https` 这种才算一个词 |
| `<C-r>"` | 插入模式下粘贴寄存器 `"`(最近删除/复制的文本) |

> [!tip] surround 在这题不是捷径
> 仓库提示的 `viwS[` 实测得到 `[ https://github.com ]`——`S` 走的是**宽松**规则
> 会带空格,而且只包了方括号,离 `[GitHub](url)` 还差"改显示名 + 加圆括号"两步。
> 这题直接 `ciW` 最干净。
>
> 顺带记住 surround 的宽松/紧凑规则:左括号 `(` `[` `{` 是宽松(带空格,
> `ysiw(` → `( Hello )`),右括号 `)` `]` `}` 是紧凑(不带空格,`ysiw)` → `(Hello)`)。
> 需要紧凑包裹时用 `)` `]` `}` 那一侧。

## 题 43:创建 Markdown 列表

> [!note] 本质命令题
> 三行行首都加 `- `,批量加前缀正是 `:s` 的用武之地。

**命令解法**:

```
:%s/^/- /
```

或者可视选中三行(`V2j`)再 `:s/^/- /`(自动变成 `:'<,'>s/^/- /`,只作用于选区)。

**关键命令解析**:

| 部分 | 作用 |
|---|---|
| `%` | 全文件范围(不写 `%` 只作用于当前行) |
| `^` | 行首锚点 |
| `- ` | 替换成的内容:短横线加空格 |

## 题 44:调整标题级别

**命令解法**:

```
:%s/^#/#&/
```

`^#` 匹配行首的**第一个** `#`,替换成 `#&`(`&` = 匹配到的原文),等于在原标题前补一个 `#`:
`# Title` → `## Title`,`## Subtitle` → `### Subtitle`。所有级别都能升一级,不用管 `#` 后面是什么。

逐行做也行:每行行首 `I#<Esc>`。

**关键命令解析**:

| 部分 | 作用 |
|---|---|
| `^#` | 行首的第一个 `#`(不是整段 `##`) |
| `#&` | 补一个 `#`,`&` 引用匹配到的原文 |
| 换行符 | 不在匹配范围内,空行原样保留 |

> [!warning] 仓库原解有坑
> 仓库给的 `:%s/^# /## /` 只匹配 `# `(**# 后必须紧跟空格**),
> 对 `## Subtitle` 这种二级标题匹配不上——实测原文件跑完 `## Subtitle` 纹丝不动,
> 达不到目标状态。用 `:%s/^#/#&/` 才对所有级别成立。

## 题 46:数字递增

> [!note] 本质命令题
> 逐行改数字没有"按键"可循,这是表达式替换的主场。

**命令解法**:

```vim
:let i=1 | g/\d\+/s//\=i/ | let i+=1
```

**关键命令解析**:

| 部分 | 作用 |
|---|---|
| `:let i=1` | 定义计数器变量,初值 1 |
| `g/\d\+/` | 全局命令:对每个含数字的行执行后面的命令(**逐行执行**) |
| `s//\=i/` | 空模式复用 `\d\+`,把数字替换为表达式 `i` 的值 |
| `\|` | 管道符:同一行依次执行多个命令 |
| `let i+=1` | 计数器 +1(**每处理一行就执行一次**,所以逐行递增) |

> [!warning] 常见误区
> 常见的 `:let i=1 | %s/\d\+/\=i/ | let i+=1` 不行——`%s` 是"一次性替换所有行",
> `i` 要等全部替换完才 +1,实测结果四行全是 `1`。要让计数器在**每行之间**递增,
> 必须用 `:g` 逐行执行。

> [!tip] 更短的备用解法
> 把数字直接换成行号,一行搞定:
> ```vim
> :%s/\d\+/\=line('.')/
> ```

## 题 47:数字递减

**命令解法**:

```vim
:let i=10 | g/\d\+/s//\=i/ | let i-=1
```

计数器从 10 开始、每行 -1,得到 `10 9 8 7`。

**关键命令解析**:

| 部分 | 作用 |
|---|---|
| `:let i=10` | 计数器初值 10 |
| `g/\d\+/s//\=i/` | 逐行把数字替换成计数器当前值(同题 46) |
| `let i-=1` | 每行处理完 -1,实现递减 |

> [!tip] 备用解法
> ```vim
> :%s/\d\+/\=11-line('.')/
> ```

## 题 49:数字格式化

> [!note] 本质命令题
> "补零成 4 位"是格式化函数的事,按键没有对应物。

**命令解法**:

```vim
:%s/\d\+/\=printf('%04d', submatch(0))/
```

**关键命令解析**:

| 部分 | 作用 |
|---|---|
| `\d\+` | 一个或多个数字(把整个数字当成一个整体) |
| `\=printf(...)` | 替换内容由表达式计算,`printf` 是 C 风格格式化 |
| `%04d` | 0=补零,4=总宽度,d=十进制整数 |
| `submatch(0)` | 当前匹配到的完整文本(就是那个数字) |

> [!tip] 改宽度
> 想补成 3 位就把 `4` 改成 `3`(`%03d`);数字超过 4 位时不会被截断,原样保留。

## 题 50:蛇形命名转驼峰

**命令解法**:

```vim
:%s/_\([a-z]\)/\U\1/g
```

**关键命令解析**:

| 部分 | 作用 |
|---|---|
| `_\([a-z]\)` | 捕获"下划线 + 一个小写字母" |
| `\U` | 后面引用的内容全部转大写 |
| `\1` | 引用第 1 个捕获组(那个小写字母) |
| `g` | 一行内全部替换(每行有多个下划线) |

## 题 52:转换为常量命名

> [!warning] 仓库提示不够
> 仓库给的 `:%s/[a-z]/\U&/g` 只会得到 `MAXVALUE`——它只负责大写,不负责插下划线。
> 要两步走:先在大写字母前插下划线,再全部大写。

**命令解法**:

```vim
:%s/\([a-z]\)\([A-Z]\)/\1_\2/g
:%s/[a-z]/\U&/g
```

**关键命令解析**:

| 部分 | 作用 |
|---|---|
| 第一条:`\([a-z]\)\([A-Z]\)` | 捕获"小写字母紧跟大写字母"的位置 |
| 第一条:`\1_\2` | 在两个字母之间插下划线 |
| 第二条:`[a-z]` | 匹配所有小写字母 |
| 第二条:`\U&` | 把匹配的整段文本(`&` = 匹配内容)转大写 |

两条命令缺一不可:只跑第一条没有全大写,只跑第二条没有下划线。

## 题 53:CSV 转 JSON

> [!note] 本质命令题
> 结构转换是外部工具的主场,`:%!` 把 buffer 交给 python 处理。

**命令解法**:

```vim
:%!python3 -c "import csv, json, sys; print(json.dumps([dict(r) for r in csv.DictReader(sys.stdin)], indent=2))"
```

**关键命令解析**:

| 部分 | 作用 |
|---|---|
| `:%!` | 把整个 buffer 内容作为标准输入喂给外部命令,再用命令输出替换 buffer |
| `python3 -c "..."` | 执行一段 python 代码(无需写脚本文件) |
| `csv.DictReader(sys.stdin)` | 把标准输入按 CSV 解析,首行自动当表头 |
| `[dict(r) for r in ...]` | 每行转成一个 `{表头: 值}` 字典 |
| `json.dumps(..., indent=2)` | 序列化成带缩进的 JSON 文本 |

> [!tip] 布局差异不算错
> 目标状态把每个对象压成一行,而 python 默认每个字段各占一行——只要结构正确
> (数组、键名、值、引号、逗号)都算通过。完成后可以 `:setf json` 打开语法高亮检查;
> 存成 `.json` 文件后 conform(prettierd,保存即格式化)会自动压成紧凑格式,
> 正好贴近目标状态。

> [!tip] jq 也可用
> 机器上装了 jq,`:!jq .` 把结果打印到命令行(不改 buffer),`:%!jq .` 会用输出
> 替换 buffer——两者都能当"JSON 是否合法"的校验:buffer 里有非法 JSON 时 jq 报错、
> 内容不变。但 jq 不管 CSV 解析,这题主体还是 python3。

## 题 54:批量格式化行

**操作解法(按键)**:光标在第一行行首,录制宏:

```
qa              开始录制到寄存器 a
0~              行首,切换首字母大小写(n → N)
f:              跳到冒号(光标停在冒号上)
a <Esc>         冒号后追加一个空格(光标在冒号上时 a = 从下一个字符开始插入)
j               下一行
q               停止录制
2@a             对剩下两行重放
```

**关键命令解析**:

| 命令 | 作用 |
|---|---|
| `qa` / `q` | 开始 / 停止录制宏,存进寄存器 `a` |
| `~` | 切换光标下字符的大小写(`n` → `N`) |
| `f:` | 跳到本行下一个冒号 |
| `a <Esc>` | 在冒号后追加空格 |
| `@a` / `2@a` | 重放宏一次 / 重放两次 |

> 宏的"结束位置"是下一行行首(`j`),这样每次重放都从同一相对位置开始——这是宏能
> 批量工作的关键。

## 题 55:重复模式操作

**操作解法(按键)**:光标在第一行行首,录制宏:

```
qa                 开始录制到寄存器 a
0Idef <Esc>        行首插入 "def "(def 后那个空格是内容的一部分,要打进去)
ea():<Esc>         跳到词尾,追加 "():"
o    pass<Esc>     下方开新行,输入 4 个空格 + pass
o<Esc>             再开一个空行当分隔(录制时立即退出插入)
j0                 下一行行首——宏的"收尾位置",保证下次重放起点正确
q                  停止录制
2@a                对剩下两行重放
```

**关键命令解析**:

| 命令 | 作用 |
|---|---|
| `I` | 行首插入(光标在任意列都回到行首) |
| `e` | 跳到下一个单词的词尾 |
| `a` | 光标后追加 |
| `o` | 下方开新行并进入插入模式 |
| `j0` | 下一行、行首——宏的"收尾位置",保证下次重放起点正确 |
| 空行 `o<Esc>` | 在函数块之间留一个空行,与目标状态对齐 |

> [!warning] 宏里插入模式的每个字符都会被录进去
> `ea():` 后面如果手滑多敲一个空格,重放时**每行** `():` 后都会多一个空格(实测坑)。
> 录完先 `@a` 试一遍、检查没问题再 `2@a`;不对就 `u` 撤销重录。

## 题 56:批量处理数据

**操作解法(按键)**:光标在第一行行首,录制宏:

```
qa             开始录制到寄存器 a
$b~            行尾($)再回单词开头(b),切换大小写(~)
A - Fruit<Esc> 行尾追加 " - Fruit"
j              下一行
q              停止录制
2@a            对剩下两行重放
```

**关键命令解析**:

| 命令 | 作用 |
|---|---|
| `$` | 跳到行尾(光标停在最后一个字符上) |
| `b` | 回到上一个单词开头(`apple` 的 `a` 上) |
| `~` | 切换光标下字符的大小写 |
| `A` | 行尾追加并进入插入模式 |
| 为什么不用 `$i` | `i` 插在光标**前**,`$` 停在行尾字符上,会插到最后一个字符前面;`A` 一定在末尾追加 |

> [!tip] 为什么不用 `w` 跳单词
> `1. apple` 里 `w` 会先跳到句点 `.`(它是独立的"单词"),容易踩坑。用 `$b` 从行尾往回找单词开头,稳。

## 题 57:操作单词

**操作解法(按键)**:光标先跳到 `world` 上(行首按一次 `w`):

```
daw
```

`daw` = Delete A Word:删掉 `world` 和它后面的空格,前后正好剩一个空格。

**关键命令解析**:

| 命令 | 作用 |
|---|---|
| `w` | 跳到下一个单词开头 |
| `daw` | 删除一个单词及其后面的空格(a = around) |
| `diw` | 只删单词本身(i = inside) |

> [!tip] `daw` vs `diw`
> `diw` 删掉 `world` 后,前后两个空格会挤在一起(`hello  neovim` 双空格);
> `daw` 把单词连同后面一个空格一起删,直接得到干净的 `hello neovim`。

## 题 58:操作句子

**操作解法(按键)**:先用 `fS` 跳到 `Second` 的大写 `S` 上:

```
fSdas
```

**关键命令解析**:

| 命令 | 作用 |
|---|---|
| `fS` | 找到本行下一个大写 `S`(句子间只有这一个,用来定位) |
| `das` | 删除一个句子及其后面的空格(a = around) |
| `dis` | 只删句子本身(i = inside) |

> [!tip] `das` vs `dis`
> `dis` 删完会留下双空格(`First sentence.  Third sentence.`);
> `das` 把句尾空格一起删掉,正好是目标状态。需要保留间距时用 `dis`,需要删干净时用 `das`。

## 题 59:操作段落

**操作解法(按键)**:光标放第一段任意一行:

```
dap
```

**关键命令解析**:

| 命令 | 作用 |
|---|---|
| `dap` | 删除一个段落(a = around,含段落后面的空行) |
| 为什么不用 `dd` | `dd` 只删光标所在的一行,而一个段落有两行 |

## 题 60:操作函数参数

**操作解法(按键)**:光标放行首:

```
0f,dt,
```

**关键命令解析**:

| 命令 | 作用 |
|---|---|
| `0` | 行首 |
| `f,` | 跳到下一个逗号(光标停在第一个逗号上) |
| `d` | 删除 |
| `t,` | 跳到下一个逗号**前一个字符**(t = till,不含目标字符) |

> [!warning] 仓库提示的坑
> 仓库提示 `d2f,`,但 `f,` 是"含目标字符"的——实测从行首直接按 `d2f,`
> 会删掉 `function(arg1, arg2,` 只剩 ` arg3)`;就算先 `f,` 移到第一个逗号上再
> `d2f,`,也会把第二个逗号一起吃成 `function(arg1 arg3)`。删到"逗号前"要用 `t,`,
> 它不含目标字符,第二个逗号安全。
