# 10 LSP 智能编程 · 实操教学 (152-165)

> [!info] 本节说明
> 共 14 道题,分 5 组。每道题的流程:
> 1. 在 kitty 终端 `cd` 进目录,用 `nvim` 打开对应的练习文件
> 2. 看题目要求,在文件上动手操作,达成目标状态
> 3. 对照"目标状态"验收,卡住时点题末链接查看解法(解答.md)
> 4. 打勾检验清单。练完可随时重开文件(初始状态不变)

| 题号 | 主题 | 难度 |
|---|---|---|
| 152-154 | 补全、跳转定义/引用、重命名 | ⭐⭐ |
| 155-156 | 诊断与自动导入 | ⭐⭐ |
| 157-158 | 格式化与折叠 | ⭐ |
| 159-160 | 签名帮助与代码操作 | ⭐⭐ |
| 161-165 | 符号搜索、大纲、内联提示、调用层次、工作区管理 | ⭐⭐⭐ |

> [!warning] LSP 前提:练习文件是 .txt,先转成真实语言文件
> 语言服务器(ts_ls、pyright…)只对它能识别的文件类型启动,`.txt` 打开不会触发任何 LSP,补全/诊断/跳转全都不生效。
> 每题先把练习文件复制成真实后缀再操作(本章每题的打开文件里都带这一步):
>
> ```bash
> cd ~/nixos-config/notes/nvim/10-LSP 智能编程
> cp 练习/152-代码补全和建议.txt 练习/152.ts   # 后缀换成 ts_ls 认识的
> nvim 练习/152.ts
> ```
>
> 打开后先删掉 `← 光标位置` 之类的标记文字,`:w` 保存让 ts_ls 开始分析。
> 后缀对照:`.ts` / `.tsx` → ts_ls,`.py` → pyright,`.rs` → rust_analyzer,`.go` → gopls,`.lua` → lua_ls,`.json` → jsonls。

> [!note] 本章已配好的环境(已实测)
> - 章节目录放好了 `tsconfig.json` + `react.d.ts`:ts_ls 把整个 `练习/` 目录当成一个 TS 项目,155/156 的 react 诊断和自动导入依赖它们,别删。
> - 格式化本机没有 prettierd,保存时由 ts_ls(LSP fallback)兜底自动格式化,只重排缩进、不拆行;手动格式化用 `:lua vim.lsp.buf.format()`(`:Format` 命令本机不存在)。
> - 题 163 的 ts_ls 内联提示默认全关,题内有前置步骤。

**本章 LSP 键位速查**:

| 操作 | 键位 |
|---|---|
| 跳转定义 | `gd` |
| 查找引用 | `gr` |
| 悬浮文档 / 签名 | `K` |
