# 6.7 提示工程

> 和 LLM 对话是一门手艺。好的 Prompt 和差的 Prompt，效果天差地别。

---

## 基础原则

### 清晰、具体、有结构

| ❌ 差 | ✅ 好 |
|------|------|
| "写一个推荐系统" | "用 Python 写一个基于协同过滤的电影推荐系统，包含数据加载、相似度计算和推荐函数" |
| "总结这篇文章" | "用 3 句话总结这篇文章，第 1 句概括主旨，后 2 句列出关键论点" |

## Few-Shot Prompting

给模型几个示例，它就能学会你想要的格式：

```
将以下句子翻译成英文的反面：

中文：今天天气很好
英文反面：The weather is not good today.

中文：我很开心
英文反面：I am not happy.

中文：这部电影很棒
英文反面：
→ "This movie is not great."
```

## Chain-of-Thought（思维链）

> 让模型展示推理过程，显著提高复杂问题的准确率。

```
Q: 一个商店买 3 个苹果和 2 个香蕉花了 $6，买 2 个苹果和 3 个香蕉花了 $5.5。
   一个苹果和一个香蕉各多少钱？

A: 设苹果价格 = a，香蕉价格 = b
   3a + 2b = 6   ... (1)
   2a + 3b = 5.5 ... (2)
   
   (1) × 3: 9a + 6b = 18
   (2) × 2: 4a + 6b = 11
   相减: 5a = 7, a = 1.4
   代入 (1): 4.2 + 2b = 6, b = 0.9
   
   答案：苹果 $1.4，香蕉 $0.9
```

### 变体

| 方法 | 做法 |
|------|------|
| Zero-shot CoT | 只加一句 "Let's think step by step" |
| Few-shot CoT | 给出几个带推理过程的示例 |
| Tree-of-Thought | 多路径探索，选择最优推理路线 |

## System Prompt 设计

System Prompt 是 LLM 的「人设」：

```markdown
你是一个专业的 Python 编程导师。你的回答应该：

1. 先用自然语言解释概念
2. 再给出代码示例
3. 解释代码中的关键点
4. 指出常见错误

风格要求：
- 用中文回答
- 代码要有注释
- 对初学者友好，避免过于深奥的术语
```

## 进阶技巧

| 技巧 | 说明 | 使用场景 |
|------|------|---------|
| **角色扮演** | 给 LLM 一个身份 | 模拟面试官、代码审查者 |
| **Self-Consistency** | 多次采样，投票选最佳 | 提高准确率 |
| **指令拆分** | 把大任务拆成小步骤 | 复杂任务 |
| **Few-shot + CoT 组合** | 少量示例 + 推理过程 | 最有效的通用方案 |
| **反思** | 让模型检查自己的输出 | 质量保证 |

## 在代码中使用 Prompt

```python
def build_prompt(user_query, context=None):
    system = """你是一个 AI 知识助手。回答原则：
    1. 准确：不确定的内容请说明
    2. 结构化：使用标题、列表组织信息
    3. 实用：提供可操作的代码示例"""
    
    messages = [{"role": "system", "content": system}]
    
    if context:
        messages.append({
            "role": "system",
            "content": f"参考知识：\n{context}"
        })
    
    messages.append({"role": "user", "content": user_query})
    return messages
```
