# 模型部署工具链

> 训练完的模型怎么用起来？不同场景的部署方案。

---

## 方案对比

| | Ollama | vLLM | llama.cpp | TGI | FastAPI 自建 |
|------|--------|------|-----------|-----|-------------|
| 场景 | 个人 | 生产高并发 | 本地/边缘 | 生产 | 自定义 |
| 安装 | 一键 | pip | 编译 | Docker | pip |
| 协议 | REST | OpenAI | REST | OpenAI | 自定义 |
| 量化 | GGUF 自动 | GPTQ/AWQ | GGUF | GPTQ/AWQ | 任意 |
| 并发 | 低 | 极高 | 低 | 高 | 中 |

---

## Ollama

```bash
# 安装
# https://ollama.com → 下载安装包

# 拉取模型
ollama pull qwen2:7b

# 交互
ollama run qwen2:7b

# API
ollama serve  # 启动服务（默认 11434 端口）
```

```python
import requests
resp = requests.post("http://localhost:11434/api/generate", json={
    "model": "qwen2:7b",
    "prompt": "你好",
    "stream": False,
})
print(resp.json()["response"])
```

## vLLM

```bash
pip install vllm

python -m vllm.entrypoints.openai.api_server \
    --model Qwen/Qwen2-7B-Instruct \
    --port 8000 \
    --max-model-len 4096
```

---

## llama.cpp

```bash
# 编译
git clone https://github.com/ggerganov/llama.cpp
cd llama.cpp && make

# 转换模型
python convert.py /path/to/model --outtype q4_0

# 运行
./main -m model.gguf -p "你好" -n 256
```

## Docker 部署模板

```dockerfile
FROM nvidia/cuda:12.1-runtime-ubuntu22.04

RUN apt update && apt install -y python3-pip
RUN pip3 install vllm

COPY ./model /model
EXPOSE 8000

CMD ["python3", "-m", "vllm.entrypoints.openai.api_server", \
     "--model", "/model", "--host", "0.0.0.0", "--port", "8000"]
```
