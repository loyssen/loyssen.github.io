## 多智能体协作

单个 Agent 能力有限，多个 Agent 可以：

```mermaid
flowchart TB
    USER["👤 用户任务"]
    ORCH["🎯 协调 Agent<br/>任务分解与分配"]
    
    RESEARCH["🔍 研究 Agent<br/>搜索+总结信息"]
    CODE["💻 代码 Agent<br/>编写+测试代码"]
    REVIEW["👀 审核 Agent<br/>检查+反馈"]
    
    USER --> ORCH
    ORCH --> RESEARCH
    ORCH --> CODE
    RESEARCH --> REVIEW
    CODE --> REVIEW
    REVIEW --> ORCH
    ORCH --> USER
```

| 协作模式 | 说明 | 类比 |
|---------|------|------|
| 辩论模式 | 多个 Agent 互相质疑，达成共识 | 论文评审 |
| 分工模式 | 各自负责子任务，汇总结果 | 软件开发团队 |
| 层级模式 | 管理 Agent 分配任务，子 Agent 执行 | 公司组织 |
| 反思模式 | 一个执行，另一个审查反馈 | 结对编程 |
