# 📐 最优化方法

> 把 Loss 降到最低。深度学习的训练就是一个巨大的优化问题。

---

## 为什么需要最优化

```mermaid
flowchart LR
    MODEL["模型 f(x;θ)"] --> LOSS["Loss ℒ(θ)"]
    LOSS --> OPT["优化器<br/>寻找使 ℒ 最小的 θ"]
    OPT --> UPDATE["更新 θ"]
    UPDATE --> MODEL
```

> 💡 **深度学习的训练 = 在几十亿维的参数空间中寻找最低点。**

---

## 1. 梯度下降（GD）

### 基本公式

$$\theta_{t+1} = \theta_t - \alpha \cdot \nabla_\theta \mathcal{L}(\theta_t)$$

```mermaid
graph TB
    subgraph GD_VISUAL["梯度下降可视化 —— Loss 曲面上的一条下山路径"]
        LANDSCAPE["等高线图<br/>每一圈 = 相同的 Loss 值"]
        PATH["🔴 → 🟠 → 🟡 → 🟢<br/>从随机点开始<br/>每步沿梯度反方向"]
        MINIMUM["⭐ 谷底 = Loss 最小点 = 训练目标"]
    end
    
    LANDSCAPE --> PATH --> MINIMUM
    
    FORMULA["θ ← θ - α·∇ℒ<br/>α 控制步长"]
```

| 符号 | 含义 |
|------|------|
| $\theta$ | 模型参数（权重和偏置） |
| $\alpha$ | **学习率** — 每步走多大 |
| $\nabla_\theta\mathcal{L}$ | 梯度 — 最陡的上升方向 |

> ⚠️ 为什么是**减去**梯度？梯度指向 Loss 增长最快的方向，我们要降低 Loss，所以反着走。

## 2. 三种梯度下降变体

```mermaid
graph TD
    GD["梯度下降变体"] --> BGD["批量 GD<br/>一次性算全部数据<br/>✅ 稳定 ❌ 慢"]
    GD --> SGD["随机 GD<br/>每次只用 1 条数据<br/>✅ 快 ❌ 不稳定"]
    GD --> MINI["Mini-Batch GD<br/>每次用一小批数据<br/>✅ 平衡 ⭐ 最常用"]
```

| 方法 | 每次用多少数据 | 特点 |
|------|-------------|------|
| Batch GD | 全部 | 最精确，但太慢 |
| SGD | 1 条 | 最快，但噪声大 |
| **Mini-Batch** | 32/64/128 条 | ⭐ **标准做法** |

### 学习率调度策略

```mermaid
graph LR
    subgraph WARMUP["Warmup（LLM 必用）"]
        W1["lr: 0 → 目标值<br/>前几千步线性增大"]
        W2["稳定初期训练<br/>防止梯度爆炸"]
    end
    subgraph COSINE["Cosine Decay"]
        C1["lr: 余弦曲线<br/>从大到小平滑递减"]
        C2["平滑收敛<br/>不突然变化"]
    end
    subgraph STEP["Step Decay"]
        S1["lr: 阶梯式<br/>每 N 步减半"]
        S2["简单粗暴<br/>但不平滑"]
    end
```

| 策略 | 描述 |
|------|------|
| **Warmup** | 从小学习率开始，逐渐增大 → 稳定初期训练（LLM 必用） ⭐ |
| **Cosine Decay** | 余弦曲线从大到小 → 平滑收敛 |
| **Step Decay** | 每隔 N 步减半 → 简单粗暴 |
| **Reduce on Plateau** | Loss 不动了就减小学习率 |

## 4. 动量优化器 — SGD 的进化

### Momentum

```python
v = β * v - α * ∇L     # 累积历史梯度（动量）
θ = θ + v               # 用动量更新
```

```mermaid
flowchart LR
    subgraph SGD["SGD（无动量）"]
        SGD_PATH["曲折的锯齿路径<br/>每步只看当前梯度<br/>容易震荡"]
    end
    subgraph MOMENTUM["Momentum（有动量）"]
        MOM_PATH["平滑的加速路径<br/>历史梯度累积动能<br/>快速穿过平坦区"]
    end
    
    SGD -.->|"加入动量<br/>β·v 项"| MOMENTUM
```

> 🏂 **比喻**：SGD = 每步重新决定方向。Momentum = 像下坡的滑雪者，积累动能，不容易被小石头卡住。

### 局部最小值 vs 全局最小值

```mermaid
graph LR
    subgraph LANDSCAPE["Loss 地形"]
        LOCAL["🔴 局部最小值<br/>周围最低<br/>但不是全局最低"]
        GLOBAL["⭐ 全局最小值<br/>整个曲面的最低点"]
        SADDLE["🟡 鞍点<br/>一个方向低，一个方向高"]
    end
    
    LOCAL -.->|"动量帮助跳出"| GLOBAL
    SADDLE -.->|"动量帮助冲过去"| GLOBAL
```

### Adam — 深度学习标配

**Adam = Momentum + 自适应学习率**

| 特点 | 说明 |
|------|------|
| 自适应 | 每个参数有自己的学习率 |
| 动量 | 积累历史梯度方向 |
| 偏差校正 | 修正初始几步的偏差 |
| 默认首选 | 绝大多数情况的默认优化器 |

```python
# 几乎所有深度学习项目的第一行训练代码
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)
```

## 5. 正则化与优化的关系

| 正则化方法 | 从优化角度看 |
|-----------|------------|
| **L2 权重衰减** | 在梯度上额外减去一个 $w$ 的项 |
| **L1 正则化** | 让优化器倾向于把权重推向 0 |
| **Dropout** | 每次优化只在随机子网络上进行 |
| **Batch Normalization** | 改变优化地形，让 Loss 曲面更平滑 |

```
带 L2 正则化的权重更新：
  w ← w - α·(∇_w Loss + λ·w)
                ↑           ↑
            正常梯度    L2 项的梯度
```

### L1 vs L2 的几何直觉

```mermaid
flowchart LR
    subgraph L2_VIS["L2 正则化（Ridge）"]
        L2_CIRCLE["约束区域：圆形<br/>Loss 等高线碰到圆边<br/>→ 解在圆周上<br/>→ 权重缩小但不为0"]
    end
    subgraph L1_VIS["L1 正则化（Lasso）"]
        L1_DIAMOND["约束区域：菱形<br/>Loss 等高线容易碰到<br/>菱形的尖角<br/>→ 某些权重恰好为0<br/>→ 自动特征选择！"]
    end
```

> 💡 L1 产生稀疏解（部分权重=0）是因为菱形有尖角。L2 是圆形，等高线碰到时各权重一般都不为 0。

## 6. 训练技巧速查

| 技巧 | 做什么 | 什么时候用 |
|------|--------|-----------|
| **Gradient Clipping** | 限制梯度最大值 | 训练不稳定时 |
| **Warmup** | 学习率从小开始 | LLM 训练必备 |
| **Weight Decay** | L2 正则化的现代叫法 | 防止过拟合 |
| **Mixed Precision** | 用 FP16 加速训练 | 节省显存 |
