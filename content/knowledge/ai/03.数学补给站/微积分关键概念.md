# 📐 微积分关键概念

> 深度学习的「学习」靠的就是导数。掌握导数、偏导数和链式法则就足够应对绝大多数场景。

---

## 为什么需要微积分

```mermaid
flowchart LR
    LOSS["Loss 函数<br/>衡量模型多差"] --> GRAD["梯度 ∇L<br/>Loss 对每个参数的偏导数"]
    GRAD --> UPDATE["参数更新<br/>w ← w - α·∇L<br/>沿着梯度反方向走"]
    UPDATE --> BETTER["模型变好一点点"]
    BETTER --> LOSS
```

> 💡 **核心洞察**：训练神经网络 = 反复计算梯度并用它更新参数。梯度就是 Loss 对参数的导数。

---

## 1. 导数 — 变化率

### 直观理解

> 导数 = 函数在某一点的「斜率」= 输入变化一点点，输出变化多少

$$f'(x) = \lim_{h \to 0}\frac{f(x+h) - f(x)}{h}$$

```mermaid
graph TB
    subgraph DERIV["导数的几何意义"]
        direction LR
        CURVE["函数曲线 f(x)"]
        TANGENT["切线<br/>斜率 = f'(x)"]
        POINT["在 x₀ 处<br/>切线斜率 = 函数的瞬时变化率"]
    end
    
    subgraph AI_MEANING["AI 中的含义"]
        POS["∂Loss/∂w > 0<br/>增大 w → Loss ↑<br/>→ 应该减小 w ✅"]
        NEG["∂Loss/∂w < 0<br/>增大 w → Loss ↓<br/>→ 应该增大 w ✅"]
    end
```

**在 AI 中的含义**：
- 如果 $\frac{\partial \text{Loss}}{\partial w} > 0$：增大 $w$ → Loss 增大 → 应该减小 $w$
- 如果 $\frac{\partial \text{Loss}}{\partial w} < 0$：增大 $w$ → Loss 减小 → 应该增大 $w$

---

## 2. 偏导数 — 多变量函数的导数

当函数有多个变量时，逐个求导：

$$f(w,b) = w^2 + b^2$$

$$\frac{\partial f}{\partial w} = 2w, \quad \frac{\partial f}{\partial b} = 2b$$

```mermaid
flowchart TB
    subgraph PARTIAL["偏导数的直观理解"]
        SURFACE["Loss 曲面 ℒ(w,b)<br/>x轴=w, y轴=b, z轴=Loss"]
        SLICE_W["沿 w 方向切片<br/>b 固定不变<br/>求 ∂ℒ/∂w"]
        SLICE_B["沿 b 方向切片<br/>w 固定不变<br/>求 ∂ℒ/∂b"]
    end
    
    SURFACE --> SLICE_W & SLICE_B
    
    GRAD["梯度 ∇ℒ = (∂ℒ/∂w, ∂ℒ/∂b)<br/>指向 Loss 上升最快的方向"]
```

> 💡 把其他变量当成常数，对目标变量求导。

**在 AI 中的含义**：神经网络的每个参数都有各自的偏导数，形成**梯度向量**。

## 3. 链式法则 — 反向传播的数学核心

### 公式

$$\frac{\partial L}{\partial x} = \frac{\partial L}{\partial y} \cdot \frac{\partial y}{\partial x}$$

### 在神经网络中

```mermaid
graph LR
    X["输入 x"] -->|w| Z["z = wx+b"]
    Z -->|σ| A["a = σ(z)"]
    A -->|Loss| L["Loss L(a,y)"]

    L -.->|"∂L/∂a"| A
    A -.->|"∂a/∂z"| Z
    Z -.->|"∂z/∂w"| X
```

**反向传播**就是链式法则的高效实现：

```python
# 用链式法则计算 ∂L/∂w
dL_dw = dL_da * da_dz * dz_dw
#        ↑        ↑       ↑
#     Loss对激活  激活对z  z对w
```

## 4. 常见函数的导数（速查）

```mermaid
flowchart LR
    subgraph RELU["ReLU"]
        R1["f(x)=max(0,x)"]
        R2["f'(x)=0 if x<0<br/>f'(x)=1 if x>0"]
        R3["⚡ 计算最快<br/>⚠️ 负数区梯度为0"]
    end
    subgraph SIG["Sigmoid"]
        S1["σ(x)=1/(1+e⁻ˣ)"]
        S2["σ'(x)=σ(1-σ)"]
        S3["输出0~1<br/>⚠️ 两端梯度趋0"]
    end
    subgraph GELU["GELU (LLM 常用)"]
        G1["f(x)=x·Φ(x)"]
        G2["平滑的 ReLU<br/>允许负值通过一点"]
        G3["⭐ Transformer 标配"]
    end
```

| 函数 | 导数 | 在 AI 中的位置 |
|------|------|--------------|
| $f(x)=x^2$ | $f'(x)=2x$ | MSE Loss |
| $f(x)=\frac{1}{x}$ | $f'(x)=-\frac{1}{x^2}$ | — |
| $f(x)=e^x$ | $f'(x)=e^x$ | Softmax 分子 |
| $f(x)=\ln x$ | $f'(x)=\frac{1}{x}$ | 交叉熵 Loss |
| $\sigma(x)=\frac{1}{1+e^{-x}}$ | $\sigma'(x)=\sigma(x)(1-\sigma(x))$ | Sigmoid 激活 |
| $\text{ReLU}(x)=\max(0,x)$ | $\text{ReLU}'(x) = \begin{cases}1 & x>0 \\ 0 & x<0\end{cases}$ | 隐藏层激活 |
| $\text{GELU}(x)$ | 近似 Sigmoid 形状 | Transformer/LLM ⭐ |

## 5. 梯度下降的直观理解

```mermaid
graph TD
    CURRENT["当前参数 w<br/>站在山坡上"]
    GRADIENT["计算梯度 ∇L<br/>这个方向最陡"]
    STEP["更新参数<br/>w ← w - α·∇L<br/>向山下走一小步"]
    REPEAT["重复<br/>直到到达山谷"]
    
    CURRENT --> GRADIENT --> STEP --> REPEAT
    REPEAT -.-> CURRENT
```

> 🏔️ **想象**：你蒙着眼睛站在山上，想知道怎么下山。你感受脚下的坡度（梯度），向最陡的下坡方向走一小步（学习率 × 梯度），重复直到感觉不到坡度了（收敛）。
