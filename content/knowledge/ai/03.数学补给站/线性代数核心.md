## 1. 向量

### 几何理解

> 向量 = 空间中的一个箭头（有方向和长度）

### AI 中的向量

> 向量 = 一个样本的特征列表

```
房价特征向量: x = [面积, 卧室数, 房龄, 地段评分]
                = [120,    3,     10,    8     ]
```

### 关键运算

#### 点积 — Self-Attention 的灵魂

$$\mathbf{a}\cdot\mathbf{b} = \sum_i a_i b_i = \|\mathbf{a}\|\|\mathbf{b}\|\cos\theta$$

```mermaid
graph TB
    subgraph DOT["点积的几何直觉"]
        A["向量 a<br/>『猫』的 Embedding"]
        B["向量 b<br/>『狗』的 Embedding"]
        ANGLE["夹角 θ 很小<br/>→ 点积大 → 语义接近"]
    end
    
    subgraph DOT2["点积的几何直觉"]
        C["向量 a<br/>『猫』的 Embedding"]
        D["向量 c<br/>『汽车』的 Embedding"]
        ANGLE2["夹角 θ 很大<br/>→ 点积小 → 语义无关"]
    end
```

> 💡 在 Transformer 的 Self-Attention 中，$QK^\top$ 本质就是对序列中每一对 token 做**点积**，衡量它们的「相关性」。

| 运算 | 公式 | AI 中的含义 |
|------|------|------------|
| **点积** | $\mathbf{a}\cdot\mathbf{b} = \sum a_i b_i$ | 两个向量的相似度！**Self-Attention 的核心** |
| **范数** | $\|\mathbf{x}\|_2 = \sqrt{\sum x_i^2}$ | 向量的「大小」，用于正则化 |
| **余弦相似度** | $\cos\theta = \frac{\mathbf{a}\cdot\mathbf{b}}{\|\mathbf{a}\|\|\mathbf{b}\|}$ | Embedding 相似度计算 |

## 2. 矩阵

### AI 中的矩阵

```
      特征1  特征2  特征3
样本1 [ 3.2   1.5   0.8 ]
样本2 [ 2.1   4.0   1.2 ]
样本3 [ 5.0   2.3   0.9 ]
...
样本m [ ...   ...   ... ]
```

**形状 = (样本数, 特征数) = (m, n)**

### 矩阵乘法

$$C = A \times B \quad \text{where} \quad C_{ij} = \sum_k A_{ik} B_{kj}$$

```mermaid
flowchart LR
    subgraph A_MAT["矩阵 A (3×2)"]
        A1["a₁₁ a₁₂"]
        A2["a₂₁ a₂₂"]
        A3["a₃₁ a₃₂"]
    end
    subgraph B_MAT["矩阵 B (2×4)"]
        B1["b₁₁ b₁₂ b₁₃ b₁₄"]
        B2["b₂₁ b₂₂ b₂₃ b₂₄"]
    end
    subgraph C_MAT["结果 C = A×B (3×4)"]
        C1["c₁₁ c₁₂ c₁₃ c₁₄"]
        C2["c₂₁ c₂₂ c₂₃ c₂₄"]
        C3["c₃₁ c₃₂ c₃₃ c₃₄"]
    end
    
    A_MAT -->|"×"| C_MAT
    B_MAT -->|"×"| C_MAT
    
    NOTE["c₁₁ = a₁₁·b₁₁ + a₁₂·b₂₁<br/>c₁₁ = 第1行 · 第1列"]
```

```mermaid
flowchart TB
    subgraph ATTENTION["Transformer 中的形状变换"]
        Q_SHAPE["Q: (seq_len, d_k)<br/>查询矩阵"]
        K_SHAPE["Kᵀ: (d_k, seq_len)<br/>键矩阵转置"]
        SCORE["QKᵀ: (seq_len, seq_len)<br/>每个 token 对每个 token 的分数"]
        V_SHAPE["V: (seq_len, d_v)<br/>值矩阵"]
        OUT["输出: (seq_len, d_v)<br/>加权聚合后的表示"]
    end
    
    Q_SHAPE --> SCORE
    K_SHAPE --> SCORE
    SCORE --> OUT
    V_SHAPE --> OUT
```

> 🔥 **这是深度学习中执行次数最多的运算。** 全都是矩阵乘法！

## 3. Softmax 函数

把任意实数向量变成概率分布：

$$\text{softmax}(z_i) = \frac{e^{z_i}}{\sum_j e^{z_j}}$$

```mermaid
graph LR
    INPUT["输入 z<br/>[2.0, 1.0, 0.1]"] --> SOFTMAX["Softmax"]
    SOFTMAX --> OUTPUT["输出概率<br/>[0.66, 0.24, 0.10]<br/>∑ = 1.0"]
```

**在 AI 中的位置**：
- 分类任务的最后一层
- **Attention 权重归一化** ← 超重要
- 语言模型的 token 概率输出

## 4. 特征值与特征分解

$$A\mathbf{v} = \lambda \mathbf{v}$$

```mermaid
flowchart TB
    subgraph EIG["特征分解的直观理解"]
        MATRIX["矩阵 A 作用在向量 v 上"]
        RESULT["结果 = λ·v<br/>方向不变，只缩放！"]
    end
    
    subgraph PCA["PCA 降维的本质"]
        DATA2D["2D 数据点散布"]
        PC1["第1主成分<br/>方差最大的方向<br/>(最大特征值对应)"]
        PC2["第2主成分<br/>正交方向"]
        PROJECT["投影到 PC1 → 1D<br/>损失少量信息，大幅降维"]
    end
    
    DATA2D --> PC1 & PC2
    PC1 --> PROJECT
```

| 概念 | AI 应用 |
|------|---------|
| 特征值 $\lambda$ | 方差解释量（PCA） |
| 特征向量 $\mathbf{v}$ | 数据变化的主方向（PCA） |
| SVD | 矩阵压缩、LoRA 的数学基础 |

### LoRA 为什么有效（SVD 直觉）

```mermaid
flowchart LR
    FULL["完整权重更新<br/>ΔW: d×k<br/>参数量 d×k"]
    LOW_RANK["低秩近似<br/>ΔW ≈ B·A<br/>B: d×r, A: r×k<br/>参数量 r(d+k)"]
    
    FULL -->|"SVD 分解<br/>只保留前 r 个分量"| LOW_RANK
    
    NOTE["r ≪ min(d,k)<br/>例如 r=16, d=k=4096<br/>压缩比 > 99.9%"]
```

> 📌 LoRA 的数学本质就是 SVD 的低秩近似。权重更新 ΔW 中最重要的信息集中在前 r 个奇异值方向上。详见 [[../06.大语言模型/6.5 LoRA高效微调]]
