# 《深海极速》



# 1. 开发概览
《深海急速》是一款于水下环境跑酷的游戏，在基于传统跑酷游戏玩法下，以海洋保护为主题，让玩家体验海洋环境的同时不失趣味。

该游戏的制作核心是水下人物动作与生态环境，需建立水下环境循环表现系统，保证主角人物与环境交互，在这些基础上加入跑酷冲刺的特殊表现

1.0版本前不考虑复杂动作和生态环境，以跑酷相关技术开发探索为主，先实现基本水下环境变化，游戏性硬相关交互逻辑的demo

1.0版本后加入养成、成就、背包这些游戏相关系统

2.0版本后加入联机联网相关功能

# 2. 虚拟故事背景
2100年，虽然人类科技发达，但仍然无法解决以往封存于海洋的化学污染物。为此，人类建造“星渊”管道、准备将历史污染物抛向深空时，所有人都将目光投向了星空。然而，真正的威胁却来自一个被遗忘的角落。

多年前，一处早期、简陋的实验性海底封存点“灰潮”，因记录丢失和技术迭代而被彻底遗忘。它的封存罐由已被淘汰的材料制成，内部封存的是第一代基因改造工业产生的特殊副产物——“惰性噬渊者”。

这种污染物特性极为隐蔽：常态下几乎不显示放射性，也难以被标准化学传感器探测。它只会缓慢地溶解在深海极压环境中，像沉重的墨水一样，在海底洼地悄然积聚，改变着深海微生物的基因，并通过食物链缓慢上行。

当“星渊”管道举行竣工典礼时，“灰潮”的泄漏已持续了数年。直到异常现象接连出现：远洋捕捞的鱼类行为诡异、深海潜艇遭到盲眼巨兽的莫名撞击、海底光缆被未知生物群集啃蚀……人类才意识到，有一个从未被监控的“幽灵污染源”正在苏醒。
为此，主角一行海洋生物学兼探险家进入海洋探寻解决此种灾难的办法，这期间，他们遭遇了海兽的袭击......

# 3. 流程
(1). 进入主菜单，主角在海面船上，显示功能菜单主界面进行下水准备，内容包括选择人物，选择开始地图，成就，金币数量，道具栏，任务栏，设置和帮助，玩家选择好人物及属性升级、地图配置局内道具摆件生成、道具的参数后进入地图开始一轮游戏

(2). 进入地图开始游戏，是一段被海兽冲散舰艇，众人带着牵引背包侥幸脱离撞击逃向不同方向的动画，而玩家操控的是被追击的人物

(3). 玩家操控主角被追击途中，可上下左右移动，越低速度越快，主角移动中躲避障碍，障碍阻拦追击的海兽，途中有可拾取的的道具迎面飘来，拾取后获得相应增益

(4). 在海路中穿梭，环境水体总体上从污染到清澈变化，正常鱼越来越多，速度越来越快，进入彻底清澈区域会迎来通关。

(5). 通关后会被救到船上，结算数据后重新回到主菜单做下水准备，反复下水跑酷会获取到一些特殊物体解锁故事碎片，达到碎片组合要求便解锁一个关卡或者结局，解锁一个结局后主菜单道具栏出现结局选项，解锁一个故事碎片后主菜单道具栏出现碎片选项。

# 4. 系统与机制
### (1). 核心玩法-矢量牵引背包
一个富有未来科技感的水下辅助移动背包，能源由“**人工生物发电共生植物群**”产生的能量提供
围绕玩家拥有可以用于快速穿梭于海洋的”**矢量牵引背包**“进行设计，即上下左右键能控制玩家上下左右移动。
移动途中靠近“**人工生物发电共生植物群**”获取能量，速度更快，反之速度变慢，植物群中有可能生成能量果实，拾取后增加速度能级。
穿梭途中需要玩家平衡上下关系，过上会慢，靠下虽然速度快，但障碍物变多，而障碍物不仅能阻拦自身导致速度变慢而形成威胁，也能躲过后获得对后方海兽减速的收益。

### (2). 水下移动
固定朝前移动，可以上下左右换朝向达到壁障目的，由”**牵引背包**“提供速度，产生水下气泡拖尾特效，水下水体扑面效果

### (3). 地图场景
##### ①. 水体环境路线 - 地图开发流程优化
水体环境路线是跑酷中的主体道路，分成路线段落，路线有若干段落，固定有一个全局段落为全局摆件生效，以路线段落中心为起点向后内含多种地图摆件，记录需触发的事件数据及索引，数据包括（坐标，摆件名称）

路线数据在一局游戏内分开加载，加载2段落，使用1个段落，预载1个段落。

##### ②. 摆件
包括以下摆件

- 起点：开局位置，同时预载玩家，地图数据

- 终点：通关点位

- “**人工生物发电共生植物群**”：普遍生长于海底表面，加速手段提供源，越靠近速度越快，有几率产生能量果实，占用一个段落，包含能量分布数据，即速度快慢变化参考数据

- 能量果实：有几率飘来，能增强背包功率进行加速

- 障碍物：玩家需躲避障碍物，对海兽降速，否则对自身具有较高减速惩罚，

- 碰撞墙：轻微10%降速惩罚，向路线中心拉回修正

- 检查点：画面效果

- 岔路口：配置路线切换

- 故事碎片：位置藏在通关描述中，拾取后组合碎片解锁新关卡或结局

- 景物：特殊复用摆件记录，无交互效果
