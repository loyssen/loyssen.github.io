## 二、SerialProtocolConfig — 串口协议格式

**创建方式：** Assets → Create → Device/SerialProtocolConfig

定义串口数据包的字节布局和校验规则。

### 2.1 数据包结构

```
接收数据包结构：
┌──────────┬──────────┬────────────┬──────────────┬──────────┐
│ 包头     │ 命令段   │ 玩家数据段 │ 固定段       │ 校验段   │
│ (header) │ (cmd)    │ (player×N) │ (fixed)      │ (check)  │
│ N 字节   │ N 字节   │ M 字节×10  │ N 字节       │ N 字节   │
└──────────┴──────────┴────────────┴──────────────┴──────────┘
```

### 2.2 接收配置（receive）

| 字段 | 类型 | 说明 |
|------|------|------|
| `headerHex` | string | 接收数据包头（16进制字符串，如 `55AAAA`） |
| `commandLength` | int | 命令段字节数（全局命令用） |
| `playerLength` | int | 每玩家数据段字节数 |
| `totalLength` | int | 包总长度（0=自动计算各段之和） |
| `verifyType` | enum | 校验方式：`None`(0) / `XOR`(1) / `CRC`(2) |

### 2.3 发送配置（send）

| 字段 | 类型 | 说明 |
|------|------|------|
| `headerHex` | string | 发送数据包头 |
| `totalLength` | int | 发送包总长度 |
| `commandLength` | int | 命令段字节数 |
| `playerLength` | int | 每玩家数据段字节数 |
| `verifyType` | enum | 发送校验方式（`XOR`=1） |

**VerifyType 枚举：**

| 值 | 名称 | 说明 |
|----|------|------|
| `0` | None | 无校验 |
| `1` | XOR | 异或校验（当前配置使用） |
| `2` | CRC | CRC 校验（预留） |

### 2.4 心跳配置（heart）

| 字段 | 类型 | 说明 |
|------|------|------|
| `enable` | bool | 是否启用心跳包 |
| `interval` | float | 心跳发送间隔（秒） |

## 三、OperationMapConfig — 通道映射配置

**创建方式：** Assets → Create → Device/OperationMapConfig

定义串口数据段中每个字节位对应什么 InputSystem 操作。

### 3.1 输入通道（inputChannels）

| 字段 | 类型 | 说明 |
|------|------|------|
| `channelName` | string | 通道名（与 InputAction 名称对应） |
| `type` | enum | Button / Value / Counter / Vector2 |
| `byteOffset` | int | 字节偏移 |
| `bitIndex` | int | 位索引（Button 类型用） |
| `isGlobal` | bool | 是否全局命令（走命令段而非玩家段） |

### 3.2 通道类型

| 类型 | 说明 | 输出值 |
|------|------|--------|
| `Button` | 单个 bit 位 | `bool` — 按下/松开 |
| `Value` | 多字节整数（1/2/4 字节） | `int` — 存入 `integers[]` |
| `Counter` | 2 字节计数器 | `int` — 自动计算增量差值 |
| `Vector2` | 自定义解析方向向量 | `Vector2` — 存入 `floats[]` |

### 3.3 典型通道配置示例

| channelName | type | byteOffset | bitIndex | isGlobal | 说明 |
|-------------|------|------------|----------|----------|------|
| fire | Button | 1 | 1 | false | 开火 |
| energy | Button | 1 | 0 | false | 切换炮等级 |
| coin | Button | 3 | 5 | false | 投币 |
| lotteryErr | Button | 3 | 4 | false | 彩票错误 |
| joystick | Vector2 | 2 | — | false | 摇杆方向（byteOffsetY 为 Y 分量偏移） |
| coins | Counter | 3 | — | false | 投币计数 |
| setting | Button | 3 | 7 | true | 全局设置 |
| up | Button | 3 | 6 | true | 全局上 |
| down | Button | 3 | 5 | true | 全局下 |

> **注意：** 具体 byteOffset/bitIndex 以 `OperationMapConfig.asset` 实际配置为准，上表为当前 serial1.6/serial2.2 版本的实际值。

### 3.4 输出通道（outputChannels）

输出通道使用模板 + 占位符填充，无需写代码即可添加新命令。

| 字段 | 说明 |
|------|------|
| `channelName` | 输出通道名（如 lottery） |
| `fixedData` | 固定字节数组 |
| `playerIdPositions` | 玩家 ID 填充位置索引 |
| `valuePositions` | 数值参数填充位置索引（每值占 2 字节） |

**模板示例（lottery 命令）：**

```yaml
- channelName: lottery
  fixedData: [7, 2, 0, 1, 0, 0]
  playerIdPositions: [2]        # 位置 2 填入玩家 ID
  valuePositions: [4]           # args[0] 写入位置 4-5（2字节）
```

**序列化后:** `07 02 [playerId] 01 [valLow] [valHigh]`

## 四、HardwareActions.inputactions — 输入动作资产

**创建方式：** Project 窗口右键 → Create → Input Actions

### 4.1 ActionMap 命名规则

| ActionMap 名 | 对应调用 | 说明 |
|-------------|---------|------|
| `P1` ~ `P10` | `P(1)` ~ `P(10)` | 玩家 1~10 的操作 |
| `Global` | `P(0)` | 全局操作 |

### 4.2 Action 命名

每个 ActionMap 中的 Action 名称必须与 `OperationMapConfig.inputChannels[].channelName` 完全一致：

| Action 名 | 类型 | 说明 |
|-----------|------|------|
| `fire` | Button | 开火 |
| `energy` | Button | 切换炮台等级 |
| `coin` | Button | 投币（单次） |
| `lotteryErr` | Button | 彩票错误 |
| `joystick` | Vector2 | 摇杆方向 |
| `coins` | Value | 投币计数 |
| `setting` | Button | 设置（全局） |
| `up` / `down` | Button | 上下（全局） |

设备绑定由 `OperationMap.BindActions()` 在运行时动态添加，不需要在 .inputactions 中手动配置设备绑定。

## 五、自定义解析与序列化

对于内置解析器无法处理的复杂通道，在 `SerialCustomParsers.cs` 的 `Init()` 中注册委托。

### 5.1 自定义输入解析

```csharp
// key = deviceLayoutName/channelName
ChannelParser.CustomParserRegistry["打鱼机/joystick"] = (data, last) =>
{
    byte b = data[0];
    bool right = (b & 0x10) != 0;
    bool up    = (b & 0x20) != 0;
    bool left  = (b & 0x40) != 0;
    bool down  = (b & 0x80) != 0;
    return new Vector2(right ? 1f : left ? -1f : 0f, up ? 1f : down ? -1f : 0f);
};
```

### 5.2 自定义输出序列化

```csharp
// key = deviceLayoutName/channelName, 委托签名: (ControlData data, int playerId) => byte[]
ControlSerializer.CustomSerializerRegistry["打鱼机/lottery"] = (data, playerId) =>
{
    var d = (LotteryControlData)data;
    return new byte[] { 0x07, 0x02, (byte)playerId, 0x01,
        (byte)(d.count & 0xFF), (byte)((d.count >> 8) & 0xFF) };
};
```
