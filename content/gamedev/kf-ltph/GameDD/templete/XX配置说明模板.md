## 二、数据格式

**文件位置：** `StreamingAssets/XX.json`

```json
[
    {
        "Id": "1001",
        "Name": "示例名",
        "Volume": 4
    }
]
```

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `Id` | string | 是 | — | 唯一标识 |
| `Name` | string | 是 | — | 名称 |
