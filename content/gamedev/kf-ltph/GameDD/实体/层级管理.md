# 层级管理

> 本文档描述 LayerManager 层级管理模块的设计。继承 `Module`，管理 Z 轴层级（Layer）的分配与释放。

---

## 一、系统概述

### 1.1 所属架构层级

Module — 独立的层级管理模块，通过 `this.GetModule<LayerManager>()` 获取。

---

## 二、公开 API

| API | 返回类型 | 说明 |
|------|---------|------|
| `AllocateLayer(int min, int max)` | int | 在 [min, max) 分配空闲层号。优先按 Spacing 间隔，间距不够时连续分配 |
| `FreeLayer(int layer)` | void | 释放指定层号 |

---

## 三、核心实现

### 3.1 层级区间定义

| 区间 | 范围 | 间距 | 用途 |
|------|------|------|------|
| UI / 特效 | 0~200 | 1 | 前景 UI 和特效层 |
| 特殊展示鱼 | 200~400 | 5 | Boss 展示、过场动画 |
| 群体鱼 | 400~500 | 3 | 鱼群共享层 |
| 个体鱼 | 500~800 | 3 | 个体鱼主层 |
| 海底背景 | 800~1000 | 1 | 背景装饰层 |

### 3.2 LayerConfig

```csharp
[Serializable]
public class LayerConfig
{
    public string Name;      // 区间名
    public int Min, Max;     // [Min, Max) 范围
    public int Spacing = 3;  // 分配间隔
}
```

Inspector 中可配置，默认 5 个区间定义。

### 3.3 分配算法

维护 `bool[1000]` 分配表。优先按 `LayerConfig.Spacing` 间隔扫描；间距不够时降级为连续分配；池满时自动重置该范围从头分配。

### 3.4 鱼的自定义覆盖

`Fish.LayerRange` 为非零 `Vector2Int` 时覆盖默认区间分配规则，允许特定鱼种使用自定义 Z 范围。
