# 对象模块

> 本文档描述 PawnModule 对象池管理模块的设计。提供基于双键索引 `(Type, pawnName)` 的 Pawn/Character/Effect 对象池系统，以及附属的路径生成和鱼生成系统。

## 二、核心接口

### 2.1 对象池 API

| API | 说明 |
|------|------|
| `RegisterPawn<T>(prefab, preloadCount)` | 注册预制体到池 |
| `Spawn<T>(pawnName)` | 分配实例，调用 `OnSpawn()` |
| `Despawn(pawn)` | 回收实例，调用 `OnDespawn()` |
| `GetRegisteredPawns()` | 遍历所有已注册预制体 |

### 2.2 双键索引

每个预制体以 `(具体子类类型, prefab.name)` 为主键注册。同时以一级分类类型（继承链中第一个继承 Pawn/Character 的类名，如 `TianWang` → `Fish`）注册别名池，共享同一底层池。

### 2.3 分组池

包含 `_` 后缀的预制体名（如 `MeiHouWang_01`, `MeiHouWang_fly`）自动建立分组。`Spawn<Fish>("MeiHouWang")` 精确匹配失败后在分组中随机选取变体。

### 2.4 PawnPool 内部

基于 `Stack<GameObject>`，后进先出。`Allocate()` 时 `SetActive(true)`，`Recycle()` 时 `SetActive(false)`。构造函数中按 `preloadCount` 预创建。

## 三、注册流程

```
预制体放 Resources/Actor/
  → PawnModule [从 Resources/Actor 扫描并分类] (Editor)
    → 按组件类型分类: Actor/Pawn/Character
    → RebuildTypeGroups() 按子类名分组
  → RegisterFromConfig()
    → RegisterInternal(具体类型, prefab.name, prefab, preloadCount)
    → RegisterInternal(一级分类类型, prefab.name, ...) // 别名共享池
    → 检测 "_" → 加入分组池
```

## 四、子系统

### 4.1 SplinePathSystem

路径生成系统。管理 SplinePath 对象池，提供 `BuildSpacedPath`/`SteerPoint`/`EmitEndpoint` 等路径生成方法。详见 [SplinePathSystem系统](SplinePathSystem系统.md)。

### 4.2 FishSpawnSystem

鱼生成代理系统。`Wave<FishEvent>.Execute` 通过此系统完成实际鱼/鱼群生成。惰性构建 FishData 缓存。详见 [FishSpawnSystem系统](FishSpawnSystem系统.md)。

---

## 五、配置

Inspector 配置三类预制体列表：`m_ActorConfigs`、`m_PawnConfigs`、`m_CharacterConfigs`。`TypeGroup` 按子类名分组展示（Fish/Effect/FishGroup 等）。
