# GameDM —— 开发管理（队长·任务指挥职责域）

> 本目录属于**队长（任务指挥，兼任务管理）**：统筹规划、任务拆解分派、进度跟踪、验收收尾。
> 其他员工只读；修改由队长执行；项目负责人可随时直接指示调整。

## 结构

- `开发管理.md` —— 文档进度总览（dataview）、进展摘要、里程碑、甘特图入口
- `任务/` —— 任务笔记（frontmatter: type/status/requester/start/end/depends/milestone），Task Gantt 扫描
- `甘特图` —— Obsidian 左侧栏 Task Gantt 插件（或命令面板打开），可视化全部任务时间线

## 协作规则（2026-08-17）

1. 员工间交流、发布任务/需求一律经队长转达统筹；未经项目负责人直接指示，员工不得绕过队长发布任务或需求
2. 项目负责人可随时直接指示/协同任何员工
3. 产出员工（策划/主程/工程师）发布任务/请求审查前先经负责人确认；队长收到已确认需求直接拆解分配
4. 验收闭环：员工完成 → 经队长转 requester 审核 → 通过后队长标 done
