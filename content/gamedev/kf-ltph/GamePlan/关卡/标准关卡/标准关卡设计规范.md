> [变更] v2.5 §六 设计流程重写：按当前机制（深度选种→触发链→白名单→云周期→密度→校验→编排）。

## 一、场上鱼数配比

| 类别 | 占比 | 50 条时 | 56 条时 | 备注 |
|------|:---:|:---:|:---:|------|
| 普通鱼 | **54%** | 26~28 | 30 | 数量由设计定，不强制偶数 |
| 进阶鱼 | **24%** | 12 | 14 | 数量由设计定，不强制偶数 |
| 奖励鱼 + 固定阵 | **18%** | 10 | 10 | 数量由设计定，不强制偶数 |
| Boss | **4%** | 2 | 2 | 固定 1 常驻 + 1 条件 |

> **总在场 50~60 条为硬性目标**（接近即可，允许一定偏差）；配比 54/24/18/4 为指导性，可调。

## 二、计算参考（密度估算）

```
在场数量 = 单次生成数量 ÷ 循环间隔 × 存活时间
```

- 存活时间 ≈ 路径长度 ÷ 速度（随机路径 ±30% 波动；Boss 由演出时间控制）
- 目标在场数 → 反推循环间隔：`循环间隔 = 单次数量 × 存活时间 ÷ 目标在场数`
- 每秒产出 = Σ(单次数量 ÷ 循环间隔)；每分钟价值 = Σ(价值 × 单次数量 ÷ 循环间隔) × 60

## 三、事件规则

### 3.1 单次生成数量

| 事件类型           |   数量   | 说明                     |
| -------------- | :----: | ---------------------- |
| 普通/进阶个体鱼       | ≥1    | 单次触发生成数量，按密度需求定（不强制偶数）     |
| 鱼群 / 阵型群 / 随机阵 |   1    | 一次一组，组内成员数由鱼群配置决定      |
| Boss           |   1    | 一次一条                   |
| 条件触发鱼（如螃蟹）     |   1    | 条件满足后生成                |
| **哨兵事件**       |   0    | 不生成实体，仅用于条件监听 + 触发其他事件 |


### 3.2 鱼群/阵型规则

- **复合形态规则**：群/阵/随机阵等复合形态**依附原始鱼种，不单独配置**——凡关卡鱼种池内的鱼种存在复合形态配置，必须全部启用（随机生成）；无复合配置的鱼种（如电鳗、奖励鱼）只有个体形态（见 [[关卡设计总纲#23-各深度鱼种池不含-boss|总纲 §2.3]]）
- 所有鱼族的群/阵**统一用组头随机**（不写死具体阵型）：
  - `{鱼名}群`：随机出该族 20 种自由群
  - `{鱼名}阵`：随机出该族 72 种阵型
  - `{鱼名}随机阵`：随机出该族全部 92 种变体
- 每族配置 3 个组头事件（群→阵→随机阵），初始时间错开 4 秒

### 3.3 时序约束

| 约束               |  值   |
| ---------------- | :--: |
| 5 秒内最多同时触发的阵型事件  |  ≤3  |
| 阵型事件最小间隔         | ≥40s |
| 同一鱼族 阵/随机阵 初始时间差 | ≥8s  |

### 3.4 命名规范

| 类别 | 名称来源 | 示例 |
|------|---------|------|
| 个体鱼 | 鱼数据的中文名 | `小剑鱼`、`黄金龟`、`龙` |
| 鱼群/阵群 | 鱼群配置的名称 | `小剑鱼群`、`小剑鱼阵`、`小剑鱼随机阵` |
| 条件事件（描述） | 触发目标鱼的中文名 | `螃蟹`、`紫金葫芦`、`美猴王` |
| 条件事件（击杀判定） | 触发目标鱼的**英文名** | `PangXie`、`ZiJinHuLu`、`MeiHouWang` |

> 文档中不得自行添加后缀/缩略（❌ `小剑鱼群随机`、`螃蟹(惩罚)`）；击杀判定一律用英文名（大小写敏感）。

### 3.5 条件事件链模式

| 模式              | 规则                       | 用例                    |
| --------------- | ------------------------ | --------------------- |
| **A 击杀停止循环**    | 事件循环出现，条件满足（目标被击杀）后停止    | 固定 Boss 每 75s 循环，击杀停止 |
| **B 条件触发+链**    | 哨兵事件（不生成鱼）监听条件，满足后触发目标事件 | 击杀鱼A → 触发鱼B出场         |
| **C 条件触发+延迟惩罚** | 条件满足后延迟 N 秒再执行           | 击杀螃蟹后 60s 惩罚刷新        |
| **D 远期等待链接管**   | 事件初始时间设很晚，实际由链触发提前接管     | 美猴王等待紫金葫芦被杀           |
| **E 时间窗限制**     | 给互斥链加时间窗，与固定 Boss 出场错开   | 紫金葫芦↔美猴王链限定在 200s 前   |

> **事件来源**：可用事件目录（事件名/目标/数量/间隔）见 [[事件表]]；具体触发链清单（固定 Boss 循环 / 条件 Boss / 惩罚链等）见 [[触发链]]，链的停止/循环规则以触发链为准。

## 四、排队鱼（随机自定义图形路径排队）

> 🆕 新增移动形态：一小队鱼沿**随机抽取的图形路径**排队行进，作为生态移动的补充（区别于默认的随机曲线游动）。

### 4.1 核心机制

| 规则 | 说明 |
|------|------|
| **随机图形路径** | 每次从预设图形路径库**随机抽一条**（圆/等距螺旋/正弦波，可选直线），不同批次随机更换 |
| **随机摆位** | 路径平移到场景活动范围（约 1/4 屏）内随机中心，并随机旋转；可选首/末段在限定角度内随机延伸 |
| **排队稳定** | 在**刷新周期**（如 30s，按关卡时间推进）内，同种鱼复用**同一条路径、同一速度**，依次入场形成整齐队形；周期到则清空重新随机 |
| **循环生成** | 与普通鱼一致按事件循环触发，每次触发生成一小队 |

### 4.2 设计建议

- **配比**：排队鱼计入普通鱼占比（54% 内），建议每关 1~2 个排队事件
- **队列规模**：单次 3~8 条同种鱼；间隔控制密集/疏散（同 [[鱼潮关卡设计规范#53-队列编排|鱼潮排队编排]]）
- **鱼种**：优先小体型鱼（小剑鱼/凤尾鱼/蝴蝶鱼），线条感强；不建议高价值鱼排队（价值感被稀释）
- **循环间隔**：按密度公式反推（`循环间隔 = 单次数量 × 存活时间 ÷ 目标在场数`），排队鱼存活时间 = 图形路径行走时间 + 入场总时长
- **特效鱼**：特效鱼仍用短路径快速穿过（展示特效），不参与排队

### 4.3 与鱼潮排队波次的区别

| 维度 | 标准关卡排队鱼 | 鱼潮排队波次 |
|------|--------------|------------|
| 路径选择 | **随机抽取**（每次不同） | 指定图形（精确编排） |
| 生成方式 | 循环生成（常态点缀） | 单次触发（演出编排） |
| 摆位 | 随机中心 + 随机旋转 | 按图形编排固定中心 |
| 定位 | 生态补充 | 视觉演出主体 |

## 五、切换白名单与云周期

> 细则见总纲 [[关卡设计总纲#22-切换规则|§2.2 切换规则]] 与 [[关卡设计总纲#三云周期节奏|§三 云周期]]，本节约要求。

### 5.1 切换白名单

- 每关必须明确：**解锁条件** + **可切换关卡列表**（深度白名单）
- 白名单内每个标准关 X 的**鱼潮关卡**自动加入候选池（若有）；鱼潮关候选池必含所属标准关（见总纲 §2.2）

### 5.2 云周期

- 每关必须明确节奏类型（常规 / 波动 / 放水）+ 强度，标准关卡默认**常规**

## 六、标准关卡设计流程

```mermaid
flowchart TD
    A[定关卡主题与深度等级 1/2/3] --> B[从深度池选鱼种<br/>个体鱼 + 奖励鱼；复合形态随选中鱼种自动启用]
    B --> C[配置触发链<br/>固定 Boss + 条件 Boss/惩罚链，见 [[鱼关卡/通用件/触发链]]]
    C --> D[配置切换白名单<br/>解锁条件 + 候选池（含鱼潮关联，见总纲 §2.2）]
    D --> E[配置云周期<br/>默认常规]
    E --> F[定密度与节奏<br/>目标在场 50~60 → 反推循环间隔<br/>可含排队鱼 1~2 队]
    F --> G{校验通过?<br/>鱼种在池 / 复合形态齐全 / 时序约束 / 数量规则}
    G -->|否| B
    G -->|是| H[编排事件时序<br/>触发时间排布]
    H --> I[输出关卡事件表<br/>事件名 + 触发时间]
```

## 七、验证清单

| 检查项 | 标准 |
|-------|------|
| 总在场鱼数 | 50 ≤ N ≤ 60（硬性目标，接近即可） |
| 普通鱼占比 | 49%~59%（指导） |
| 进阶鱼占比 | 19%~29%（指导） |
| 奖励鱼+固定阵占比 | 13%~23%（指导） |
| Boss 在场数 | 2（1 常驻 + 1 条件） |
| 群/阵/Boss/条件鱼 单次数量 | 1 |
| 哨兵事件 单次数量 | 0（不生成实体） |
| 5s 内阵型触发 | ≤3 |
| 鱼种是否在所属深度池内 | 是 |
| 排队鱼同种同路径同速度 | 周期内队形一致；混合队列速度一致 |
| 排队鱼事件数 | 建议 ≤2 个/关 |
| 切换白名单 | 已按总纲 §2.2 配置（解锁条件 + 候选池含鱼潮关联） |
| 云周期 | 节奏类型 + 强度已明确（标准关默认常规） |
