> 按 [[标准关卡设计规范]] v2.5 流程产出：深度池选种 → 触发链 → 白名单 → 云周期 → 密度 → 编排。10 关 = **3 套深度模板**（深1×3 关、深2×4 关、深3×3 关）+ 每关差异（Boss/白名单）。

## 七、校验结果

| 检查项 | 结果 |
|-------|------|
| 鱼种在所属深度池 | ✅ 模板全部取自深度池 |
| 复合形态全启用 | ✅ 选中鱼种有群/阵配置的族全部 3 组头启用 |
| 5s 内阵型触发 ≤3 | ✅ 族起始 12/15/18/21（深1）、12/16/20/24（深2/3），窗口均 ≤3 |
| 同族 阵/随机阵 初始差 ≥8s | ✅ 族内 +8s |
| 阵型循环间隔 ≥40s | ⚠️ 群循环 38s（微调 40s，落地时调整事件库） |
| 个体鱼数量 | ✅ ≥1（4/3/2 档），不强制偶数 |
| 群/Boss/条件鱼数量 =1、哨兵 =0 | ✅ |
| 估算在场 | 个体 ~16-20 + 奖励 ~2-3 + 群阵 4 族 ~15-20 + Boss 1 ≈ **40~45**（接近 50 目标） |
