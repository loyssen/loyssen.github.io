# 鱼生成触发链

> [变更] v1.1 链 5 刺豚高频链随 9111 金色龙宫海域删除而废弃（负责人裁定 2026-08-18，见 [[玩法系统/伤害系统/数值框架]]）。

> 所有关卡（标准/鱼潮）的鱼均由**关卡配置好的时序 + 对应触发规则**生成：时序事件按触发时间排布（见各关卡事件表），触发链按条件关联生成。本文档定义全部触发链——**每一条链一项，表格排布**，是触发类生成的权威清单。

---

## 一、生成规则说明

- 鱼的生成**不由任何逻辑主动决定**，全部由关卡配置驱动：① 时序事件（关卡事件表，到点生成）；② 触发链（本文档，条件满足生成）
- 触发链由事件组合实现：部分事件为**哨兵**（不生成鱼，仅监听条件并触发其他事件），部分事件实际生成鱼
- 链的"循环 / 停止"规则见各链条目；新增链只需在本文档追加一项，并同步设计层配置

## 三、各链详细说明

### 链 1：固定 Boss 循环（已实现）

| 项 | 规则 |
|----|------|
| 触发 | 关卡运行 200 秒后首次出场 |
| 生成 | 该关卡的固定 Boss（各关 Boss 见对应关卡文档） |
| 循环 | 约每 75 秒出现一次 |
| 停止 | Boss 被击杀后停止，并允许切换下一个关卡 |

### 链 2：螃蟹惩罚链（已实现）

| 项 | 规则 |
|----|------|
| 触发 | 玩家击杀螃蟹 |
| 生成 | 螃蟹 1 条 |
| 循环 | 击杀后延迟 60 秒生成；期间每 15 秒检查条件 |
| 停止 | 螃蟹被击杀后停止循环（等待下次击杀重新触发） |

### 链 3/4：紫金葫芦 ⇄ 美猴王互斥链（已实现）

| 项 | 规则 |
|----|------|
| 触发 | 击杀紫金葫芦 → 美猴王出场；击杀美猴王 → 紫金葫芦出场 |
| 生成 | 美猴王 / 紫金葫芦 |
| 循环 | 触发后循环出现 |
| 停止 | 各自被击杀后停止（互斥交替） |
| 限制 | 互斥链可加时间窗，与固定 Boss（200s 出场）错开 |

### 链 5：刺豚高频链（已废弃）

| 项 | 规则 |
|----|------|
| 触发 | 关卡开始即启用 |
| 生成 | 刺豚 3 条 |
| 循环 | 每 3 秒一次 |
| 停止 | 关卡结束 |
| 生效 | ~~金色龙宫海域~~（9111 已裁定删除 2026-08-18，链失效；保留条目备后续鱼潮关复用） |

### 链 6/7/8：条件 Boss 链（新策划）

条件 Boss 有统一规则：**触发后每分钟出现一次，击杀后停止出现，直到下次触发重新开始循环**。

| 链 | 触发条件 | 生成 | 生效范围 |
|----|---------|------|---------|
| 美猴王 | 紫金葫芦被击杀 | 美猴王 | 任何关卡 |
| 武则天 | 玉玺被击杀 | 武则天 | 深度 2、3 关卡 |
| 财神爷 | 奖励鱼（3xxx）被击杀 10 次（本关内累计，关卡重置） | 财神爷 | 深度 2、3 关卡 |

> "击杀"均指玩家击杀；条件 Boss 与固定 Boss 可同时在场（互不替代）。
