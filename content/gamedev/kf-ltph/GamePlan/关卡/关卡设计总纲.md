# 关卡设计总纲

> 鱼关卡域的**起始规范**：关卡总体目标/类型/深度切关体系/鱼种池/生成机制/鱼潮规则/数值供给。只定义关卡规则与需求，不含实现细节（数据结构/事件配置/GUID/代码模块见设计文档 [[../../GameDD/总体设计]] 与 [[关卡配置说明]]）；下游按 策划→设计→管理→开发 流程推进。

---

## 一、关卡类型体系

| 类型 | 定位 | 时长 | 内容构成 | 节奏 |
|------|------|:---:|---------|------|
| **标准关卡** | 常态主流程 | 10 分钟 | 个体鱼 + 鱼群/阵型 + Boss + 条件事件链 | 常规云周期 |
| **鱼潮关卡** | 奖励/视觉短关 | 0.5~1 分钟 | 全部为大型阵型群，图形化编排 | 高放水节奏 |
| **测试关卡** | 开发验证 | 不限 | 任意 | 任意 |

**类型差异规则：**

| 维度 | 标准关卡 | 鱼潮关卡 |
|------|---------|---------|
| 路径 | 随机路径为主，群阵用固定出入口 | 全部固定出入口 |
| 阵型选择 | 组头随机（同族多阵型随机出） | 指定具体阵型（精确编排） |
| 生成方式 | 持续循环生成 | 单次触发，按时间编排 |
| 个体鱼 | 有（占主体） | 无 |
| 云周期 | 常规 | 高放水（≈97% 回报） |

## 二、关卡深度体系

### 2.1 深度分级

10 个标准关卡分 3 个深度等级：

| 深度 | 关卡 |
| :-: | :--------------------: |
| 1 | 珊瑚浅海、朽木深渊、幽海草地 |
| 2 | 水下遗址、海底宝藏、恐龙遗址、水下遗址-景海 |
| 3 | 龙宫海域、宝藏海域、希腊神话 |

**深度含义**：深度越高，鱼种越丰富、价值越高、节奏越快。

### 2.2 切换规则

- 切换方向：**低 → 高 → 低** 循环（深度1 ⇄ 深度2 ⇄ 深度3）
- 每个关卡有**解锁参数**与**指定可切换的关卡列表**（白名单）
- 解锁判定**视场上实时数据**而定（如击杀 Boss、炒场期结束）
- 只有**已解锁**且**在白名单内**的随机关卡才能被切换
- **解锁条件语义分类**（负责人裁定，对应设计 12.6 待确认项 T1/T2/T3）：
  - 击杀 Boss 类 = **玩家级跨关成就**：击杀过即永久解锁，换关/换场不清除，存玩家持久状态
  - 炒场期结束类 = **本关内场级标志**：本场**至少进入过炒场期且炒场已结束**即解锁；本场置位后不再翻转，换关/换场重置（**非**「切关时刻不在炒场期」的实时快照）
  - 本关内计数类（财神爷等）= 关卡重置
- 炒场预算**每场重置**：云周期炒场预算每次换关独立，保证每场完整收放水节奏（引擎行为实测不符时按本语义修正）
- 成就位表**追加式扩展**：新成就按序占用新位，禁止重排/复用已发布位；解锁判定语义为「对应位已置位」（与位掩码整体值无关）

#### 鱼潮关 ⇄ 标准关 关联（候选池扩展）

- 标准关卡 A 的下个关卡候选池 = 深度白名单 [B、C…] + **白名单内每个标准关 X 的鱼潮关卡**（若存在，全部加入）
- 鱼潮关卡 X 的下个关卡候选池 = **所属标准关 X（必含）** + 其他另行策划的候选（**候选池内随机，不保证必切回标准关**）
- 切关链条示意：标准1 →（标准2 或其鱼潮关）→ 标准2 →（标准3 或其鱼潮关）→ 标准3 →（标准1 或其鱼潮关）→ …——鱼潮关是标准关之间的可选跳板，白名单内各候选（含其鱼潮关）随机选取，增加切关随机性

| 鱼潮关卡 | 所属标准关 |
| :---: | :---: |
| 9101 龙宫海域·鱼潮 | 9001 龙宫海域 |

> 9111 金色龙宫海域已删除（负责人裁定 2026-08-18，不参与核算与候选池）。

> 示例：9001 龙宫海域（深度 3）白名单 [珊瑚浅海、朽木深渊、幽海草地] → 候选池 = [珊瑚浅海、珊瑚浅海鱼潮(若有)、朽木深渊、朽木深渊鱼潮(若有)、幽海草地、幽海草地鱼潮(若有)]。鱼潮关候选池**必含**所属标准关（当前仅 9101 列表只有 9001，故总是切回；后续加入其他候选则随机）。

#### 首关与无人游玩回深度 1

- **首次进入**：游戏刚打开第一次进入的关卡 = **深度 1 可用关卡随机**（候选 = 深度 1 三关 [珊瑚浅海、朽木深渊、幽海草地] 中满足解锁条件的关卡；开局无成就时实际候选为珊瑚浅海、幽海草地，朽木深渊需击杀水下遗址 Boss 解锁后才会进入候选）——**不随机到深度 2/3**
- **无人游玩判定**：以 **Backend 后台会话**为边界——后台界面打开即视为无人游玩开始；后台关闭后的**下一次关卡加载**（Scene_Loading → PickNextLevel）强制回到深度 1
- **回深度 1 方式**：深度 1 可用关卡随机（同「首次进入」口径，候选为深度 1 三关中解锁条件满足者）
- **回到深度 1 后**：**继续正常白名单自动切关循环**（深度 1 → 白名单 → 深度 2 → …），不停驻、不等待投币——避免破坏自动切关机制
- 实现注意（供设计参考）：首次进入与后台返回均发生在 **Scene_Loading → PickNextLevel** 节点；「本次为首关/后台返回后首关」标志由流程提供，不改变现有白名单/解锁/候选池机制

### 2.3 各深度鱼种池（不含 Boss）

> **复合形态规则（重要）**：群/阵/随机阵/排队等复合形态**不单独配置**——鱼种池只列原始鱼种；凡池中列出的鱼种，只要存在复合形态配置（群/阵/随机阵），该关卡**必须全部启用**（随机生成）；无复合形态配置的鱼种（如电鳗、奖励鱼）自然只有个体形态。
> 例：深度 3 有小剑鱼 → 小剑鱼群、小剑鱼阵、小剑鱼随机阵、小剑鱼排队，必须全部出现；蝴蝶鱼同理。

> 每个关卡从所属深度的鱼种池中选取（可全选或子集，需在关卡文档中明确）。

### 2.4 鱼生成机制

> 标准/鱼潮关卡的鱼**全部由关卡配置好的时序和对应规则计算生成**（时序事件按触发时间排布，见各关卡事件表；触发链按条件关联生成）。**触发链清单见 [[触发链]]**——每一条链一项、表格排布（固定 Boss 循环 / 螃蟹惩罚 / 葫芦⇄猴王互斥 / 刺豚高频 / 条件 Boss 等），本文档不逐关罗列。

## 三、云周期节奏

云周期控制关卡**收水/放水的回报节奏**，三种类型：

| 类型                | 策划语义               | 适用       |
| ----------------- | ------------------ | -------- |
| **常规（Standard）**  | 稳定收放水交替，回报均衡       | 标准关卡     |
| **波动（Variation）** | 常规节奏的加强版：振幅更大、阶段更短 | 高难度/刺激关卡 |
| **放水（FishTide）**  | 短时间持续高回报，玩家获得感强    | 鱼潮关卡     |
|                   |                    |          |

每关可配置：节奏类型、强度（0.1~3.0）、目标回报点数（默认用全局配置）。

## 四、鱼潮关卡规则

> 鱼潮关卡为奖励/视觉短关（30s~1 分钟），全部固定出入口，单次触发不循环。详细设计约束见 [[鱼潮关卡设计规范]]（本节约概要）。

0. **关卡 ID**：鱼潮关 ID = 所属标准关 ID 百位 +1（9001→9101）；每场景/标准关最多 9 种变体（91xx~99xx）

1. **两种波次形态**：
   - **阵型波次**：整组同时生成，排成面状图形（矩形环/椭圆环/实心圆/填充阵列等）
   - **排队波次**：鱼沿固定图形路径逐条入场，线状流动（圆/等距螺旋/正弦波，同种鱼同路径同速度排队）
2. **出入口**：全部固定出入口，入口在**屏外至少 1 屏**外，保证滑入自然
3. **图形编排**：同一视觉中心的多个波次**同时触发**；可能重叠的图形**错开 1.5~3 秒**（排队与阵型 ≥2s）；外层先、内层后（嵌套）
4. **单次触发**：所有波次不循环，总时长 0.5~1 分钟
5. **鱼种选择**：聚焦 2~4 种鱼（外围轮廓用小体型多数量鱼，中心填充用高价值鱼）；不使用 Boss/奖励鱼
6. **云周期**：放水节奏（高回报 ≈97%）
7. **结束**：下个候选池**必含所属标准关**，候选池内随机（当前列表仅有标准关故总是切回；加入其他候选后随机选取，见 §2.2）
8. **经济豁免**：鱼潮关属于奖励关，不纳入普通关的攻击范围、收益和经济平衡约束（见 [[流程与视觉/流程/场景流程]] §三）；鱼潮关也投放附魔道具携带者（负责人终审确认）

## 五、标准关卡配置要求（每关必填清单）

设计一个标准关卡时，关卡文档必须明确以下内容：

|  #  | 要素    | 说明                                         |
| :-: | ----- | ------------------------------------------ |
|  1  | 深度等级  | 1/2/3，决定鱼种池与白名单                            |
|  2  | 鱼种清单  | 从所属深度池选取（个体鱼 + 奖励鱼），复合形态随鱼种自动启用            |
|  3  | 触发链   | 按 [[触发链]] 配置适用的链（固定 Boss / 条件 Boss / 惩罚链等） |
|  4  | 云周期   | 类型 + 强度                                    |
|  5  | 切换白名单 | 解锁条件 + 可切换关卡（含鱼潮关联，见 §2.2）                 |
|  6  | 场景风格  | 视觉/场景背景                                    |

**配比要求**（指导性原则，可调）：全场同时在场约 50~60 条；普通鱼约 54%、进阶鱼约 24%、奖励鱼约 18%、Boss 1~2 条；每种鱼除Boss奖励鱼之外在场数为尽量保证为偶数。
