# 鱼清单（FishActor 全实体清单）

> FishActor 全实体清单：每种鱼一条说明（价值/速度/等级/移动策略），并归纳其**种群类型**（该鱼种单一种类的群游/阵型/随机阵/固定阵/鱼潮阵等复合形态）。**多种鱼混合的鱼阵不计入任何鱼种的种群类型**；组头（Count=0）为随机索引，不注册实体。
> 基础实体语义见 [[实体/鱼/鱼]]，奖励鱼派生实体见 [[实体/鱼/奖励鱼]]。

## 数据源与多维表格引用（重要）

| 数据层 | 位置 | 说明 |
|--------|------|------|
| **多维表格（协作编辑源）** | `GameData/鱼种.duowei` | 鱼种表（FishActor 全字段：Id/Name/HP/Volume/Speed/Level 等），策划与数值在多维表格协作维护 |
| 编辑源（Luban 链路） | `DragonBreakSeaDoc/GameData/FishData.xlsx` → `Assets/StreamingAssets/luban/cfg_tbfishdata.json`（运行时产物） | 三表协作约定见 [[总体策划]] §七 |
| 本清单 | 策划可读汇总 | 价值/速度/等级等以数据源为唯一事实源，本清单做策划注解（移动策略、种群类型） |

> 约定：**数值字段（HP/Volume/Speed/Level 等）以 `鱼种.duowei` / 运行时 JSON 为唯一事实源**，本清单不重复维护数值总表（分档定价见 [[玩法系统/伤害系统/数值框架]] §四）；发现不一致以数据源为准并回改本清单。权威 ID 与配置文件分组见 §九。

## 六、奖励鱼价值计算（血量制 · 固定定值）

> 奖励鱼/Boss 鱼的击杀彩票值 = 该鱼**固定 Volume**（数据源配置值）；多阶段大奖演出保留，各阶段分值为**固定配置值**（原随机滚值与池健康度折减已随概率制退役）。

**结算规则**：

1. 击杀奖励鱼/Boss → 击杀者彩票值一次性计入该鱼 Volume
2. 大奖演出按该鱼的**定值序列**分阶段跳分（每阶段显示一个定值跳分数字）
3. 各阶段定值之和恒等于 Volume（配置约束）；演出只决定「分几次表现」，不改变总额

- 各鱼**定值序列总表**（14 prefab / 46 条目，Min=Max 定值、逐鱼 Σ=Volume 全闭合）见 [[实体/鱼/奖励鱼]] §三
- 定值规则（倍率条目退役处置、演出键连续性）见 [[实体/鱼/奖励鱼]] §三
- 未配置多阶段条目的奖励鱼：彩票值 = Volume 直配

> 跳分显示遵循 ScoreKeys 累加规则（分数1→分数2→分数3 依次累计）；原 Mul 倍率条目已全部改为定值占位（值 1~2，仅作演出键连续性，非倍率语义）。
