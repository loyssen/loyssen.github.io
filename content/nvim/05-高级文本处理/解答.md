## 题 81:提取错误日志

**操作解法(按键)**:文件只有 5 行,搜索 + 逐个删最快:

```
/\[INFO\]   搜索 INFO 行([ 和 ] 是正则字符类,必须转义)
dd          删除
n           跳下一条 INFO
dd          再删
n 和 dd 交替,直到 3 条 INFO 全部删完
```

**命令解法(推荐)**:`:v/\[ERROR\]/d` —— 一次删光所有非 ERROR 行。

| 部分 | 作用 |
|---|---|
| `:v` | 反向全局命令:对**不匹配**的行执行操作(和 `:g` 相反) |
| `\[ERROR\]` | 匹配字面 `[ERROR]`。`[` 和 `]` 在正则里是"字符集合"的语法,必须加 `\` 转义成普通字符 |
| `d` | 删除 |

> [!tip] 解法不唯一:把匹配行"复制"到新文件
> ```vim
> :g/\[ERROR\]/yank A      " 匹配的行逐行追加进寄存器 a(大写 A = 追加,不是覆盖)
> :enew                    " 开一个空文件
> "ap                      " 粘贴寄存器 a 的内容(空文件自带一空行,按 dd 删掉)
> ```
> 注意它复制的是**整行**(含 `[ERROR]` 前缀),适合"筛选出某类行"的场景。

## 题 82:日志时间戳对齐

> [!note] 本质命令题
> 键盘上没有"对齐"键,手工数每列最大宽度再补空格不现实——这正是 `:%!` 过滤器存在的意义。

**命令解法**:`:%!column -t`

| 部分 | 作用 |
|---|---|
| `:%!` | 把整个文件交给外部命令处理,输出替换回缓冲区(过滤器) |
| `column` | 按空格把每行拆成列,自动计算每列最大宽度 |
| `-t` | table 模式:把各列右补空格对齐 |

> [!tip] 只对齐选中的几行
> 可视模式选中几行后按 `:` ,命令栏自动变成 `:'<,'>!column -t`,此时只处理选中范围。

## 题 83:过滤特定日志级别

**操作解法(按键)**:文件只有 4 行,找到多余的两行删掉即可:

```
/^DEBUG   找到 DEBUG 行(^ 锚定行首)
dd        删除
/^INFO    找到 INFO 行
dd        删除
```

**命令解法(推荐)**:`:v/^\(WARN\|ERROR\)/d`

| 部分 | 作用 |
|---|---|
| `^` | 行首锚点,防止误匹配行中间出现的词 |
| `\(WARN\|ERROR\)` | 分组 + 或:`WARN` 或 `ERROR` 都算匹配 |
| `:v` + `d` | 对不匹配的行执行删除(等价于 `:g!` 反向全局) |

## 题 84:提取 URL 参数

**操作解法(按键)**:先把域名删掉,参数拆分交给替换命令:

```
f?   跳到 ?
d0   删到行首(把 https://example.com 整个删掉)
x    删掉剩下的 ?
```

**命令解法(推荐)**:纯 vim 三步:

```vim
:%s/.*?//
:%s/&/\r/g
:%s/\(.*\)=\(.*\)/\1: \2/
```

| 步骤 | 作用 |
|---|---|
| `:%s/.*?//` | `.*` 贪婪匹配到最后一个 `?`,把 `https://example.com` 部分整个删掉 |
| `:%s/&/\r/g` | 把参数分隔符 `&` 替换成换行(`\r` 写在替换串里 = 换行),一行变三行 |
| `:%s/\(.*\)=\(.*\)/\1: \2/` | 捕获等号两边的键和值,用 `\1: \2` 重排成 `键: 值` |

> [!tip] 解法不唯一:shell 管道版
> ```vim
> :%!cut -d'?' -f2 | tr '&' '\n' | awk -F= '{print $1": "$2}'
> ```
> 三条命令用 `|` 串起来:先按 `?` 切掉域名,再把 `&` 换成换行,最后按 `=` 拆开拼成 `键: 值`。`:%!` 会把 `|` 原样交给 shell 解释成管道。

## 题 85:URL 编码

> [!note] 本质命令题
> 百分号编码要按 ASCII 表逐字符查表,没有按键对应物,交给 python 一行脚本。

**命令解法**:

```vim
:%!python3 -c "import urllib.parse,sys;print(urllib.parse.quote(sys.stdin.read().strip(), safe=''))"
```

| 部分 | 作用 |
|---|---|
| `:%!python3 -c "..."` | 整文件交给 python 的一行脚本处理 |
| `sys.stdin.read().strip()` | 读入全部内容并去掉末尾换行 |
| `urllib.parse.quote(s, safe='')` | 百分号编码;`safe` 留空 = 除字母数字和 `_.-~` 外全部编码 |
| `%20` / `%26` / `%2F` | 空格、`&`、`/` 的编码结果 |

> [!warning] 必须写 `safe=''`
> `quote()` 的默认 `safe='/'` 不会编码斜杠,结果会得到 `special/chars` 而不是目标要求的 `special%2Fchars`。仓库提示里的 `quote(...)` 漏了 `safe=''`,照抄会不对。

## 题 86:URL 解码

> [!note] 本质命令题
> 逐段把 `%20` 还原成空格没有按键可言,`unquote()` 一行解决。

**命令解法**:

```vim
:%!python3 -c "import urllib.parse,sys;print(urllib.parse.unquote(sys.stdin.read().strip()))"
```

| 部分 | 作用 |
|---|---|
| `urllib.parse.unquote(s)` | 把 `%XX` 还原成原字符,是 `quote()` 的逆操作 |
| 其余 | 与题 85 相同:`:%!` 过滤 + `read()/print()` 收尾 |

> 与题 85 相互验证:编码后解码能还原原文,两道题合起来练一遍。

## 题 87:ENV 文件格式化

**操作解法(按键)**:只有 3 行,逐行改:

```
0iexport <Esc>   行首插入 "export "
f=a"<Esc>        光标移到等号,f= 跳到它,再 a 在等号后插入 "
A"<Esc>          行尾补一个 "
j                下一行,重复 3 次
```

**命令解法(推荐)**:`:%s/\([^=]*\)=\(.*\)/export \1="\2"/`

| 部分 | 作用 |
|---|---|
| `\([^=]*\)` | 第 1 组:等号前的键(`[^=]` = 非等号的任意字符) |
| `=\(.*\)` | 等号 + 第 2 组:等号后的所有内容 |
| `export \1="\2"` | 用捕获组重排成 `export 键="值"`,`"` 在替换串里是普通字符 |

## 题 88:YAML 缩进修复

**操作解法(按键)**:

```
j       光标下移一行(child1 行)
Vj      选中 2 行子项
>       右缩进(你的 shiftwidth = 2,一次正好 2 空格)
```

**命令解法(推荐)**:`:2,$s/^/  /`

| 部分 | 作用 |
|---|---|
| `2,$` | 行范围:第 2 行到文件尾,把 `parent:` 行排除在外 |
| `s/^/  /` | 在行首插入 2 个空格(`^` 匹配空串也能替换,这是"行首插入"的经典写法) |

> [!warning] 仓库提示的 `:%s/^  */  /g` 在本文件无效
> 这个模式是"行首一个或多个空格"(空格 + `*` = 至少一个),而本文件的子项行首是 **0 个**空格,匹配不上,结果什么都不改。给"没有缩进"的行加缩进,正确做法是用行范围(如上)或选中子项行后按 `>`。

## 题 89:配置项对齐

> [!note] 本质命令题
> 要对齐到"最宽键 + 2 空格",宽度要现数、每行要现补——交给 python 算。

**命令解法**:

```vim
:%!python3 -c "import sys;[print(k.ljust(7)+'= '+v) for l in sys.stdin.read().splitlines() for k,v in [l.split('=',1)]]"
```

| 部分 | 作用 |
|---|---|
| `l.split('=',1)` | 每个键值对按 `=` 拆成两部分(只拆第一个 `=`) |
| `k.ljust(7)` | 键左对齐补空格到 7 位(最宽键 `email` 5 个字符 + 2 内边距) |
| `'= ' + v` | 拼上 `= 值` |

> [!tip] 解法不唯一
> 纯 vim 也能做,用表达式替换 + `printf` 补宽:
> ```vim
> :%s/\([^=]*\)=\(.*\)/\=printf('%-7s= %s', submatch(1), submatch(2))/
> ```
> 注意 `:%!column -t -s'='` 虽然能对齐,但会**丢掉 `=` 分隔符**(输出 `name   John`),不满足目标。

## 题 90:提取所有邮箱地址

> [!note] 本质命令题
> "只取匹配部分"靠 grep -o 切子串,按键只能复制整行,切不出 `@` 后面的部分。

**命令解法**:

```vim
:%!grep -oE '[a-zA-Z0-9._\%+-]+@[a-zA-Z0-9.-]+\.[a-zA-Z]+'
```

| 部分 | 作用 |
|---|---|
| `:%!grep -oE` | 过滤整个文件;`-o` = 只输出匹配到的部分(而不是整行),`-E` = 扩展正则 |
| `[a-zA-Z0-9._%+-]+@` | 邮箱"用户名"部分:字母数字加 `._%+-`,至少 1 个,后跟 `@` |
| `[a-zA-Z0-9.-]+\.` | 域名部分(允许 `-` 和 `.`)+ 转义的字面点 |
| `[a-zA-Z]+` | 顶级域名后缀,如 `com`、`org` |

> [!warning] 实测:字符类里的 `%` 必须转义成 `\%`
> `:%!` 会先把 `%` 展开成当前文件名,所以字符类 `[a-zA-Z0-9._%+-]` 里的 `%` 会被替换成文件路径,
> 字符类直接变形,grep 报 `Invalid range end`,命令失败。
> 写成 `\%` 才能把字面 `%` 传给 grep。其余字符没有这种特殊含义,不用转义。

> [!tip] 解法不唯一:寄存器法
> ```vim
> :g/@/yank A
> :enew
> "ap
> ```
> 把含 `@` 的整行追加进寄存器 a 再粘贴。注意它是整行复制,会把 `Contact: ` 前缀也带走,适合"按行筛选",不适合本题这种"只要匹配部分"。

## 题 91:提取所有 IP 地址

> [!note] 本质命令题
> "只取 IP、丢掉前缀"没有按键操作可言,grep -oE 是正解。

**命令解法**:

```vim
:%!grep -oE '[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}'
```

| 部分 | 作用 |
|---|---|
| `[0-9]{1,3}` | 1~3 位数字(IP 的每一段),`{1,3}` = 重复 1 到 3 次 |
| `\.` | 转义的字面点,只匹配 `.`(不转义的话 `.` 匹配任意字符,会把别的数字也吞进来) |
| 四段连写 | 标准 IPv4 形状:数字.数字.数字.数字 |

## 题 92:提取所有数字

> [!note] 本质命令题
> 从 `Price: $99.99` 里只抠出 `99.99`,按键做不了,交给 grep -oE。

**命令解法**:

```vim
:%!grep -oE '[0-9]+\.?[0-9]*'
```

| 部分 | 作用 |
|---|---|
| `[0-9]+` | 至少 1 位数字(整数部分) |
| `\.?` | 可选的小数点(`?` = 出现 0 或 1 次),有它才能匹配 `99.99` |
| `[0-9]*` | 0 个或多个小数位,配合上面让 `5`(无小数点)也能匹配 |

> `$`、`Price:` 等符号不是数字,不会被匹配出来;`99.99` 会整体被提取(贪婪匹配尽量多)。

## 题 93:对齐表格列

> [!note] 本质命令题
> 列宽要按最宽内容现算,键盘没有"自动对齐"键,交给 python 算宽补宽。

**命令解法**:

```vim
:%!python3 -c "import sys;c=[[x.strip() for x in l.split('|')] for l in sys.stdin.read().splitlines()];w=[max(len(r[i]) for r in c) for i in range(len(c[0]))];[print(' | '.join(r[i].ljust(w[i]+1) if i==0 else r[i].ljust(w[i]) if i<len(w)-1 else r[i] for i in range(len(w)))) for r in c]"
```

| 部分 | 作用 |
|---|---|
| `l.split('|')` + `x.strip()` | 每行按 `|` 拆成单元格并去掉两侧空格 |
| `w=[max(len(r[i]) for r in c) ...]` | 自动算出每列最宽内容的长度 |
| `r[i].ljust(w[i])` | 单元格左对齐补空格到列宽 |
| `' | '.join(...)` | 用"空格\|空格"重新拼回表格;首列多补 1 位、末列不补,才与目标一致 |

> [!tip] 解法不唯一
> 快速但会丢分隔符:`:%!column -t -s'|'`(对齐效果有,但 `|` 会消失,不满足本题目标)。纯 vim 也能做——用表达式替换补宽:
> ```vim
> :%s/^\([^|]*\)/\=printf('%-6s', submatch(1))/
> :%s/| \([^|]*\) |/\=printf('| %-3s', submatch(1)) . ' |'/
> ```
> 宽度 6 / 3 是按本文件最宽内容算出来的,换文件要重数。

## 题 94:添加表格边框

> [!note] 本质命令题
> 每条边框线的长度取决于各列宽度,手工画必错,交给 python 现算现画。

**命令解法**:

```vim
:%!python3 -c "import sys;r=[l.split() for l in sys.stdin.read().splitlines()];w=[max(len(x[i]) for x in r) for i in range(len(r[0]))];b='+'+'+'.join('-'*(n+2) for n in w)+'+';print(b);[print('| '+' | '.join(c.ljust(w[i]) for i,c in enumerate(l))+' |') for l in r];print(b)"
```

| 部分 | 作用 |
|---|---|
| `l.split()` | 每行按空格拆成单元格 |
| `w=[max(len(x[i]) ...)]` | 每列最宽内容的长度 |
| `'| '+' | '.join(c.ljust(w[i]) ...)+' |'` | 单元格补宽到列宽,拼成 `| 内容 | 内容 |` 行 |
| `b='+'+'+'.join('-'*(n+2)...)` | 边框线:每个单元格宽度 + 2 个内边距空格换成 `-`,首尾和交界处是 `+` |

> [!tip] 备选
> 小表格可以直接手动敲边框;仓库解法用的 vim-table-mode 插件(`:TableModeEnable`)你还没装,装了之后它会自动维护边框和对齐。

## 题 95:表格转 CSV

> [!note] 本质命令题
> 一条正则替换就能吞掉管道和两侧空格,按键逐个删会删到怀疑人生。

**命令解法**:

```vim
:%s/ *| */,/g
:%s/^,//
:%s/,$//
```

| 步骤 | 作用 |
|---|---|
| `:%s/ *| */,/g` | 把"管道及其两侧的所有空格"整体换成逗号(模式 = 零或多个空格 + `|` + 零或多个空格) |
| `:%s/^,//` | 删掉行首多余的逗号(来自表格最左边的 `| `) |
| `:%s/,$//` | 删掉行尾多余的逗号(来自表格最右边的 ` |`) |

> [!warning] 别用"先删管道再换逗号"的两条
> 仓库提示的 `:%s/| //g` + `:%s/ |/,/g` 顺序会留下空格:前者删"管道+空格"时管道**前面**的空格还在,后者换逗号时逗号**后面**的空格也在,结果会得到 `Name Age City,` 这种残废串。正确做法是让 `*` 把管道两侧的空格一次吃掉。

## 题 96:生成函数文档

**操作解法(按键)**:手动输入 docstring(neogen 插件未装,仓库解法用不了):

```
O              光标在 return 行,按 O(大写 = 上方)插入新行,进入插入模式

Calculate the total price after discount.<CR>
<CR>           空一行(正文与 Args 之间的惯例留白)

## 题 98:匹配并替换模式

> [!note] 本质命令题
> 正则替换是命令的领域,按键没有对应物。

**命令解法**:

```vim
:%s/file_2024_\(\d\{2\}\)_\(\d\{2\}\)/file_2024-\1-\2/
```

| 部分 | 作用 |
|---|---|
| `\(\d\{2\}\)` | 第 1 组:恰好 2 位数字(`\d` = 数字,`\{2\}` = 恰好 2 次,花括号要转义) |
| `_\(\d\{2\}\)` | 下划线 + 第 2 组(月份) |
| `file_2024-\1-\2` | 用两个捕获组重拼,两个下划线都变成 `-` |

> [!warning] 只用一个捕获组的写法会翻车
> `:%s/file_2024_\(\d\{2\}_\d\{2\}\)/file_2024-\1/` 只替换了 `2024` 后那一个下划线,捕获组内部的下划线会原样带回,得到 `file_2024-01_01.txt`,和目标不一致。要替换两处,就得分两组捕获。

## 题 99:提取匹配组

> [!note] 本质命令题
> 捕获组 + 重排是正则替换的看家本领,按键做不了。

**命令解法**:

```vim
:%s/User: \(\w*\) (age: \(\d*\))/\1 is \2 years old/
```

| 部分 | 作用 |
|---|---|
| `\(\w*\)` | 第 1 组:名字(`\w` = 字母数字下划线) |
| ` (age: ` | 字面文本,注意 `(age:` 前面有一个空格,必须原样匹配 |
| `\(\d*\)` | 第 2 组:年龄数字 |
| `\1 is \2 years old` | 用两个捕获组把信息重组成句子 |

## 题 100:条件替换

> [!note] 本质命令题
> 两条替换命令各自匹配不同前缀,实现"条件"替换;按键逐行改也能做,但命令一次搞定。

**命令解法**:

```vim
:%s/^TODO: /[ ] /
:%s/^DONE: /[x] /
```

| 部分 | 作用 |
|---|---|
| `^TODO: ` | 行首锚点 + 字面前缀,确保只改行首的标记,不动行内容里的单词 |
| `[ ] ` | 替换串里的 `[ ]` 是普通字符,没有正则含义(正则的特殊含义只作用于**模式**里) |
| 两条命令 | 各自匹配不同前缀,实现"条件"替换 |

> [!tip] 加 `c` 逐个确认
> 在命令末尾加 `c`(`:%s/^TODO: /[ ] /c`)会逐个询问 y/n,适合替换前想人工确认的场景。
