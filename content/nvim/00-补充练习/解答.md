## 题 1:移动键位速查(4 关指法练习)

> [!note] 本质按键题
> 速查卡设计在教学中,这里补每个键位的操作详解。没有"解法",只有练熟:
> 每关的文件只是提示词,对着它把键位按一遍,练到不用想。

### 关卡 1:横向移动详解

| 键 | 操作要点 |
|---|---|
| `h` `l` | 逐字符左 / 右移。一次只移一位,按住不放是新手习惯 |
| `f` + 字符 | 跳到本行下一个该字符;按 `;` 重复上一个 f/t |
| `F` + 字符 | 向左找字符,`;` 同样重复 |
| `t` + 字符 | 跳到该字符**前一个**位置(till);配 `dt`/`ct` 使用 |
| `T` + 字符 | 向左 till |
| `w` `e` `b` | 按词移动:词首 / 词尾 / 回词首;标点(`,`)也是一个词 |
| `W` `E` `B` | 按 WORD 移动:只看空格分词,标点不挡路 |
| `0` `^` `$` | 行首 / 行首第一个非空字符 / 行尾 |

练习心法:每次移动前先想"我要到哪个粒度"(字符 / 词 / 行),再选键。

### 关卡 2:纵向移动详解

| 键 | 操作要点 |
|---|---|
| `j` `k` | 下 / 上一行 |
| `gg` `G` | 文件第一行 / 最后一行;`50G` 直达第 50 行 |
| `5j` `5k` | 数字前缀一次移多行,不必连按 |

### 关卡 3:查找跳跃详解

| 键 | 操作要点 |
|---|---|
| `/` `?` | 向后 / 向前搜索;`n` `N` 下一个 / 上一个匹配,循环搜索 |
| `*` `#` | 搜索光标下的**整个单词**(精确匹配),向后 / 向前 |
| `%` | 配对括号间跳转(`(` `)` `{` `}` `[` `]`) |
| `;` | 重复上一次 `f`/`t`,连续跳同一行里的相同字符 |
| `<leader><leader>` | 快速找文件(常见配置绑定 telescope find_files) |
| `<leader>sw` | 搜索光标下的单词 |
| `<leader>sg` | 全局搜索字符串 |

> `<leader>` 键位依赖你已装的 telescope,映射以你的配置为准,用 `:map <leader>` 自查。

### 关卡 4:标记跳跃详解

| 键 | 操作要点 |
|---|---|
| `m` + 字母 | 在光标处设标记(如 `ma`),标记随文件保存 |
| `'a` | 跳到标记 a 所在行的行首 |
| `` `a `` | 跳到标记 a 的精确位置(精确到列) |
| `''` | 跳回上一次的位置 |

练习:文件里设 `ma` `mb`,来回跳;再配合 `%` 在括号对之间跳,体会"跳转不走回头路"。

## 题 2:交换列

**操作解法(按键)**(块操作法,进阶):光标移到第一行第 3 列首字符:

```
0f,f,l            " 0 行首;f, 找第 1 个逗号;再 f, 找第 2 个逗号;l 到 tree
Ctrl+v  11j  4l   " 块选 12 行 × 5 列("tree," 整块)
d                 " 剪下整块
gg0P              " 回到文件头行首粘贴
```

**命令解法(正则法,推荐)**:一次搞定:

```
:%s/\([^,]*\),\([^,]*\),\([^,]*\),\([^,]*\)/\3,\1,\2,\4/
```

| 部分 | 作用 |
|---|---|
| `\([^,]*\)` | 捕获组:一个"列"(不含逗号的连续字符) |
| `\1`-`\4` | 引用第 1-4 个捕获组 |
| `\3,\1,\2,\4` | 输出顺序:第 3 列、第 1 列、第 2 列、第 4 列 |
| `Ctrl+v` | 块可视:按列选中矩形区域 |
| `11j` `4l` | 选中 12 行、"tree," 5 个字符宽 |
| `d` + `gg0P` | 剪切整块,回到文件头行首粘贴 |

> [!tip] 举一反三
> 交换第 2、4 列,把替换串改成 `\1,\4,\3,\2` 即可。这就是"正则重排列"的套路。

## 题 3:交换单词

**操作解法(按键)**(全部为词级操作,已实测):

```
" 第 1 步:mete → meet(xp = 交换光标字符和右邻字符)
ggft;xp    " gg 到文件头;ft 找第 1 个 t;再按 ; 找第 2 个 t(mete 里);xp 交换

" 第 2 步:交换第 1、2 行
ddp        " dd 删除当前行,再 p 粘到下一行下方

" 第 3 步:this is → is this
3G0ww      " 到第 3 行行首,ww 前进两个词("3" 和 "." 各算一个词)到 this
dwwP       " dw 剪下 "this ";w 跳到 is;P 粘到 is 前面

" 第 4 步:this 移到句尾
bh         " b 回词首,h 到 this 前面的空格
daw        " 剪下 " this"(连前导空格一起)
$P         " 到行尾 ? 前粘贴

" 第 5 步:交换参数(arg1, arg2, arg3 → arg3, arg2, arg1)
4G0f(l     " 到第 4 行,0 行首,f( 找左括号,l 到 arg1
d2w        " 剪下 "arg1, "(词+逗号+空格)
ww         " 跳过 arg2 和逗号,到 arg3
P          " 粘到 arg3 前 → (arg2, arg1, arg3)
bbb        " 退到 "arg2," 后的逗号上
dt,        " 剪下 ", arg1"(从逗号剪到下一个逗号前)
ww         " 到右括号 )
P          " 粘到 ) 前 → (arg2, arg3, arg1)
0f(l       " 回到 arg2
d2w        " 剪下 "arg2, "
ww         " 跳过逗号到 arg1
P          " 粘到 arg1 前 → (arg3, arg2, arg1)
```

**关键命令解析**:

| 命令 | 作用 |
|---|---|
| `xp` | 交换光标字符和它右边的字符(相邻字符互换) |
| `ddp` | 删除当前行再粘贴到下方 = 交换相邻两行 |
| `dwwP` | 剪下当前词(含空格),粘到后两个词之间 = 相邻词交换 |
| `daw` | 剪下"一个词 + 一个相邻空格"(本课利用它连前导空格一起剪) |
| `d2w` | 剪下两个词(含中间的逗号、空格) |
| `dt,` | 从光标剪到下一个逗号前(不含逗号) |
| `P` / `p` | 在光标前 / 光标后粘贴 |
| `b` `e` `w` | 回词首 / 到词尾 / 到下一个词首 |

> [!warning] 词的定义
> nvim 里 `,`、`(`、`)` 这类标点也是独立的"词",所以 `w` 要多按一次才能跳过逗号。第 5 步里 `d2w`、`ww` 都是这个原因。

## 题 4:分割合并行

**操作解法(按键)**:

```
" 第 1 步:把每个空格替换成换行
:%s/ /\r/g

" 第 2 步:合并回一行,保留空格
ggVGJ

" 第 3 步:先撤销回 5 行,再合并成一行,不留空格
u
ggVGgJ
```

> [!warning] 第 3 步前必须先撤销
> `J` 之后文件只剩一行,此时再 `gJ` 没有对象可合并。
> 先 `u` 撤销回拆行后的 5 行,再 `ggVGgJ` 才是真正的"无空格合并"。

**关键命令解析**:

| 命令 | 作用 |
|---|---|
| `:%s/ /\r/g` | 把每个空格替换成换行符(`\r` 在替换串里就是换行) |
| `ggVG` | 行可视选中整个文件:gg 文件头、V 行选、G 到文件尾 |
| `J` | 把选中的行合并成一行,行之间加一个空格 |
| `gJ` | 同 `J`,但不在行之间加空格 |

## 题 5:反转行(阅读理解题)

> [!note] 本质命令题
> `:%!tac` 只有一行,但它是"外部命令过滤"的代表:`:%!命令` 把整文件交给
> 外部程序处理,用它的输出替换原文。以后整理代码、清洗数据都能用上。

**命令解法**(在测试缓冲里验证):

```
:new              新开一个测试窗口
i 几行内容 <Esc>   输入几行文本
:%!tac            行序反转(最后一行变第一行)
:%!sort           按字母序排序
:%!tr a-z A-Z     全部转大写
```

| 部分 | 作用 |
|---|---|
| `%` | 范围 = 整个文件 |
| `!` | 过滤器:把范围内的文本交给外部命令处理,用它的输出来替换 |
| `tac` | `cat` 倒着写 = 反向输出行(最后一行变第一行) |
| `sort` | 排序(系统自带) |
| `tr a-z A-Z` | 字符转换:小写转大写 |

> [!tip] 一技通百技
> `:%!命令` 可以把文本交给任意外部命令处理。以后整理代码、清洗数据都能用上。

## 题 6:插入空格空行

**命令解法**:

```
" 第 1 步:逗号后加空格
:%s/,/, /g

" 第 2 步:给前 5 行行尾加换行(变成空行)
:1,5s/$/\r/
```

> 第 2 步用范围 `1,5` 而不是 `%`:如果给最后一行也加空行,文件末尾会多出一个空行。

**关键命令解析**:

| 命令 | 作用 |
|---|---|
| `:%s/,/, /g` | 全文件把每个逗号替换成"逗号+空格" |
| `:1,5s/$/\r/` | 第 1-5 行:把行尾 `$` 替换成换行 = 每行后面多一个空行 |
| `\r` | 替换串中的换行符 |

## 题 7:文本排序

**命令解法**:

```
:sort              " 第 1 步:升序
:sort!             " 第 2 步:降序
:sort /^[^,]*,/    " 第 3 步:匹配"第一列+逗号",排序键从匹配之后开始 = 第 2 列
```

**关键命令解析**:

| 命令 | 作用 |
|---|---|
| `:sort` | 按字母序排序(整个文件或选中范围) |
| `:sort!` | 降序(`!` 取反) |
| `:sort /pattern/` | 按 pattern 决定排序键 |
| `^[^,]*` | 行首到第一个逗号(第一列) |
| `:sort /^[^,]*,/` | 排序键 = 匹配之后的内容,即从第 2 列开始比较 |

## 题 8:更改大小写

**操作解法(按键)**:

```
gUU               " 第 1 步:整行大写
guu               " 第 2 步:整行小写
gg0~ww~ww~        " 第 3 步:how→How、title→Title、sentence→Sentence
                  "   ~ 反转光标字符大小写;w 跳到下一个词首,跳过不动的 to/a
g~~               " 第 4 步:整行大小写反转
```

**关键命令解析**:

| 命令 | 作用 |
|---|---|
| `gU` / `gu` | 大写 / 小写;跟移动一起用:`gUw` 大写一个词,`gUU` 大写整行 |
| `g~` | 大小写反转;`g~~` 反转整行 |
| `~` | 反转光标下的一个字符 |
| `~ww~ww~` | 在要改的词首按 `~`,用 `w` 跳到下一个词首,跳过 `to`/`a` |

## 题 9:添加序列号

> [!note] 本质命令题
> 逐行手工加序号没有"操作"可言,这类批量加工正是命令的用武之地。

**命令解法**:

```vim
" 递增
:let i=1 | g/^/s//\=i.". "/ | let i=i+1

" 先撤销回原状,再递减
u
:let i=12 | g/^/s//\=i.". "/ | let i=i-1
```

> [!warning] 递减前必须先撤销
> 递增之后行首已经带了编号,直接跑递减会在原编号前再叠一层
> (得到 `12. 1. word...`)。`u` 撤销回原始文件后再递减。

**关键命令解析**:

| 部分 | 作用 |
|---|---|
| `:let i=1` | 定义计数器变量 |
| `g/^/命令` | 对每一行执行后面的命令 |
| `s//\=i.". "/` | 行首替换,替换内容用表达式 `\=` 动态生成(`i` 拼上 `". "`) |
| `\|` | 管道符:把 `let i=i+1` 挂到同一行命令里,跟着 `g` 每行执行一次 |
| `.` | 字符串拼接运算符 |

> 记忆:先 `:let i=1`,再全局替换用 `\=i`,最后 `let i=i+1`——三件套。

## 题 10:生成键值对(重点题,8 个递进文件)

> [!note] 本质命令题
> 拆行、加引号、重组字段全是正则的领域。6 个阶段 8 条命令,一条条拆开看,
> 每步结果与下一个文件(1001-1007)逐字一致。

**命令解法(阶段 1-3,从 1000 号文件开始)**:

```vim
" 阶段 1:每两个词拆成一行(第 2 个逗号替换成换行)
:%s/\([^,]*\),\([^,]*\),/\1,\2,\r/g

" 阶段 2:加引号变成键值对
:%s/\([^,]*\),\([^,]*\),\?/"\1":"\2",/
:$s/,$//          " 最后一行本来没有尾逗号,去掉补出来的逗号

" 阶段 3:只取 value
:%s/"\([^"]*\)":"\([^"]*\)",\?/\2/
```

**命令解法(阶段 4-6,从 1004 号文件开始)**:

```vim
" 阶段 4:以"逗号+空格"为界拆成键值对
:%s/\(.*\), *\(.*\)/"\1": "\2",/

" 阶段 5:全部缩进 4 格,首行前加 mapping = {,尾行后加 }
:%s/^/    /
:1s/^/mapping = {\r/
:$s/$/\r}/

" 阶段 6:只取 value,删掉首尾行
:%s/^    ".*": "\(.*\)",$/\1/
:g/^mapping = {\|^}/d
```

**关键命令解析**:

| 部分 | 作用 |
|---|---|
| `\([^,]*\)` | 捕获组:不含逗号的一段 |
| `\r` | 替换为换行(用来拆行) |
| `,\?` | 逗号可有可无(最后一行没有尾逗号) |
| `\(.*\), *\(.*\)` | 贪婪匹配:以"逗号 + 空格"为界把一行分成两段 |
| `:1s/^/mapping = {\r/` | 在第 1 行行首插入 `mapping = {` 和换行 |
| `:$s/$/\r}/` | 在最后一行行尾追加 `}` |
| `:g/^mapping = {\|^}/d` | 全局删除匹配的行(去掉表头和表尾) |
| `\|` | 正则里的"或" |
