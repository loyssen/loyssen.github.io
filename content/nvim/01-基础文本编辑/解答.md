# 01 基础文本编辑 · 解答

## 题 1:删除空行

**操作解法(按键)**:

```
/^$        搜索空行(^ 行首 + $ 行尾 = 空行)
n          跳到下一个空行
dd         删除空行
n 和 dd 交替按,直到底部提示"找不到"
```

**命令解法(进阶)**:`:g/^$/d` —— 全局匹配空行并删除,一次搞定。

> 原理:空行 = 行首到行尾之间什么都没有。

## 题 2:删除重复行

**操作解法(按键)**:

```
/NVIM v0.9.0   搜索目标行
n              跳到第二处重复
dd             删除它
```

**命令解法(进阶)**:`:sort u` —— 排序并去重。

> [!warning] 注意副作用
> `:sort u` 会打乱行序。只要去重、不排序时,用按键法逐个删。

## 题 3:添加递升/递减序号

> [!note] 本质命令题
> 逐行手工加序号没有"操作"可言,这类批量加工正是命令的用武之地。

**命令解法**:

```vim
" 递增
:let i=1 | g/^/s//\=i." "/ | let i=i+1

" 递减
:let i=4 | g/^/s//\=i." "/ | let i=i-1
```

| 部分 | 作用 |
|---|---|
| `:let i=1` | 定义计数器变量 |
| `g/^/s//\=i." "/` | 全局每行替换,内容用表达式 `\=i." "` 生成 |
| `\|` | 管道符,一行里依次执行多个命令 |
| `let i=i+1` | 计数器递增 |

> 记忆:先 `:let i=1`,再全局替换用 `\=i`,最后 `let i=i+1`——三件套。

## 题 4:倒置文本行

**操作解法(按键)**:

```
G       跳到文件最后一行
dd      剪切该行
gg      跳回文件第一行
P       粘贴到光标上方
```

重复 4 次(文件有几行就做几次)。行数多时录个宏:

```
qaGddggPq     录宏:把"剪切最后一行贴到最前"存入寄存器 a
3@a           执行 3 次
```

**命令解法(进阶)**:`:g/^/m 0` —— 每行移到第 0 行,顺序反转。

## 题 5:行排序

> [!note] 本质命令题
> 键盘上没有"排序"键。`:sort` 是唯一途径。

**命令解法**:

```
V           选中 case 1 的 4 行
:sort n     数值升序(自动变成 :'<,'>sort n)
```

再选中 case 2 同样操作。降序用 `:sort! n`。

| 命令 | 作用 |
|---|---|
| `:sort n` | 按数值排序(`10` 排在 `2` 后面) |
| `:sort! n` | 数值降序 |

## 题 6:更改文本对象内容

**操作解法(按键)**:光标放引号内任意位置:

```
ci"wsgggws<Esc>
```

`ci"` = Change inside quotes:删引号内内容进插入模式,直接输入新内容。

> 文本对象全家桶:`ciw` 改词 / `ci(` 改括号内 / `ci{` 改花括号内 / `cit` 改 HTML 标签内。这是 nvim 高效编辑的核心,后面章节专门练。

## 题 7:删除行尾空格

**操作解法(按键)**:光标放行内任意位置:

```
$       到行尾
x       删掉行尾空格
.       重复删(每按一次删一个空格,直到行尾干净)
j       下一行,重复
```

**命令解法(进阶)**:`:%s/\s\+$//` —— 全文件一行清理。

| 部分 | 作用 |
|---|---|
| `:%s` | 全文件替换 |
| `\s\+` | 一个或多个空白字符 |
| `$` | 行尾锚点 |
| `//` | 替换为空 |

---

## 题 8:删除行首空格

**操作解法(按键)**:

```
0       到行首(缩进之前)
x       删一个空格,重复按 x 直到 ^ 位置(第一个非空白)
j       下一行,重复
```

**命令解法(进阶)**:`:%s/^\s\+//`

| 部分 | 作用 |
|---|---|
| `^` | 行首锚点 |
| `\s\+` | 一个或多个空白 |

## 题 9:批量注释代码

> [!warning] 先做这一步
> 练习文件是 `.txt`,`text` 文件类型没有注释符号,直接 `gc` 会报
> `Invalid commentstring`。打开文件后先执行:
> ```
> :set ft=python
> ```
> 之后 commentstring 自动变成 `#`,`gc` 才能用。

**操作解法(按键)**(comment.nvim):

```
:set ft=python  先指定文件类型
V2j     选中 3 行
gc      注释切换
```

或光标在函数内任意一行:`3gcc`(注释 3 行)。再按一次 `gc` 取消注释。

**通用命令解法**:`:3,5s/^/# /`(按实际行号)

## 题 10:批量取消注释

**操作解法(按键)**:同题 9,选中 3 行按 `gc`(切换)。

**命令解法**:`:3,5s/^# //`

## 题 17:简单查找替换

**操作解法(按键)**:`cgn` 流程(标准高效做法):

```
/hello      搜索
cgn         修改下一个匹配(Change Go Next)
hi<Esc>     输入新内容
n           下一个匹配
.           重复修改
n/. 交替按,直到改完所有匹配
```

**命令解法(进阶)**:`:%s/hello/hi/g`

| 部分 | 作用 |
|---|---|
| `%` | 全文件范围 |
| `s/旧/新/g` | 替换,`g` = 每行全部 |
| 加 `c` | `:%s/hello/hi/gc` 逐个确认 |

> `cgn` 是"改一个 → `.` 重复"的按键版替换,和 `:s` 是同一件事的两种手感。

---

## 题 18:替换当前行

**操作解法(按键)**:同题 17 的 `cgn` 流程,但只在当前行范围内改(匹配到行尾为止)。

**命令解法**:光标在目标行上 `:s/hello/hi/g` —— 省略 `%` 就是当前行。

---

## 题 19:大小写敏感替换

**操作解法(按键)**:`/hello` + `cgn` 流程——搜索模式 `hello` 默认只匹配全小写,`Hello`/`HELLO` 会被 `n` 跳过。

**命令解法**:`:%s/hello/hi/g`(默认大小写敏感)。不敏感用 `:%s/hello/hi/gi`(加 `i`)。

---

## 题 20:正则表达式替换

> [!note] 本质命令题
> 正则替换是命令的领域,按键没有对应物。

**命令解法**:

```vim
:%s/file\(\d\+\)\.txt/file\1.md/g
```

| 部分 | 作用 |
|---|---|
| `\(...\)` | 捕获组(要保留的数字) |
| `\d\+` | 一个或多个数字 |
| `\.` | 转义的点(否则匹配任意字符) |
| `\1` | 引用第 1 个捕获组 |
