## 题 139:文本对齐和排版

> [!note] 本质命令题
> 键盘上没有"对齐"键。要点是 `\=` 替换表达式:替换内容不是死字符串,而是运行一段表达式,用 `printf()` 做左对齐补空格。

**命令解法(推荐)**:每行把 `const xxx = yyy` 拆成两组,用 `printf('%-13s = %s', ...)` 统一补到 13 列:

```vim
:%s/^\(const \w\+\) = \(.*\)$/\=printf('%-13s = %s', submatch(1), submatch(2))/
```

| 部分 | 作用 |
|---|---|
| `\(const \w\+\)` | 捕获组 1:`const ` + 变量名 |
| ` = \(.*\)$` | 捕获组 2:`=` 后面的全部内容 |
| `\=` | 替换内容改为表达式,`submatch(1)`/`submatch(2)` 取回两个捕获组 |
| `printf('%-13s', ...)` | 左对齐补空格到 13 列(`-` = 左对齐;13 来自最长的 `const address`) |

结果:

```text
const name    = "John";
const age     = 30;
const email   = "john@example.com";
const address = "123 Main St";
```

> [!warning] CJK 宽度陷阱
> `%-13s` 按"字符数"补空格,中文显示占 2 列,中英混排会错位。按显示宽度补齐要用 `strwidth()`:
> ```vim
> :%s/^\(const \S\+\) = \(.*\)$/\=submatch(1) . repeat(' ', max([0, 13 - strwidth(submatch(1))])) . ' = ' . submatch(2)/
> ```
> `strwidth('const 名字')` = 10(中文按 2 列算),自动补 3 个空格,`=` 和值仍落在同一屏幕列。

> [!warning] 别用 `:%!column -t`
> `column -t` 会把 `"123 Main St"` 里的空格也当成分隔符,值被拆成两列。含空格的值必须用上面的替换表达式。

## 题 140:列编辑和块操作

**操作解法(按键)**(块插入 + 块内递增,两步块操作):

```
gg<C-v>3j      ① 光标在行首,框选 4 行的第 1 列
I0. <Esc>      ② 块内行首统一插入 "0. ",按 Esc 一次性应用到 4 行
gv             ③ 重新框选上一次的块(数字列)
g<C-a>         ④ 块内数字逐行递增:第 1 行 +1、第 2 行 +2……从 0 起步正好得 1,2,3,4
```

| 命令 | 作用 |
|---|---|
| `<C-v>` | 可视块模式:框选多行同一列 |
| `I` | 块内每行行首同时插入,`<Esc>` 一次性应用 |
| `gv` | 重新选中上一次的可视区域 |
| `g<C-a>` | 块内数字逐行递增:每行偏移 +1、+2、+3……所以插 `0` 得 1,2,3,4;插 `1` 会得 2,3,4,5 |

> 单行数字递增/递减用 `Ctrl-a` / `Ctrl-x`(光标放数字上,每次 +1/-1)。

**命令解法(进阶)**:第一章题 3 的计数器:

```vim
:let i=1 | g/^/s//\=i.". "/ | let i=i+1
```

## 题 141:表达式寄存器计算

**操作解法(按键)**:

```
A<C-r>=125*3<CR>
```

按下 `<C-r>=` 后底部出现 `=`,输入表达式回车,结果直接插入光标处。`A` 是行尾进入插入模式,`<C-r>` 是插入模式下粘贴寄存器,`=` 号是"表达式寄存器"。

| 按键 | 作用 |
|---|---|
| `A` | 行尾进入插入模式 |
| `<C-r>=` | 插入模式下打开表达式寄存器,提示符 `=` |
| `125*3<CR>` | 输入表达式回车,`375` 插入文本 |

> [!warning] 表达式里没有 `2^10`
> Vim 表达式**没有**幂运算符,`2^10` 会报 `E15: Invalid expression`。想算乘方用函数 `pow(2,10)` = 1024。

**命令解法(进阶)**(批量计算):多行形如 `Item 1: $10 x 3 =` 要补结果时,替换表达式里直接做算术:

```vim
:%s/\$\(\d\+\) x \(\d\+\) =\s*$/\='$'.submatch(1).' x '.submatch(2).' = $'.(submatch(1)*submatch(2))/
```

结果:每行补上 `= $30` / `$50` / `$75`。`\=` 开头的替换内容可以调用任意 Vim 函数,`submatch()` 取捕获组参与运算。

## 题 142:文本转换和大小写处理

**命令解法**:提取 key 名 → 合并 → 包裹,一条命令串起来:

```vim
:%s/^  \(\w\+\):.*/\1,/ | 2,4j | 1d | 1s/,$// | 1s/.*/const { \0 } = user;/ | 2d
```

| 步骤 | 作用 |
|---|---|
| `:%s/^  \(\w\+\):.*/\1,/` | 每行只留 key 名,并补逗号(`name,` / `age,` / `email,`) |
| `2,4j` | 把 2-4 行合成一行:空格连接成 `name, age, email,` |
| `1d` | 删掉 `const user = {` |
| `1s/,$//` | 去掉合并行末尾的逗号 |
| `1s/.*/const { \0 } = user;/` | 给合并行加前缀后缀(`\0` 引用整行) |
| `2d` | 删掉 `};` |

> [!warning] 容易踩的坑
> 若第 1 步不加逗号(`s//\1/`),`2,4j` 合并出来是 `name age email`,缺逗号,和目标状态不符。所以第 1 步就要补逗号、第 4 步再清尾部。

**操作解法(按键)**(大小写处理三件套):

```
gu   转小写(如 guiw 转当前词)
gU   转大写(如 gUiw 转当前词)
g~   大小写翻转
```

驼峰转蛇形(命令):

```vim
:%s/\([a-z]\)\([A-Z]\)/\1_\l\2/g
```

`\l` 把下一字符转小写:`getEmailAddress` → `get_email_address`。

## 题 143:智能换行和合并

**操作解法(按键)**:

```
:set textwidth=80
gqq
```

| 命令 | 作用 |
|---|---|
| `:set textwidth=80` | 设定折行列宽(0 = 不折行) |
| `gqq` | 按 textwidth 重排当前行,在最近空格处断行(实测第一行 76 列、以 `better` 结尾) |
| `gqip` / `gqG` | 重排当前段落 / 到文件末尾 |
| `J` / `gJ` | 连接下一行(自动插空格 / 不加空格) |

> 想合并回一行:光标在上一行按 `J`;再 `gqq` 折开。`:set textwidth=0` 关闭折行。

## 题 145:文本排序和去重进阶

> [!note] 本质命令题
> `:sort` 只能按行内容排序,没有"按长度"选项。要么走外部命令流水线,要么用 Vim 脚本的 `sort()`。

**命令解法 A(外部命令流水线)**:awk 给每行前加长度 → `sort -n` 数值排序 → `cut` 去掉长度列:

```vim
:%!awk '{ print length, $0 }' | sort -n | cut -d' ' -f2-
```

| 部分 | 作用 |
|---|---|
| `:%!命令` | 缓冲区整体交给外部命令,输出替换回来(过滤器) |
| `awk '{print length, $0}'` | 行首加长度:`10 JavaScript` |
| `sort -n` | 按数值排序 |
| `cut -d' ' -f2-` | 去掉长度列 |

**命令解法 B(纯 Vim 脚本)**:`sort()` 是稳定排序,同长项保持原序:

```vim
:call setline(1, sort(getline(1,'$'), {a,b -> len(a)-len(b)}))
```

> [!warning] 去重
> 删除**相邻**重复行(保持其余顺序):
> ```vim
> :g/^\(.*\)$\n\1$/d
> ```
> `:sort u` 也能去重,但会打乱行序。

## 题 146:文本分割和提取

**命令解法(推荐)**:捕获 `@` 后面的域名,替换成它:

```vim
:%s/.*@\(.*\)/\1/
```

| 部分 | 作用 |
|---|---|
| `.*@` | 贪婪匹配到 `@`(每行只有一个 `@`,等价于从头吃到 `@`) |
| `\(.*\)` | 捕获域名 |
| `\1` | 替换为捕获内容 |

**操作解法(批量按键)**(`:normal!` 对每行执行普通模式命令):

```vim
:%normal! 0df@
```

`0df@` = 回到行首 → 删到 `@`(含),留下域名。

## 题 147:增量数字和序列

**操作解法(按键)**(宏录制,生成式):

```
A 1<Esc>      第一行行尾追加 " 1"
qa            开始录制宏
yyp           复制当前行插到下方(行数 +1)
<C-a>         新行数字 +1
q             停止录制
3@a           执行宏 3 次 → Item 1 到 Item 4
```

`yyp` 是"复制一行插到下方",是生成式(从 1 行变 N 行);`<C-a>` 加一。本例文件已有 4 行 `Item`,想用宏就先 `:2,$d` 只留 1 行再生成。

**命令解法 A(计数器 + 全局替换)**:第一章题 3 的升级版,替换内容用 `\=` 表达式:

```vim
:let i=1 | g/^Item$/s//\='Item '.i/ | let i=i+1
```

**命令解法 B(脚本生成)**:`map` 遍历 + `printf` 控制格式:

```vim
:1,4d
:put =map(range(1, 4), 'printf(''Item %d'', v:val)')
:1d
```

补零编号(`%03d` 补到 3 位,生成 `ID-001` 风格):

```vim
:put =map(range(1, 100), 'printf(''ID-%03d'', v:val)')
```

| 部分 | 作用 |
|---|---|
| `:put =map(range(1,4),'...')` | `map` 对 1-4 逐个求值,`v:val` 是当前值,`put` 插入缓冲(每个元素一行) |
| `printf('Item %d', ...)` | 格式化;`%03d` 补零 |
| `''` | 脚本字符串里的单引号转义 |
| `:1d` | 空缓冲自带一个空行,插完删掉它 |

## 题 148:文本差异和比较

**操作解法(按键)**(编辑部分全是按键):

```
:w /tmp/148-原版.txt     ① 先存一份原版,作为对比基准
ggf(aname<Esc>           ② 函数签名加参数:f( 跳到 (,a 在 ( 后追加 name
jci"Hello " + name<Esc>  ③ 改引号内内容(文本对象,第一章题 6)
:vert diffsplit /tmp/148-原版.txt   ④ 垂直分屏并进入 diff 模式
```

diff 窗口操作:

```
]c / [c      下一个 / 上一个差异块
dp            把当前窗口内容推给另一边(diff put)
do            从另一边取差异过来(diff obtain)
:diffoff      退出 diff 高亮
:bw           关闭临时窗口
:!rm /tmp/148-原版.txt   清理基准文件
```

> [!warning] 括号后追加别带空格
> `f(a name<Esc>` 会得到 `hello( name)`,和目标状态 `hello(name)` 不符。直接 `f(aname<Esc>` 不输入空格。

## 题 149:文本加密和编码

> [!note] 本质命令题
> Base64 没有按键对应物,标准做法是 `:%!` 过滤器交给外部命令。

**命令解法**:

```vim
:%!tr -d '\n' | base64
```

| 部分 | 作用 |
|---|---|
| `:%!` | 整个缓冲区走外部命令,输出替换回来 |
| `tr -d '\n'` | 删除换行符 |
| `base64` | coreutils 编码 |

> [!warning] 为什么必须先 `tr -d '\n'`
> 不能直接 `:%!base64`:文件行尾有换行,`Hello World\n` 会编成 `SGVsbG8gV29ybGQK`(结尾的 `K` 就是换行)。去掉换行才是题目的 `SGVsbG8gV29ybGQ=`。

解码:

```vim
:%!base64 -d
```

> [!tip] ROT13 轮转
> ```vim
> :%!tr 'A-Za-z' 'N-ZA-Mn-za-m'
> ```

## 题 150:模式匹配和捕获组

**命令解法(推荐)**:三个捕获组,替换串里重排:

```vim
:%s/\(\d\{4\}\)-\(\d\{2\}\)-\(\d\{2\}\)/\3\/\2\/\1/
```

替换串里 `/` 要转义太烦,换 `#` 当分隔符,顺便用 `\v` 省掉括号转义:

```vim
:%s#\v(\d{4})-(\d{2})-(\d{2})#\3/\2/\1#
```

| 部分 | 作用 |
|---|---|
| `\(\d\{4\}\)` | 捕获组 1:恰好 4 位数字 |
| `\1` `\2` `\3` | 按序引用捕获组(本组 3 个捕获组分别对应年、月、日) |
| `\/` | 替换串中的 `/` 转义 |
| `#` 分隔符 | 替换内容含 `/` 时换分隔符免转义 |
| `\v` | 很魔法:`()`、`{}` 免转义 |

> [!warning] `\v` 模式里 `=` 不是普通字符
> 很魔法模式下 `=` 是"零或一"量词(类似 `?`):`x=1` 会被当成 `x?1`,匹配不到字面 `x=1`。要匹配字面 `=` 得写 `\=`,所以模式里含 `=` 时用默认 magic 模式最稳。

## 题 151:动态文本生成

**命令解法(推荐)**:一条替换搞定(`\l` 小写首字符;`...` 行不匹配,原样保留):

```vim
:%s/.*name: '\(User\d\+\)'.*/INSERT INTO users (name, email) VALUES ('\1', '\l\1@example.com');/
```

| 部分 | 作用 |
|---|---|
| `\(User\d\+\)` | 捕获 `User` + 数字 |
| `\l\1` | `\l` 把下一字符转小写:`User1` → `user1` |
| `.*name: '...'.*` | 只匹配带 `name:` 声明的行,`...` 行不匹配、原样保留 |

**命令解法 B(从零生成整批数据)**:for 循环 + `:put`,`''` 转义字符串里的单引号:

```vim
:for i in range(1, 10) | put ='INSERT INTO users (name, email) VALUES (''User'.i.''', ''user'.i.'@example.com'');' | endfor
:1d
```

| 部分 | 作用 |
|---|---|
| `:for i in range(1,10)` | 循环,`\|` 分隔循环体 |
| `put ='...'.i.'...'` | 表达式拼出整行插入缓冲 |
| `''` | 字符串里的单引号转义 |
| `:1d` | 空缓冲自带一个空行,插完删掉它 |
