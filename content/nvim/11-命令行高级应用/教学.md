## 题 174:条件命令

**打开文件**:

```bash
cd ~/nixos-config/notes/nvim/11-命令行高级应用

```

**要求**:文件里的 `:if search('pattern')` 示例展示:命令可以带条件,条件成立才执行。练习三个场景:

1. `backup` 目录不存在时创建它:一行版 `:if !isdirectory('backup') | call mkdir('backup') | endif`。验证后清理 `:!rmdir backup`(外部命令不可撤销)。注意别写成 `:if ... | !mkdir ... | endif`——`:!` 会把 `|` 之后的 `endif` 也交给 shell(bash 会报 `endif: 未找到命令`),目录操作用内置函数 `call mkdir()` 更干净
2. 按文件类型设选项(你本机是 C#/Unity,`#` 注释是 C# 场景):`set ft=cs` 后执行 `:if &filetype == 'cs' | set shiftwidth=4 | endif`,再用 `:echo &shiftwidth` 验证
3. 交互式多行输入:输入 `:if 1` 回车,提示符不消失,继续输入 `:endif` 回车,命令才执行

**目标状态**:

```text
:if !isdirectory('backup')
:  !mkdir backup
:endif
```

**检验清单**:
- [ ] 执行条件命令后 `backup` 目录被创建(清理 `:!rmdir backup` 后恢复)
- [ ] `:if &filetype == 'cs'` 能按文件类型改变 `shiftwidth`
- [ ] 会交互式多行输入 `:if`/`:endif`(和单行版二选一也行)

## 题 179:复杂的搜索替换

**打开文件**:

```bash
cd ~/nixos-config/notes/nvim/11-命令行高级应用
nvim 练习/179-复杂的搜索替换.txt
```

**要求**:文件里的示例 `:let counter=0 | %s/pattern/\=counter+=1/g` 想做"编号替换",但**直接执行会报 E15**——`+=` 不能写在 `\=` 表达式里(Vim 表达式没有复合赋值)。练习三个能跑的正确写法:

1. 造文件:`:!echo 'var a = 1;' > a.cs`,同样造 `b.cs`、`c.cs`
2. `:args *.cs` — 把目录下所有 `.cs` 加入参数列表;`:args` 查看列表(当前文件在 `[]` 里);`:next`/`:prev`/`:first`/`:last` 在文件间切换

4. 再试 `:bufdo %s/let /var /ge | update` — 对所有**已打开缓冲区**执行(先用 `:e a.cs`、`:e b.cs` 打开两个)
5. `:windo set number` — 对所有**窗口**执行(先 `:split` 分一个窗口)
6. quickfix 版:`:vimgrep /var / *.cs` 生成匹配列表,`:cdo %s/var /let /ge | update` 只对列表里的位置执行;`:copen` 查看列表
7. 练完清理临时文件:`:!rm -f a.cs b.cs c.cs`

**目标状态**:

```text
:windo set number
```

**检验清单**:
