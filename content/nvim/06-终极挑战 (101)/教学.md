## 题 101:综合练习重构代码

**打开文件**:

```bash
cd ~/nixos-config/notes/nvim/06-终极挑战 (101)
nvim 练习/101-综合练习.txt
```

**初始状态**(缩进混乱、命名随意、没有文档的 Python 代码):

```python
def f(x,y,z):
 if x>0:
  if y>0:
   if z>0:
    return x+y+z
   else:
    return x+y
  else:
   return x
 else:
  return 0
```

**任务**:把它重构为规范版本——4 空格缩进、可读的函数名、清晰的提前返回结构、类型注解和 docstring。不改变任何计算逻辑:同样的输入,输出必须完全一样。

> [!tip] 读懂这段代码再动手
> 这段代码其实"逻辑正确、格式混乱":三层嵌套的 `if/else`。
> 翻译成自然语言:从 `x` 开始逐层检查,遇到非正数就停止并返回"已经累加的部分";
> 三个数都是正数,返回 `x+y+z`;`x` 非正则返回 0。
> 也就是:三个正数的和,负数/零在累加时被截断。
> 先把逻辑读懂,重构才有底气——重构的规则是**行为不变,形式变好**。

分 6 个阶段完成,每阶段做完自检再进入下一阶段。

## 阶段 2:修复缩进

**任务**:

- 练习文件是 `.txt` 扩展名,先把它当 Python 处理,并把缩进宽度设为 4 空格(否则自动缩进和语法检查都不生效)
- 先试全文件自动重排,再手工修复所有错位缩进——先观察自动重排的结果,你会发现它并不可靠,这正是本阶段要练习的
- 修复标准:第 1 层 4 空格、第 2 层 8 空格、第 3 层 12 空格;每个 `else:` 与它配对的 `if` 在同一列

**阶段性自检**:

- [ ] 语法检查无报错(修复前会报 `IndentationError`——这正是没修好的信号)
- [ ] 3 个 `else:` 分别与 `if x>0:` / `if y>0:` / `if z>0:` 对齐
- [ ] 用 `u` 撤销后能重做一遍

## 阶段 3:重命名函数

**任务**:

- `f` 这个名字没有信息量,改成能读出用途的名字 `calculate_sum`
- 用词边界保证只替换独立单词 `f`,不误伤 `foo`、`f1` 这类名字

**阶段性自检**:

- [ ] 第一行变成 `def calculate_sum(x,y,z):`
- [ ] 全文件找不到独立的 `f`(注意:`def` 里的 `f` 不是独立词,别被它骗了)

## 阶段 4:重构嵌套 if 为提前返回

**任务**:

- 把三层嵌套的 `if/else` 压平成"守卫 + 提前返回"结构:每个守卫是"条件不满足就立即返回",所有守卫都通过后再给出最终结果
- 铁律:行为必须不变——改完后这个函数在相同输入下必须给出相同输出

**阶段性自检**:

- [ ] 语义测试输出 `6 0 5 10`(四个分支全覆盖:全正 / x 非正 / y 非正 / z 非正)
- [ ] 文件里不再有嵌套的 `if ... if ... if`
- [ ] 语法检查无报错

---

## 阶段 5:添加类型注解和 docstring

**任务**:

- 给参数和返回值加类型注解:参数是三个 `int`,返回也是 `int`
- 函数体第一行写 Google 风格 docstring:一行摘要、`Args:` 每个参数一行、`Returns:` 一行
- 写完后全文件重排一遍,确认 docstring 和缩进没有互相破坏

**阶段性自检**:

- [ ] 语法检查无报错
- [ ] 参数 `x`、`y`、`z` 都有 `: int` 注解,返回有 `-> int`
- [ ] docstring 有摘要、Args、Returns 三部分,`Args` 参数行彼此对齐
- [ ] 能说出:注解写错(比如 `x: str`)会影响程序运行吗?为什么?

## 阶段 6:对照目标代码终验

**任务**:

- 开一个新窗口,把目标代码放进去,和你的作品逐行对比,确认一致(具体做法见解答)
- 确认无误后关掉对照窗口,回到你的作品

**目标状态**(重构完成后的完整代码):

```python
def calculate_sum(x: int, y: int, z: int) -> int:
    """
    Calculate the sum of positive numbers.

    Args:
        x: First number
        y: Second number
        z: Third number

    Returns:
        Sum of positive numbers
    """
    if x <= 0:
        return 0

    if y <= 0:
        return x

    if z <= 0:
        return x + y

    return x + y + z
```

**逐项对照检查**:

- [ ] 函数名、参数名与目标一致(`calculate_sum`,参数仍叫 `x/y/z`,不要顺手改名)
- [ ] 缩进:4 空格层级,无 Tab
- [ ] 结构:3 个提前返回守卫 + 1 个兜底 `return`,没有嵌套 `if`
- [ ] 类型注解与 docstring 与目标一致
- [ ] 逻辑等价:4 个分支输出与阶段 4 的语义测试完全一致
