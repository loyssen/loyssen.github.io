# AI编程工具的进化:Copilot → 对话 → Cursor → CLI Agent

> [!info] 本页内容
> 补全、对话、Agent、编辑器——四种 AI 形态差在哪?
> 为什么 2025 年风向转到"终端里跑 Agent"。

## 一、进化时间线

| 阶段 | 年份 | 代表 | 形态 |
|---|---|---|---|
| 1. IDE 内补全 | 2021 | **GitHub Copilot** | 写代码时自动续写,Tab 接受 |
| 2. 对话式 | 2022-2023 | ChatGPT / Claude | 贴代码问问题、查 API |
| 3. AI 优先 IDE | 2023 | **Cursor** | 编辑器 + AI 深度绑定,看得见整个项目 |
| 4. CLI Agent | 2025 | **Claude Code / Aider** | 终端里自主干活:读代码、改文件、跑命令 |
| 5. 回流入编辑器 | 2025- | avante / Copilot Agent | 把 Agent 能力再装回编辑器,与 buffer 协作 |

## 二、各形态详解

### 1. Copilot(2021):补全——AI 的"打字机"

第一个改变写代码体验的产品:模型看上下文预测下一个 token,`Tab` 接受。
**边界:单行/小块代码**——它只是"续写",不思考、不跨文件。

### 2. 对话式(2022):问它——AI 的"百科"

ChatGPT 让"贴代码问问题"成为日常:

- 解释一段看不懂的代码
- 问 API 用法、查报错
- 生成一段样板代码

缺点:上下文割裂——代码在编辑器里,对话在网页里,来回拷贝。

### 3. Cursor(2023):AI 优先 IDE——AI 的"助理"

VS Code 分叉,把 AI 做成一等公民:`@` 提及文件、选中代码直接改、Agent 模式跨文件修改。
**核心创新:让模型看到整个项目**,而不只是当前文件。

### 4. CLI Agent(2025):终端里跑——AI 的"员工"

Claude Code / Aider 把 Agent 从编辑器搬进终端,它会:

```
claude "给这个仓库加 .gitignore,排除 dist 和 .env"
    ↓
自己读目录 → 自己改文件 → 跑 git status → 给你看 diff → 你确认
```

### 5. 回流入编辑器(2025-):avante 等

nvim 的 avante、VS Code 的 Copilot Agent,把 CLI Agent 的能力装回编辑器——AI 面板和你的 buffer 无缝协作。**方向不是替代,是融合**。

## 三、四种形态对比

| | 补全 (Copilot) | 对话 (ChatGPT) | Agent (Claude Code) | 编辑器内 (Cursor/avante) |
|---|---|---|---|---|
| 入口 | 编辑器内自动 | 网页/App | 终端 | 编辑器面板 |
| 作用范围 | 当前行 | 你贴的内容 | **整个项目** | 整个项目 |
| 主动性 | 被动续写 | 被动回答 | **主动干活** | 主动干活 |
| 典型场景 | 样板代码 | 问概念/查 API | 改 bug/加功能 | 边看代码边改 |
| 你需要会 | 写代码 | 描述问题 | 看懂 diff | 看懂 diff |

## 四、能力边界:什么时候 AI,什么时候自己写

**AI 帮手适合:**

- 样板代码、重复劳动(config、boilerplate、测试)
- 不熟的语言/框架的"入门写法"
- 改 bug、全局重构的初稿

**应该自己写 / 必须会:**

- **审稿能力**:看不懂 AI 生成的代码,就别提交——bug 是欠债
- 设计决策、架构取舍:AI 没有你的上下文
- 基础技能本身:键位、LSP、命令行——**AI 只是打字员,你才是把关人**

> [!note] Agent 时代的新技能
> 从"会写"变成"会看 diff、会验收"。
> 这正是本系列的地基(键位、LSP、搜索)不会因为 AI 而消失的原因。

## 五、现今流行:CLI Agent 是 2025-2026 增长最快的形态

- 2025 年起 Claude Code / Codex CLI / Gemini CLI / Aider 百花齐放,终端 Agent 成为新标配
- 原因:终端无所不在(SSH 到服务器也能跑)、与 git 天然一体、随便接管道和脚本
- nvim 用户的红利:**编辑器不用换,AI 在终端里跑**——配置零迁移

## 六、怎么选

| 你的情况 | 建议 |
|---|---|
| 刚接触 AI 编程 | 先用编辑器内 Agent(avante),入口最简单 |
| 已习惯终端 | Claude Code CLI,看它读文件/改文件的全过程 |
| 写代码为主、问问题为辅 | avante 面板 + Claude 终端组合 |
| 只想要补全 | 补全已过时——直接上 Agent,体验完全不同 |

> [!tip] 记一条主线
> 补全 → 对话 → 编辑器 Agent → 终端 Agent → 融合。
> 形态在变,底层没变:模型 + 上下文 + 工具。
