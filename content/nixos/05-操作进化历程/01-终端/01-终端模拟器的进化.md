# 终端模拟器的进化

> [!info] 本页内容
> 终端到底是什么?"终端模拟器"模拟的是什么?
> 从物理设备到 GPU 渲染的四个时代,以及今天的格局。

## 一、先建立四层模型

"终端"这个词的混乱,源于它指过好几层东西。正确的打开方式:

```
┌─────────────────────────────────────────────┐
│ 终端模拟器 (Terminal)   ← 显示层:kitty、Alacritty、WezTerm │
│   ┌───────────────────────────────────────┐ │
│   │ Shell(命令解释器)← bash、zsh、fish       │ │
│   │   ┌─────────────────────────────────┐ │ │
│   │   │ CLI 工具(跑完即退):ls、rg、fd    │ │ │
│   │   │ TUI 工具(常驻全屏):nvim、yazi    │ │ │
│   │   └─────────────────────────────────┘ │ │
│   └───────────────────────────────────────┘ │
└─────────────────────────────────────────────┘
```

| 术语 | 是什么 | 例子 |
|---|---|---|
| **终端模拟器** | 画窗口、接收键盘的那个程序 | kitty、Alacritty、WezTerm、foot |
| **Shell** | 读命令、执行、补全 | bash、zsh、fish、nushell |
| **CLI** | 命令行程序,输入→输出→退出 | `ls`、`rg`、`git`、`jq` |
| **TUI** | 全屏交互界面,常驻运行 | nvim、htop、lazygit、yazi |

> [!tip] 最关键的区分
> **CLI 是一次性的,TUI 是常驻的。**
> 运行 `ls` 输出完就退出,这叫 CLI;nvim 打开后一直占着全屏界面等你按键,这叫 TUI。
> 有人喊"CLI 编辑器"是口语混用——准确说 nvim 是 TUI 编辑器。

## 二、第一代:硬终端(1970s)

终端最初是**物理设备**——显示器 + 键盘的一台机器,通过串口(RS-232)连到远处的分时主机。

- 经典机型:**VT100**(DEC 公司,1978),绿字黑底,直到今天影视剧里的"黑客终端"形象还是它
- 它是"终端模拟器"这个词的来源:现代程序**模拟**的正是 VT100 这类设备
- 它留下的遗产:**转义序列**(escape sequence)——程序通过输出特殊字节序列(`\x1b[...`)控制光标位置、颜色。1978 年的协议,至今每一行终端代码都在用

```
[主机] ←串口→ [VT100 终端(显示器+键盘)]
```

> [!note] 为什么叫"模拟器"
> 现代终端模拟器 = 用软件模拟一台 VT100 的行为:接收键盘输入发给 shell,
> 接收 shell 输出的转义序列渲染成文字。它本质是"虚拟的硬件终端"。

## 三、第二代:X 终端与系统自带(1980s-2000s)

GUI 时代到来,终端从"独立设备"变成"桌面上的一个窗口程序":

| 终端 | 年份 | 特点 |
|---|---|---|
| **xterm** | 1984 | X11 时代的鼻祖,兼容性之最,至今仍是"兜底"终端 |
| **GNOME Terminal** | 2001 | GNOME 桌面默认,功能朴实 |
| **Konsole** | 2003 | KDE 桌面默认 |
| **Windows Terminal** | 2019 | 微软补课之作,跨平台现代终端 |

- 共同特点:**CPU 渲染**,逐帧绘制文字;显示大量输出(滚动日志)时会卡
- 这是"系统自带终端"的传统阵营——大众用户到今天用的还是它们

## 四、第三代:GPU 终端(2015-至今)

GPU 渲染技术让"终端"重新成为开发者市场:

- **Alacritty**(2016):第一个 Rust 终端,GPU 渲染,极简主义,引爆了"现代终端"概念
- **kitty**(2016):GPU + 完整功能(分屏/tab/协议),Neovim 圈口碑第一
- **WezTerm**(2018):配置最灵活,Rust + Lua/JS 配置
- **foot**(2020):Wayland 原生,极简省资源

为什么 GPU 渲染重要:终端显示的本质是"把字符画到屏幕上",GPU 终端把每个字符当纹理批量贴图——滚动万行日志不掉帧,这是 CPU 渲染做不到的。

## 五、进化时间线

```
1978  VT100 硬终端(转义序列标准)
1984  xterm(X11 鼻祖)
2001  GNOME Terminal(桌面默认时代)
2016  Alacritty / kitty(GPU 终端元年)
2018  WezTerm
2019  Windows Terminal
2020  foot
2026  四强格局:kitty / Alacritty / WezTerm / foot
```

## 六、现今流行情况

- **大众市场**:系统自带终端(GNOME Terminal 等)仍占绝对多数——"能用就行"
- **开发者市场**:kitty / Alacritty / WezTerm / foot 四强分立,各有拥趸
- **生态位**:kitty 在 nvim + Wayland 用户圈最受认可(详见下篇《现代终端对比》)
