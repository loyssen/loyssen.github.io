# vi 到 vim 到 neovim:40 年统治的编辑器家族

> [!info] 本页内容
> vi/vim/neovim 是什么关系?模式编辑为什么能赢 40 年?
> vim 键位为什么"学一次,到处用"?

## 一、谱系

```
vi (1976, Bill Joy, 随 Unix 第七版捆绑)
└── vim (1991, Bram Moolenaar, 增强版, 事实标准)
    └── neovim (2015, 重构 + 可编程性, 现役王者)
        └── nixvim(用 Nix 声明式配置 neovim——你现在用的)

旁支:emacs (1985) —— "操作系统般的编辑器",另一条路,至今有信仰者
```

| 版本 | 年份 | 关键贡献 |
|---|---|---|
| **vi** | 1976 | 模式编辑、组合命令——设计全部来自这里 |
| **vim** | 1991 | 撤销树、多窗口、脚本语言、插件体系 |
| **neovim** | 2015 | Lua 配置、异步、内嵌终端、LSP 原生支持 |

## 二、核心设计:为什么能赢 40 年

### 1. 模式编辑
普通模式(移动/操作)与插入模式(打字)分离——**手不用离开键盘**:

- 普通模式:每个字母都是命令(`j` 下移、`d` 删除、`p` 粘贴)
- 插入模式:只有 `i` 进入后才是"打字状态"
- 对比:记事本式编辑器 = 永远在打字模式,移动只能靠方向键/鼠标

### 2. 组合命令:小积木搭出无限操作

```
d(删除) + w(词)    = dw   删一个词
c(修改) + i"(引号内) = ci"  改引号内内容
y(复制) + s(句子)  = ys   复制整句
```

动词(操作)× 名词(文本对象)= 组合爆炸。几十个键位能表达上千种操作——这是其他编辑器学不来的"按键即语言"。

### 3. vim 键位:全行业通用语

学 vim 键位 = 学一门"到处能用"的语言:

| 场景 | 位置 |
|---|---|
| 服务器 | `vim` 就是默认编辑器 |
| IDE | VS Code / JetBrains 的 vim 模式插件 |
| 终端复用器 | tmux 的复制模式是 vim 键 |
| 浏览器 | Vimium 等插件 |

## 三、neovim:为什么是"现役王者"

vim 的问题(2015 年前后):代码老化、插件生态靠 VimScript、异步支持差。
neovim 的答案:

- **Lua 配置**:配置即代码,可编程性碾压
- **异步 + RPC**:插件可以并行跑、外部程序可以控制 nvim
- **内嵌终端**:终端里跑终端
- **LSP 原生支持**:配合 LSP 协议(见下篇),补齐补全/跳转,对抗 IDE

结果:插件生态大爆发(2020 年后),LazyVim 等配置框架让"开箱即用的 nvim"成为可能。

## 四、现今地位

| 维度 | 现状 |
