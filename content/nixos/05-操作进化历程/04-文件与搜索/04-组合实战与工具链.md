# 组合实战与工具链:把现代工具串起来

> [!info] 本页内容
> 前面的工具单看各有本事——串起来才是工作流。
> 本篇给出一套可直接用的"现代文件操作工具链"。

## 一、核心管道(可直接抄)

```bash
# 1. 找文件并打开(替代:记得路径)
nvim $(fd -e nix | fzf)

# 2. 找内容并打开全部匹配文件
nvim $(rg -l "TODO" ~/nixos-config)

# 3. 智能跳目录(替代:cd 长路径)
z 操作进化

# 4. 交互选目录进入(替代:cd + Tab 慢慢敲)
cd $(fd -t d | fzf)

# 5. 找文件并预览内容(替代:ls + cat 两步)
fd -e md | fzf --preview 'bat {}'

# 6. 批量处理搜索结果(替代:手动画范围)
rg -l "old_api" | xargs sed -i 's/old_api/new_api/g'
```

## 二、一整套现代工具链(你的配置现状)

| 功能 | 经典 | 现代(已装) | 用法速记 |
|---|---|---|---|
| 列目录 | ls | **lsd** | `alias ls=lsd` |
| 看文件 | cat | **bat** | `alias cat=bat` |
| 找文件 | find | **fd** | `fd -e nix` |
| 搜内容 | grep | **rg** | `rg "关键词"` |
| 模糊选择 | — | **fzf** | 任何列表 `\| fzf` |
| 跳目录 | cd | **zoxide** | `z 关键词` |
| 文件管理 | mc | **yazi** | `yazi` |
| 提示符 | PS1 | **starship** | 自动显示 git/语言版本 |
| 系统监控 | top | **btop** | `btop` |
| 系统信息 | uname | **fastfetch** | `fastfetch` |

## 三、接入日常三处

### 1. shell 别名(~/.bashrc 一行一个)

```bash
alias ls='lsd'
alias cat='bat'
alias find='fd'        # 或留着 find,用 fd 的别名 fd
alias grep='rg'        # 或留着 grep,习惯用 rg
```

### 2. nvim 里(你已经有了)

```
<leader>ff   找文件(telescope 后端就是 fd)
<leader>fg   内容搜索(telescope 后端就是 rg)
<leader>o    Oil 文件管理
yazi 里 o    用 nvim 打开
```

### 3. 终端交互

```
Ctrl+r       历史搜索(fzf 版,你的配置已开)
Ctrl+t       当前目录文件选择(fzf 版,可开)
```

## 四、性能对比(为什么要换)

| 场景 | 经典 | 现代 | 差距 |
|---|---|---|---|
| 搜 10 万行日志 | grep | rg | 3-10 倍 |
| 大仓库找文件 | find | fd | 5-10 倍 |
| 列大目录 | ls | lsd | 相当,但好看 |
| 看大文件 | cat | bat | 相当,但分页+高亮 |

> [!note] 诚实说明
> 现代工具不是"必须换"——经典工具在脚本/服务器/最小系统里依然正确。
> 换的理由是**交互体验**(高亮/选择/预览),不是速度焦虑。
> 服务器上没有这些工具时,经典命令依然是你兜底的能力。

## 五、学习路径建议

```
第 1 天    alias ls=lsd / alias cat=bat(零成本适应)
第 2 天    用 fd -e xxx 替代 find(语法更简单)
第 3 天    用 rg 替代 grep(默认忽略规则省心)
第 4 天    用 z 替代 cd(记不住路径也能跳)
第 5 天    fzf 组合:cd $(fd -t d | fzf)
第 6 天    yazi 管理文件
之后       nvim 里 telescope(ff/fg)成为默认
```

> [!tip] 记忆一句话
> **"描述 + 选择"取代"记忆 + 输入"**——现代工具链的全部哲学。
> 你不再需要记住路径和精确名字,只需要模糊描述,然后从候选里选。
