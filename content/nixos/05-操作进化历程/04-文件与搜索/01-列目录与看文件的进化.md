# 列目录与看文件的进化:ls → lsd / cat → bat

> [!info] 本页内容
> 为什么现代人不用 `ls` 用 `lsd`?`cat` 有什么可改的?
> 这类"重写经典工具"运动是怎么回事。

## 一、经典二件套(1971)

Unix 最古老的两个工具:

| 工具 | 出生 | 作用 |
|---|---|---|
| **ls** | 1971 | 列出目录内容 |
| **cat** | 1971 | 把文件内容输出到屏幕(名字来自 concatenate,串联) |

它们的设计是"只做一件事、输出文本流"——40 多年来接口没变,变的只有体验。

## 二、现代替代运动

2015 年后,一批"重写经典工具"出现——**接口不变(还是文本流),但体验现代化**:

| 经典 | 现代替代 | 现代版加了什么 |
|---|---|---|
| `ls` | **lsd** / **eza**(exa 的维护分支) | 图标、颜色、按类型着色、git 状态标记、树状视图 |
| `cat` | **bat** | 语法高亮、行号、git 变更标记、分页(长文件自动进 less) |
| `find` | **fd** | 见下篇《搜索的进化》 |
| `grep` | **rg** | 见下篇 |

### bat 详解(你已装)

```
bat nixvim/plugins/lsp.nix
    ↓
───────┬────────────────────────────────────────
       │ 1 │ { pkgs, ... }:           ← 行号
       │ 2 │ {                       ← 语法高亮(Nix)
       │ 3 │   programs.nixvim = {
       │...
```

| 特性 | 说明 |
|---|---|
| 语法高亮 | 自动识别 150+ 语言 |
| 行号 + git 标记 | 变更行带 `+`/`-` 标记 |
| 分页 | 长文件自动交给 less(还能搜索) |
| 管道兼容 | `bat file | rg xxx` 输出不带装饰(自动检测) |
| 替代 cat 场景 | `bat > file` 也能当 cat 用(无 TTY 时退化为 cat) |

### lsd 详解(你已装)

```
lsd -l
    ↓
drwxr-xr-x loysan users  4.0K 8月6日 21:30 📁 03-编辑器
-rw-r--r-- loysan users  1.2K 8月6日 21:30 📄 02-LSP与Treesitter.md
```

| 特性 | 说明 |
|---|---|
| 图标 | 文件类型一目了然 |
| 颜色 | 按类型/权限着色 |
| git 状态 | 分支名、文件变更状态(`✔`/`?`) |
| 兼容 | `ls` 的别名参数全部保留(`-l -a -t -r`) |

## 三、为什么"重写经典"成为运动

1. **接口红利**:只要输出还是文本流,新旧工具就能无缝替换——别名 `alias ls=lsd` 即可,脚本不受影响
2. **社区驱动**:Rust 生态(2015+)带来一批"更快 + 更安全"的实践者(ripgrep/fd/bat 都是 Rust)
3. **审美升级**:终端从"工具"变成"工作台",好看不再是可选项

> [!note] 统一规律
> 现代替代 = 经典接口 + 更快 + 更好看 + 更安全。
> 你配置里的 bat/lsd/rg/fd/fzf 全部遵循这个模式——**学一次经典,替代品零成本上手**。

## 四、怎么配(你的环境)

```bash
# ~/.bashrc 里一行别名即可
alias ls='lsd'
alias cat='bat'
```

| 场景 | 命令 |
|---|---|
| 快速看文件 | `bat 文件` |
| 长文件分页 | `bat 大文件`(自动进 less) |
| 看目录带图标 | `lsd` / `lsd -l` |
| 树状目录 | `lsd --tree` / `fd -t d`(见下篇) |

> [!tip] 已装即用
> 你的 packages.nix 里 bat/lsd 都已安装,但**默认 shell 还是用 ls/cat**——
> 想要现代体验,在 `~/.bashrc` 加两行别名,或让 Claude 帮你加进配置。
