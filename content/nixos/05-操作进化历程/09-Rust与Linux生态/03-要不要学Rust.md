# 要不要学 Rust:成本、收益与路径

> [!info] 本页内容
> Rust 学习曲线到底多陡?对你的技能栈(Shell/Python/Lua)意味着什么?
> 想入门的话,最短路径是什么。

## 一、先诚实回答三个问题

### 1. 不学 Rust 会错过什么?

- **不会错过工具使用**:你用的 Rust 工具(rg/fd/btop/helix)都是编译好的二进制,使用不需要会 Rust
- **不会错过就业机会**:如果你的方向是 Unity/C# 开发,学 Rust 不是刚需
- **会错过的**:理解"为什么现代工具这么快又这么稳"的第一性原理,以及参与/修改开源小工具的能力

### 2. 学 Rust 的成本是什么?

| 阶段 | 体验 | 时长 |
|---|---|---|
| 语法基础 | 和 C/Java 差不多,平缓 | 1-2 周 |
| **所有权/借用** | **第一个坎**:反直觉,编译器疯狂报错 | 2-4 周(劝退多数人) |
| 生命周期/泛型 | 第二个坎:类型系统最深的地方 | 2-4 周 |
| 写实际项目 | 借用检查器和你"博弈" | 持续 1-2 个月 |

> [!warning] 现实
> Rust 的入门痛苦是**真实的**。它的设计哲学是"编译器严格到令人沮丧,
> 但一旦通过编译,代码几乎肯定是对的"。多数人放弃在所有权阶段。

### 3. 学 Rust 的收益是什么?

- **思维升级**:所有权思想(谁拥有数据、谁可以借用)能反哺任何语言——写 Python 时也会更注意数据归属
- **能力边界**:能读懂/修改 rg、fd 这类工具源码,遇到"工具不够用"时能自己造
- **生态入场**:Rust 是未来 10 年系统级方向的默认选项,早学早受益

## 二、和你的技能栈的关系

| 你已有的 | 和 Rust 的关系 |
|---|---|
| Shell/管道 | Rust 工具是管道的**积木**;日常不需要 Rust |
| Python | 胶水语言/脚本;Rust 是"性能不够时"的下沉选项 |
| Lua(nvim 配置) | nvim 插件生态不用 Rust(除非写原生插件) |
| C#(Unity) | 完全独立生态;Rust 是爱好/认知投资,不是职业必需 |
| NixOS 配置 | Nix 生态有 Rust 工具,但配置用 Nix 语言 |

**结论**:对你而言,Rust 是"认知投资"——不改变你现在的日常,但让你理解你每天用的工具。

## 三、入门最短路径

### 路径 A:只想了解(2-3 小时)

```
1. 读《Rust 程序设计语言》(rust book)第 1-4 章
   —— 安装、猜数字游戏、所有权三章
2. 重点看第 4 章"所有权"的图示(栈/堆/移动)
3. 动手:改一个现有小工具的行为(比如给 fd 加个参数?——不需要,看懂即可)
```

### 路径 B:认真入门(1-2 个月)

```
1. rust book 全文(免费,rust-lang.org 官方,中文版齐全)
2. 《Rust 程序设计语言》第 4/10/15/16 章反复看(所有权/泛型/智能指针/并发)
3. 小项目练手:重写一个你用过的 CLI 工具的最小版本
   (比如:30 行实现一个"简易 fd"——递归找文件)
4. 读一个真实工具的源码:fd 或 ripgrep 的 main.rs(先看结构,不看细节)
```

### 工具准备(NixOS 上)

```bash
# 装 Rust 工具链(你的 nixos-config 里,或临时)
nix shell nixpkgs#rustc nixpkgs#cargo

# 验证
cargo --version
```

## 四、怎么判断该不该学

| 你的情况 | 建议 |
|---|---|
| 好奇"为什么现代工具快" | 读 rust book 前 4 章即可 |
| 想写自己的 CLI 工具 | 学(入门后收益直接) |
| 想进内核/系统级方向 | 学(必修) |
| 日常是 C#/Unity 开发 | 不学也不亏;有空当认知投资 |
| 时间紧张 | 先不学——Rust 不会跑 |

> [!tip] 最好的"试用装"
> 在 [play.rust-lang.org](https://play.rust-lang.org) 网页上直接跑 Rust 代码,
> 零安装。把 rust book 第 4 章的例子敲一遍,你就知道自己喜不喜欢它的风格。

## 五、一句话总结

> Rust 的魅力是真实的,但它是**系统级语言的魅力**——不是每个人的必修课。
> 用它的工具(零成本)、理解它的思想(2 小时)、写它的代码(1-2 个月,可选)。
> 最差的情况,你多看懂了一个领域;最好的情况,你多了一个造工具的能力。
