# 01 · 从 Windows 到 Linux 的思维转换

> 上一篇：[[00-索引]] · 下一篇：[[02-Linux发展简史与发行版生态]]
> 这一篇不讲命令，先讲"操作系统世界观"的差异。看懂这个，后面都顺。

## 1. 没有 C 盘，只有一棵树

**Windows**：每个磁盘一个盘符（C:\、D:\），软件散落在
`C:\Program Files`、注册表、`%APPDATA%` 三处。

**Linux**：一切从 `/`（根）开始的一棵树。其他磁盘"挂载"到树的某个节点上
（比如 U 盘出现在 `/run/media/loysan/xxx`）。路径用正斜杠 `/`。

```
/                ← 根，相当于"此电脑"
├── home/loysan/  ← 你的家目录（≈ C:\Users\loysan），~ 是它的缩写
├── etc/          ← 系统配置（≈ 注册表 + system32\config，但是纯文本！）
├── usr/          ← 软件安装地（≈ Program Files）
├── var/          ← 可变数据：日志、缓存（≈ ProgramData）
├── tmp/          ← 临时文件（重启清空）
└── run/          ← 运行时数据（内存里，关机即失）
```

**关键区别**：Linux 配置全是**纯文本文件**，没有注册表。
"改设置"就是"编辑文本文件"。备份配置 = 复制文件。

## 2. 软件不是"下载安装包下一步"

**Windows**：官网下 .exe/.msi → 下一步 → 装完可能带全家桶。

**Linux**：**包管理器**统一安装（≈ 手机应用商店的概念，比 Windows Store 早 20 年）：
```bash
# 传统发行版（Ubuntu 等）
sudo apt install firefox

# 你的 NixOS：不写命令，写在配置文件里
environment.systemPackages = [ pkgs.firefox ];
```
软件源是官方维护的仓库，没有全家桶，没有"高速下载器"。

**NixOS 更进一步**：见 [[01-为什么需要Nix-传统包管理的痛点]]。

## 3. 权限思维：你不是管理员

**Windows**：日常账户基本等于管理员，弹个 UAC 点"是"就完事。

**Linux**：日常用户权限很小，系统级操作要 `sudo`（临时提权）：
- 改 `/etc`、装软件、动服务 → 要 sudo
- 自己家目录（`~`）随便折腾，不需要 sudo

好处：病毒/误操作很难毁掉系统，最坏只毁掉家目录。
你在 `wheel` 组（= 允许 sudo 的组），见 [[05-用户与权限]]。

## 4. 杀毒软件？不需要

Windows 的火绒/Defender 思维可以放下了：
- Linux 桌面恶意软件极少（市场份额 + 权限模型 + 开源软件源）
- 真正的防线：**只从官方 nixpkgs 装软件**、别乱 `curl | sh`、sudo 前三思

## 5. 卸载 = 删除声明，没有残留

**Windows**：卸载程序 → 控制面板 → 还留一堆注册表垃圾和文件夹。

**NixOS**：从 `packages.nix` 删掉那一行 → rebuild → 软件消失。
没有残留概念（配置还在你家目录的话那是用户数据，故意的）。
详见 [[12-系统维护-代际回滚-垃圾清理-更新]]。

## 6. 驱动：基本不用管

**Windows**：新硬件 → 装驱动 → 驱动精灵/官网找。

**Linux**：驱动在**内核里**，内核越新支持的硬件越多。
你的 NVIDIA 显卡是唯一需要"配置"的（专有驱动），已在 `modules/nvidia.nix` 搞定。
打印机、U 盘、键鼠、数位板：插上即用。

## 7. 蓝屏/卡死的应对不同

**Windows**：卡死 → 任务管理器 → 不行重启。

**Linux**：
- 图形界面卡死 ≠ 系统卡死。可以切到 tty（`Ctrl+Alt+F3`，纯文本终端）处理，
  `Ctrl+Alt+F1/F2` 切回图形界面
- 杀进程：`killall 程序名` 或 `btop` 里选中杀掉
- NixOS 独有后悔药：**开机菜单选上一个代际**，配置改坏了也能进系统

## 8. 大小写敏感！

`Documents` 和 `documents` 是**两个不同的文件夹**。Windows 不敏感，Linux 敏感。
打路径打命令时注意，这也是新手最常见的"找不到文件"原因。

## 9. 隐藏文件：点开头

`~/.config`、`~/.local` 这种点开头的文件/文件夹是隐藏的
（≈ Windows 的隐藏属性）。文件管理器里 `Ctrl+H` 显示。
你的大部分个人配置都在这里。

## 10. 一句话总结

> Windows 把复杂性藏起来（注册表、安装向导、驱动精灵），
> Linux 把复杂性摆在明处（文本配置、包管理器、权限），
> NixOS 把明处的复杂性变成**代码**（可版本管理、可回滚、可复制）。
> 你现在的不适应，是"看不见的魔法"换成了"看得见的机制"——学会后会更省心。
