## 文件与目录

| 目的 | Windows | Linux（你的系统） |
|---|---|---|
| 当前目录 | `cd` | `pwd` |
| 列文件 | `dir` | `lsd`（增强版 ls） |
| 切目录 | `cd 路径` | `cd 路径` / `z 关键词`（智能跳） |
| 复制 | `copy` | `cp -r 源 目标` |
| 移动/改名 | `move` | `mv 源 目标` |
| 删除 | `del` / `rmdir` | `rm 文件` / `rm -r 目录` ⚠️无回收站 |
| 建目录 | `md` | `mkdir -p a/b/c` |
| 建空文件 | `type nul >` | `touch 文件` |
| 查看文件 | `type` | `bat 文件`（高亮）/ `less`（翻页） |
| 查找文件 | `dir /s 名` | `fd 关键词` |
| 文件内容搜 | `findstr` | `rg 关键词` |
| 快捷方式 | .lnk | `ln -s 目标 链接名` |
| 磁盘占用 | 此电脑 | `df -h` / `du -sh 目录` |

## 系统

| 目的 | Windows | Linux |
|---|---|---|
| 任务管理器 | Ctrl+Shift+Esc | `btop` |
| 杀进程 | 结束任务 | `killall 名` / `kill -9 PID` |
| 服务管理 | services.msc | `systemctl status/start/enable 名` |
| 事件日志 | 事件查看器 | `journalctl -b` |
| 环境变量 | 系统属性 | `env` / `echo $PATH` |
| 关机/重启 | 开始菜单 | `systemctl poweroff` / `reboot`（或 GUI） |
| 清屏 | `cls` | `clear` / `Ctrl+L` |
| 以管理员运行 | 右键 | `sudo 命令` |
| 系统信息 | msinfo32 | `fastfetch` |

## NixOS 专属（每天打交道）

| 目的 | 命令 |
|---|---|
| 应用配置 | `sudo nixos-rebuild switch --flake ~/nixos-config#loysan` |
| 只验证不激活 | `nixos-rebuild build --flake ~/nixos-config#loysan` |
| 测试某配置不污染系统 | `nixos-rebuild test --flake ...`（重启即还原） |
| 开机选旧系统 | systemd-boot 菜单（物理按键选） |
| 更新所有依赖 | `nix flake update --flake ~/nixos-config` |
| 临时试某软件 | `nix shell nixpkgs#包名`（退出即消失） |
| 临时跑某工具 | `nix run nixpkgs#包名` |
| 搜包 | `nix search nixpkgs 关键词` |
| 清垃圾 | `sudo nix-collect-garbage -d` |
| 看 store 多大 | `du -sh /nix/store` |
| 列出系统代际 | `sudo nix-env -p /nix/var/nix/profiles/system --list-generations` |

## 文本处理（管道组合拳）

```bash
rg "error" log.txt          # 搜内容
head -50 / tail -50 文件     # 头/尾 50 行
tail -f 文件                # 实时追日志
wc -l 文件                  # 数行数
sort | uniq -c | sort -rn   # 统计频次排行
jq . data.json              # 格式化/查询 JSON（已装）
命令 | fzf                  # 交互式模糊筛选
```

## 网络

```bash
curl -I 网址          # 看响应头（测连通）
curl -O 文件网址       # 下载文件
wget 网址             # 下载（备用）
ping 域名             # 测连通（Ctrl+C 停）
ss -tlnp             # 看本机监听的端口（≈ netstat）
aria2c 网址          # 多线程下载（已装）
```

## 压缩解压

```bash
7z x 包.7z           # 解压（已装 p7zip）
7z a 包.7z 目录/      # 压缩
tar -xf 包.tar.gz    # 解压 tar 系
unzip 包.zip         # 解压 zip（已装）
peazip              # GUI 压缩工具（已装）
```

## 终端生存键位

| 键位 | 作用 |
|---|---|
| `Tab` | 补全（连按两次列候选） |
| `Ctrl+R` | **模糊搜索历史命令（fzf，最高频）** |
| `Ctrl+C` | 中断当前命令 |
| `Ctrl+D` | 退出终端 |
| `Ctrl+L` | 清屏 |
| `Ctrl+A` / `Ctrl+E` | 行首 / 行尾 |
| `Ctrl+W` | 删一个词 |
| `↑` / `↓` | 上/下一条历史 |
