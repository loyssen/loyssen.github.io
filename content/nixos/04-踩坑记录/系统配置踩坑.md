# 系统配置踩坑记录

> NixOS 配置和桌面环境层面的坑（Unity 相关见 [[Unity开发踩坑]]，
> 软件包相关见 [[nixpkgs软件包踩坑]]）。

## 坑 1：vim.fs.find 不支持 glob（nvim LSP root_markers）

**症状**：nixvim 里写 `root_markers = [ "*.sln" "*.csproj" ".git" ]`，
roslyn_ls 永远不 attach。

**根因**：nvim 0.11 新 LSP API 的 `root_markers` 走 `vim.fs.find()`，
**只做精确文件名匹配**（文件或目录均可），`*.sln` 这类 glob 原样当文件名找，永远不中。

**修法**：找"必然存在的精确名"。Unity 项目根必有 `ProjectSettings/` 目录：
```nix
root_markers = [ "ProjectSettings" ".git" ];
```

**通用原则**：写 root_markers 时问自己——这个 marker 是**逐字文件名/目录名**吗？
不是的话改用 `root_dir` 函数（lua）或换精确 marker。

## 坑 2：EditorPrefs 目录不存在 → Unity 设置静默丢失

详见 [[Unity开发踩坑#坑 1：Unity 设置每次重启全部丢失]]。
核心：Linux 上很多程序**不会自动创建配置目录**，写配置静默失败。
排查套路：strace 看 openat 的 ENOENT。

## 坑 3：nix-daemon 不继承用户代理环境

**症状**：终端里 curl/git 走代理都通，`nixos-rebuild` 下载却卡死或失败。

**根因**：rebuild 的下载是 **nix-daemon（root 系统服务）**干的，
它不读你的 shell 环境变量。

**修法**（configuration.nix）：
```nix
systemd.services.nix-daemon.environment = {
  GOPROXY = "https://goproxy.cn,direct";
  HTTPS_PROXY = "http://127.0.0.1:7897";
  HTTP_PROXY = "http://127.0.0.1:7897";
  https_proxy = "http://127.0.0.1:7897";
  http_proxy = "http://127.0.0.1:7897";
};
```
（Go 模块下载还需要 GOPROXY，DMS 这类 Go 构建必须有。）

## 坑 4：niri 环境块硬编码 WAYLAND_DISPLAY / XDG_RUNTIME_DIR

**症状**：曾经为了"修"某些程序识别不到 Wayland，在 niri config 的
environment 块里写死 `WAYLAND_DISPLAY "wayland-1"` 和
`XDG_RUNTIME_DIR "/run/user/1000"`。

**为什么这是坑**：这两个值**本来就由系统自动设置**（合成器和 logind）。
硬编码 = 把动态值写死：多会话/多用户/显示编号变化时全部错乱，
而且排障时极度迷惑（环境变量来源查半天）。

**修法**：删掉，让系统自己管。环境变量问题先查真正来源，不要硬覆盖。

## 坑 5：forceFullCompositionPipeline（X11 残留选项）

`hardware.nvidia.forceFullCompositionPipeline = true` 是 **X11 抗撕裂**选项，
对 Wayland 会话完全无效（Wayland 合成器天然防撕裂）。从 Windows/X11 教程
抄配置时容易带上。已删。

**通用原则**：抄别人的 NVIDIA 配置先看它针对 X11 还是 Wayland。

## 坑 6：systemd 用户服务失败的"假报警"

**症状**：`systemctl --user` 状态 degraded，`anime-wallpaper.service` failed。

**根因**：脚本里"搜索无结果就 exit 1"。但该脚本每分钟随机换壁纸关键词，
部分关键词本来就没结果——**业务常态被当成了失败**。

**修法**：区分"真失败"和"业务跳过"，后者 `exit 0`。
另外 `systemctl --user reset-failed <服务>` 可清掉失败状态。

**通用原则**：写 systemd oneshot 服务时想清楚：什么情况才值得标红报警？

## 坑 7：明文密码进 git

`users.users.loysan.initialPassword = "sk335="` 明文写在 flake 里，
推到 git 就是泄露。

**修法**：`hashedPassword`（`nix run nixpkgs#mkpasswd -- -m sha-512 '密码'` 生成）。
initialPassword 只在安装时兜底，日常生效的是 hashedPassword。

## 排查工具箱（本次实战用过的）

| 工具 | 干什么 | 例子 |
|---|---|---|
| `strace -f -e trace=openat` | 看进程实际读写哪些文件 | Unity prefs 路径 |
| `journalctl --user -u xxx` | 用户服务日志 | anime-wallpaper |
| `~/.config/unity3d/Editor.log` | Unity 第一现场 | 终端检测失败 |
| `nixos-rebuild build` | 免 sudo 验证配置 | 每次改完先跑 |
| `pgrep -af xxx` | 确认进程怎么启动的 | unityhub bwrap 沙箱 |
| `ldd <二进制>` | 查动态库解析 | UnityPlayer.so |
| 读包源码 | PackageCache/nixpkgs 源码都在本机 | walcht 终端列表 |
