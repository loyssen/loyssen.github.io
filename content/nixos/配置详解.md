# 配置详解 —— loysan 的 nixos-config

> 配置仓库：`~/nixos-config`（git 管理，master 分支）
> 重建命令：`sudo nixos-rebuild switch --flake ~/nixos-config#loysan`
> 相关：[[使用说明]] · [[04-踩坑记录/系统配置踩坑|踩坑记录]]

## 一、整体架构

```
~/nixos-config/
├── flake.nix                  # 入口：声明所有外部依赖 + 组装系统
├── configuration.nix          # 系统级核心：引导/网络/用户/nix 设置/overlay
├── hardware-configuration.nix # 自动生成：磁盘/内核模块（勿手改）
├── modules/                   # 功能模块，每个文件管一个领域
│   ├── audio.nix              # PipeWire 音频
│   ├── desktop.nix            # SDDM 登录器 + 主题 + 数位板
│   ├── locale.nix             # 中文 locale + fcitx5 输入法 + 字体
│   ├── niri.nix               # niri 合成器（键位/布局/启动项，最大模块）
│   ├── noctalia-dms.nix       # DMS 顶栏构建
│   ├── nvidia.nix             # NVIDIA 驱动
│   ├── packages.nix           # 所有用户软件包
│   ├── portal.nix             # XDG portal（文件对话框/截图共享）
│   ├── security.nix           # polkit/密钥环/SSH
│   └── unity.nix              # Unity 开发支持（nix-ld 图形库）
└── nixvim/                    # Neovim 全套配置（独立子体系）
    ├── default.nix            # 入口 + 插件模块列表
    ├── options.nix            # 编辑器选项 + catppuccin 主题
    └── plugins/               # lsp/completion/dap/ai/unity...
```

**心智模型**：flake.nix 是"采购清单"（从哪买原料），configuration.nix 是"总装车间"，
modules/ 每个文件是"一个工位"。改系统 = 改这些文件 → rebuild → 原子切换。

## 二、flake.nix —— 依赖声明

| Input | 来源 | 作用 |
|---|---|---|
| `nixpkgs` | nixos-25.11 | 系统基线（稳定版） |
| `nixpkgs-unstable` | nixpkgs-unstable | 前沿包（QQ、pi-coding-agent） |
| `niri` | sodiboo/niri-flake | niri 合成器二进制 + NixOS 模块 |
| `noctalia` | noctalia-dev/noctalia | 桌面 shell（壁纸/锁屏/launcher/控制中心） |
| `dankMaterialShell` | AvengeMedia | DMS 顶栏 + 系统监控 |
| `quickshell` | outfoxxed | DMS 的 UI 运行时 |
| `nixvim` | nix-community | Neovim 全 Nix 化 |

所有 input 都 `follows nixpkgs`（共用同一份 nixpkgs，避免重复下载）。
系统只定义一台机器：`nixosConfigurations.loysan`（x86_64-linux）。

## 三、configuration.nix —— 系统核心

- **引导**：systemd-boot + EFI
- **网络**：NetworkManager，主机名 `loysan`，时区 Asia/Shanghai
- **镜像加速**：清华/USTC 二进制缓存优先，cache.nixos.org 兜底
- **nix-daemon 代理**：GOPROXY=goproxy.cn + HTTP(S)_PROXY=127.0.0.1:7897（clash）
  —— DMS 等 Go 模块下载必须走代理
- **unstable overlay**（重要模式）：
  ```nix
  nixpkgs.overlays = [
    (final: prev: {
      unstable = import inputs.nixpkgs-unstable {
        system = prev.stdenv.hostPlatform.system;
        config.allowUnfree = true;   # ← 必须！legacyPackages 不带 unfree 许可
      };
    })
  ];
  ```
  之后任何模块直接用 `pkgs.unstable.<包名>`，不用各自重复定义。
  ⚠️ 坑：`legacyPackages` 的 allowUnfree=false，QQ 等 unfree 包会报许可错误。
- **用户**：loysan，wheel/networkmanager/video/input/audio 组，hashedPassword
  （明文 initialPassword 仅首装兜底，勿再改它）

## 四、modules/ 逐模块

### niri.nix（核心中的核心，225 行）
niri 配置以 KDL 文本写入 `/etc/niri/config.kdl`：
- **输入**：us 布局、触控板自然滚动、鼠标 flat 加速、focus-follows-mouse
- **启动链**：noctalia → 2 秒后隐藏其 bar → DMS daemon → OCR 剪贴板守护
- **环境变量**：全套 Wayland 强制 + fcitx5 + 代理（DMS 插件需要）
- **布局**：gaps 5、焦点环 `#7fc8ff`、5 个命名 workspace、6px 圆角
- **规则**：Firefox 固定 workspace 3 + 最大化
- **键位**：完整 vim 风格，详见 [[使用说明]]

### nvidia.nix
专有驱动 open 内核模块 + latest 包 + modeset/fbdev + initrd 早加载防闪屏 + vaapi。
已删 `forceFullCompositionPipeline`（X11 专用，Wayland 无意义）。

### audio.nix / portal.nix / security.nix
- PipeWire + WirePlumber + rtkit（实时调度）
- portal：gtk（默认）+ gnome（niri 录屏需要），`xdgOpenUsePortal = true`
- polkit + LXQt 认证 agent（user service）+ gnome-keyring + SSH

### locale.nix
zh_CN.UTF-8 全套 + en_US 备选；fcitx5（rime + chinese-addons + nord 主题，
waylandFrontend）；Noto CJK + JetBrainsMono Nerd Font + 思源黑体。

### desktop.nix
SDDM（Wayland 模式，catppuccin-corners 主题）+ 自动登录 + 默认 niri 会话；
全局环境变量（NIXOS_OZONE_WL 强制 Electron 走 Wayland 等）；
`hardware.opentabletdriver.enable`（Wacom 数位板，含 udev 规则 + 用户服务）。

### unity.nix（Unity 开发的生命线）
```nix
programs.nix-ld.enable = true;
programs.nix-ld.libraries = with pkgs; [ libglvnd mesa xorg.libX11 ... wayland libxkbcommon dbus ];
```
- nix-ld = 外来二进制的"翻译官"，提供标准 ld.so + 库搜索路径
- libraries 追加到默认集合（list 选项自动合并，不会覆盖基础库）
- 没有这些库，Unity 打包的游戏窗口创建失败（详见 [[Unity开发踩坑]]）
- 另有：chromiumSuidSandbox（Editor 内嵌 chrome-sandbox）、inotify 4096（roslyn 大项目）、unityhub

### packages.nix
按用途分组：终端/浏览器/CLI 现代化工具（yazi/zoxide/fzf/bat/lsd...）/
开发（nodejs/python3/gcc/dotnet-sdk_9/roslyn-ls/netcoredbg/csharpier）/
网络（clash-verge-rev/wireguard）/媒体（mpv/nautilus/amberol）/
办公（obsidian/wpsoffice/xmind）/创作（blender/krita/pinta）/
IM（wechat/qq-unstable）/网易云音乐/Chrome。

### noctalia-dms.nix
DMS 用 **unstable** nixpkgs 构建（`mkDmsShell pkgs.unstable`），quickshell 用上游 flake。

## 五、nixvim/ —— Neovim 子体系

- **options**：相对行号、2 空格缩进、系统剪贴板、catppuccin mocha 透明背景、leader=空格
- **LSP**：10 个语言服务器 + roslyn_ls（新 `lsp.servers` API，
  `root_markers = [ "ProjectSettings" ".git" ]` —— ⚠️ vim.fs.find 不支持 glob，
  写 `"*.sln"` 永远匹配不到！）
- **DAP**：Python(debugpy)/Rust(codelldb)/Node(vscode-js-debug)/Go(delve)/C#(netcoredbg)，F5-F12
- **补全**：blink.cmp (super-tab) + luasnip；**格式化**：conform-nvim 保存时格式化 13 种文件类型
- **AI**：avante.nvim (Claude) + `<leader>ap`/`<leader>ac` 右侧 35% 分屏拉起 pi/claude CLI
- **编辑**：neo-tree + oil + telescope + treesitter；git：gitsigns + lazygit + diffview

## 六、扩展点（以后要改什么去哪改）

| 想做什么 | 改哪里 |
|---|---|
| 加软件 | `modules/packages.nix` 对应分组加一行 |
| 包在 stable 没有/太旧 | 改 `pkgs.unstable.<包名>`（overlay 已就绪） |
| 加 niri 键位/规则 | `modules/niri.nix` 的 binds / window-rule 块 |
| 加 nvim 插件 | `nixvim/plugins/` 新建或改对应文件，default.nix 里 import |
| 加新的语言 LSP | `nixvim/plugins/lsp.nix` servers 加一行 |
| 换壁纸/锁屏样式 | noctalia GUI（Mod+Comma）或 DMS 设置 |
| 加系统级服务 | 新建 `modules/xxx.nix` 并在 configuration.nix imports |
| 外来二进制跑不起来 | 大概率缺库 → `modules/unity.nix` 的 nix-ld.libraries 追加 |

## 七、日常维护命令

```bash
sudo nixos-rebuild switch --flake ~/nixos-config#loysan   # 应用配置
nixos-rebuild build --flake ~/nixos-config#loysan         # 只构建不激活（验证用，免 sudo）
sudo nixos-rebuild boot --flake ... && reboot             # 下次启动生效（当前系统坏了时用）
nix flake update --flake ~/nixos-config                   # 更新所有依赖（升级系统）
sudo nix-collect-garbage -d                               # 清理旧代际和孤立包
```

每次改完**记得 git commit**，配置即历史，可回滚可 diff。
