## 1. 你的视觉体系

| 层面 | 你用的什么 | 在哪配的 |
|---|---|---|
| 系统字体 | Noto Sans/Serif CJK SC | locale.nix（`fonts.fontconfig.defaultFonts`） |
| 等宽字体 | JetBrainsMono Nerd Font | locale.nix（monospace fallback）、nvim 也用 |
| 终端字体 | 继承系统等宽 → JetBrainsMono | kitty 自动认 fontconfig |
| SDDM 主题 | catppuccin-corners | desktop.nix（`sddm.theme`） |

## 2. 字体优先级（fontconfig 怎么选字）

你的 locale.nix 设了：
```nix
sansSerif = [ "Noto Sans CJK SC" "DejaVu Sans" ];
serif = [ "Noto Serif CJK SC" "DejaVu Serif" ];
monospace = [ "JetBrainsMono Nerd Font" "Cascadia Code" "Noto Sans Mono CJK SC" ];
```

当一个应用（比如你的 nvim）请求 "monospace 字体"时：
1. 找 JetBrainsMono Nerd Font → 找到了 → 用它（含 nerd font 图标 support）
2. 找不到 → 用 Cascadia Code→ 找不到 → Noto Sans Mono CJK SC（含中文字符集）

CJK 字体很大（Noto Sans CJK SC 一个文件 20MB+），不能每应用各拷一份——
fontconfig 做集中管理，应用只需要请求字体族名称。

## 3. Nerd Font：为什么你的 nvim 和终端里有图标

JetBrainsMono Nerd Font = JetBrainsMono + Nerd Font 的图标字符集补丁。
nvim 里 web-devicons/lualine/telescope 的 FileType 图标、Git 符号全用的是这种字体。
没有它 → 看到方块 □。你的 locale.nix 已经把 Nerd Font 加上去了。

## 4. 光标：Bibata-Modern-Ice

Bibata 光标主题是 pixel-perfect 的矢量光标套件：
- 正常箭头 + 淡蓝色调（Ice = 冷色调）
- 支持动画光标（可拓展）

声明在**两个地方**（都要设）：
- niri.nix `cursor { xcursor-theme "Bibata-Modern-Ice"; xcursor-size 24; }`
  → 合成器在 compositor 层画出光标
- desktop.nix `environment.variables XCURSOR_THEME/SIZE`
  → XWayland 应用用这个找光标

如果 XWayland 应用的光标跟原生 Wayland 外观不一致，查这里。

## 5. SDDM：登录界面主题

`catppuccin-sddm-corners` = Catppuccin 色系 + 圆角设计 + 用户头像区的登录管理器主题。
Wayland 模式生效（`sddm.wayland.enable = true`），niri 启动前显示。

## 6. GTK 主题（未定制，留白）

dconf 已启用（`programs.dconf.enable = true`）。
当前 GTK 应用用默认的 Adwaita 主题。如果需要统一 GTK 应用的外观：
```nix
# 临时手动测试
gsettings set org.gnome.desktop.interface gtk-theme Adwaita-dark
# 如果需要永久性声明（HM 或 nix 模块）
```

现在这样其实挺一致：catppuccin 登录 → catppuccin nvim → Adwaita GTK
→ Bibata 光标——视觉不打架。

## 7. 怎么改

| 想改的 | 文件 | option |
|---|---|---|
| 默认字体 | locale.nix | `fonts.fontconfig.defaultFonts` |
| 光标 | niri.nix + desktop.nix | `xcursor-theme` / `XCURSOR_THEME` |
| SDDM 背景/头像 | sddm 主题配置目录 | sddm theme 的 theme.conf |
| nvim 颜色 | nixvim options.nix | `colorschemes.catppuccin.settings.flavour` |
| 终端字体 | kitty config | `font_family JetBrainsMono Nerd Font` |
