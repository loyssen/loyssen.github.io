## 一、niri 键位速查（Mod = Super/Win 键）

### 应用启动
| 键位 | 作用 |
|---|---|
| `Mod+回车` | kitty 终端 |
| `Mod+D` | fuzzel 应用启动器（≈ Windows 开始菜单搜索） |
| `Mod+B` | Firefox |
| `Mod+Space` | Noctalia 应用 launcher |
| `Mod+S` | 控制中心（≈ Windows 设置面板） |
| `Mod+,` | Noctalia 设置 |
| `Super+Alt+L` | 锁屏 |
| `Mod+Shift+/` | 显示全部键位（忘了就按这个） |

### 窗口操作（vim 风格 hjkl = 左下上右）
| 键位 | 作用 |
|---|---|
| `Mod+H/J/K/L` 或方向键 | 切换焦点 |
| `Mod+Ctrl+H/J/K/L` | 移动窗口/列 |
| `Mod+Q` | 关闭窗口（≈ Alt+F4） |
| `Mod+F` | 最大化当前列 |
| `Mod+Shift+F` | 真全屏 |
| `Mod+V` | 浮动/平铺切换 |
| `Mod+R` | 循环预设列宽（50%/66%/100%） |
| `Mod+C` | 居中当前列 |
| `Mod+O` | Overview（≈ Windows 任务视图） |
| `Mod+[` / `Mod+]` | 把窗口吞入/吐出左侧/右侧列 |

### 工作区（5 个）
| 键位 | 作用 |
|---|---|
| `Mod+1..5` | 切换工作区 |
| `Mod+Ctrl+1..5` | 把窗口移到工作区 |
| `Mod+U` / `Mod+I` | 上/下工作区 |
| `Mod+滚轮` | 滚轮切工作区 |
| `Mod+Shift+滚轮` | 滚轮切列 |

### 系统
| 键位 | 作用 |
|---|---|
| 音量/亮度键 | 直接可用（锁屏下也行） |
| `Mod+Shift+S` | flameshot 截图标注 |
| `Mod+Shift+O` | 截图 + OCR 文字识别（自动复制到剪贴板） |
| `Mod+Shift+E` | 退出 niri（≈ 注销） |

## 二、日常工作流

### Unity 开发（核心工作流）
1. **Unity Hub**（fuzzel 搜 "Unity Hub"）→ 打开项目
2. 双击 C# 脚本 → 自动弹 kitty + nvim（单实例，多文件开新 tab）
3. nvim 里：`gd` 跳定义、`K` 文档、`<leader>rn` 重命名、`<leader>ca` 代码操作、
   `<leader>ff` 找文件、`<leader>fg` 全局搜、`<leader>e` 文件树、`<leader>gg` lazygit
4. 保存自动格式化（csharpier）；`:LspInfo` 查 LSP 状态
5. 打包：File → Build Settings → **Build**（选 `Builds/Test`，文件名输 `xxx.x86_64`）
   —— 产物可直接双击运行（nix-ld 已配好图形库）
6. 调试：nvim 里 `<leader>db` 打断点，`F5` 启动 netcoredbg

**注意**：Unity 设置改了要用 **File → Exit 正常退出** 才保存。
External Script Editor 已预置为 Neovim，勿改。

### 截图三件套
- `Mod+Shift+S`：flameshot —— 框选 + 箭头/文字/马赛克标注 + 钉图
- `Mod+Shift+O`：截图 OCR —— 框选后文字直接进剪贴板
- 剪贴板里的图片会被 OCR 守护进程自动识别文字（后台）

### 音乐
- 本地：amberol（DMS 顶栏自动显示播放控制/可视化）
- 在线：netease-cloud-music-gtk4（fuzzel 搜 "网易云"）
- 任何 MPRIS 播放器都会被 DMS 自动接管

### 文件管理
- GUI：`nautilus`（fuzzel 搜 "文件"）；Unity 打包完会自动用它打开输出目录
- TUI：终端里 `yazi`（hjkl 移动，回车进入，q 退出，空格选中）

### 翻译
- crow-translate：选中文字后唤出可划词翻译，支持 OCR 截图翻译
- （pot 已被 nixpkgs 移除，见 [[nixpkgs软件包踩坑]]）

### 数位板（Wacom）
插上即用。配置界面：终端 `otd-gui`（OpenTabletDriver）。
服务状态：`systemctl --user status opentabletdriver`

## 四、终端基本功（每天必用）

```bash
cd / ls / pwd          # 切换/列出/当前目录（≈ cd, dir）
cp -r a b / mv a b     # 复制/移动（≈ copy, move）
rm file / rm -r dir    # 删除（危险！无回收站）
cat file / less file   # 看文件（less 可翻页，q 退出）
command | grep 关键词   # 管道过滤（≈ findstr）
command > file         # 输出写文件（>> 追加）
sudo command           # 管理员执行（≈ 以管理员身份运行）
systemctl status xxx   # 查服务状态
journalctl -u xxx      # 查服务日志
journalctl --user -u xxx  # 用户服务日志
```

你的 shell 已装现代化替代：`lsd`(ls)、`bat`(cat)、`ripgrep`(grep)、`fd`(find)、
`zoxide`(cd，`z 关键词` 跳目录)、`fzf`(模糊搜索，`Ctrl+R` 搜历史命令)。

## 五、出问题了怎么办（自检流程）

1. **图形界面异常** → `Mod+Shift+E` 退出重进；不行就 `sudo reboot`
2. **系统起不来** → 开机 systemd-boot 菜单选**上一个代际**（NixOS 自带后悔药）
3. **配置改坏了** → `nixos-rebuild build` 先验证；switch 报错原样发出来
4. **软件行为异常** → 查 [[04-踩坑记录/系统配置踩坑|踩坑记录]] 有没有同款
5. **查日志** → `journalctl -b`（本次启动全部）、`journalctl --user -b`
